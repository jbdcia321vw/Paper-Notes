    🎮 强化学习与动态探索推荐 (RL, Bandits & Long-Term Engagement)

    研究范畴：Contextual Bandit 探索与利用 (E&E)、Offline RL 长期留存与生命周期价值 (LTV) 策略优化

    当前方向共收录 86 篇顶会/顶刊论文解读：

    BayesCNS: A Unified Bayesian Approach to Address Cold Start and Non-Stationarity in Search Systems at Scale

    用经验贝叶斯先验网络+Thompson采样在线更新，统一解决物品冷启动与非平稳漂移，线上A/B新物品曝光+10.60%。

    Contrastive Representation for Interactive Recommendation

    用偏好排序对比学习(PRCL)为 DRL 交互推荐提炼状态表征，冷启动下样本效率显著提升。

    LLM-Powered User Simulator for Recommender System

    用 LLM 离线蒸馏物品优缺点关键词，构建关键词匹配+语义相似+序列统计三模型集成用户模拟器，为 RL 推荐提供可解释高保真环境。

    Neural Combinatorial Clustered Bandits for Recommendation Systems

    用双神经网络+上下文聚类替代组合老虎机的精确优化 oracle，实现 $\tilde{O}(\tilde{d}\sqrt{T})$ 遗憾并显著降低推荐累积遗憾。

    Preference is More Than Comparisons: Rethinking Dueling Bandits with Augmented Human Feedback

    用增强置信界把相似/依赖观测注入无模型 Dueling Bandit，给出样本复杂度与遗憾权衡，在推荐、多目标优化与 LLM 响应优化上显著降遗憾。

    LaMP-Val: Large Language Models Empower Personalized Valuation in Auction

    用 LLM 从用户评论语义中做个性化估值，构建 23k 估值数据集 + 多样化指令 SFT，并提出 PU/PV 闭环拍卖指标，PU 较 GPT-4 提升约 6.5 倍。

    User Feedback Alignment for LLM-powered Exploration in Large-scale Recommendation Systems

    解耦新颖性与用户对齐双 LLM，用集体隐式反馈训练对齐模型做 best-of-n 选择，线上同时提升新颖曝光与满意度。

    World Model-Guided Reinforcement Learning via Counterfactual User Engagement Simulation

    将推荐视为动作、异构反馈视为观测，用语言世界模型 UEWM 做反事实用户模拟器，为 1.7B 策略提供同状态稠密奖励，跨域零样本超越大模型。

    Generative Flow Networks for Personalized Multimedia Systems: A Case Study on Short Video Feeds

    用 GFlowNet 多候选生成替代单动作 RL 策略，在短视频预取场景实现个性化 QoE 与带宽双优化。

    Energy-Guided Diffusion Sampling for Long-Term User Behavior Prediction in Reinforcement Learning-based Recommendation

    用扩散策略替代行为克隆以提升离线RL4RS策略表达能力，并以Q值能量引导采样降低随机性，六数据集与仿真环境全面领先。

    Expert-Guided Diffusion Planner for Auto-bidding

    用专家轨迹引导条件扩散规划器生成出价序列，配合混合强制训练与跳步采样，线上转化+11.29%、收入+12.36%。

    Heterogeneous Influence Maximization in User Recommendation

    将异质传播概率与 RR 集影响力最大化引入好友邀请推荐，HeteroIR/HeteroIM 在 NSpread/Recall/NDCG 全面领先并落地腾讯游戏 A/B 提升 8.5%/10%。

    KP-Agent: Keyword Pruning in Sponsored Search Advertising via LLM-Powered Contextual Bandits

    将关键词剪枝建模为上下文赌博机，用 LLM Agent 生成代码片段执行剪枝，美团真实数据上累计利润最高提升 49.28%。

    Maximum In-Support Return Modeling for Dynamic Recommendation with Language Model Prior

    将轨迹拼接从训练期移至动作推理期，用 expectile 回归估计最大在支撑回报并自适应截断历史，配合 LLM 先验初始化 DT，在 5 个离线数据集与 VirtualTB 仿真上全面超越 EDT4Rec。

    Stratified Expert Cloning for Retention-Aware Recommendation at Scale

    用分层专家行为克隆替代 RL 探索，配合动作熵正则与自适应专家选择，在快手双平台 A/B 中提升活跃天数 0.098%/0.122%。

    Efficient Offline Learning of Ranking Policies via Top-$k$ Policy Decomposition

    将排序策略分解为 top-$k$ 策略梯度与 bottom 回归两段，在 CPC 条件下无偏且大幅降方差，小样本与大规模排序空间下显著优于 IPS/DR/RIPS/IIPS。

    EVOL: Simulator-Guided Evolutionary Expert Synthesis for Deployment-Free Learning Path Recommendation

    用知识追踪模拟器内进化搜索合成专家路径，蒸馏为仅凭初始掌握度盲规划的非对称 Actor-Critic，实现免模拟器部署的学习路径推荐。

    FunnelCausalNet: Funnel-aware Joint Conversion-Revenue Uplift for Multi-tier Coupon Allocation

    以漏斗恒等式 μ_gmv=μ_conv·μ_val 耦合双头 uplift 估计，配 RCT 锚定拉格朗日预算分配与 Bonferroni 联合保形审计带，工业多档券 RCT 上 7/7 锚点 ΔROI 最优。

    Learning from Unreachable Rewards: Hint-Conditioned Reinforcement Learning for Generative Recommendation

    用 SFT 检查点诊断语义 ID 前缀树可达性，对不可达样本注入最短目标前缀提示并以提示感知信用分解（前缀 SFT + 后缀 GRPO）恢复学习信号，零优势组从 70%+ 降至 20% 以下。

    LLM-Enhanced Reinforcement Learning for Long-Term User Satisfaction in Interactive Recommendation

    LLM 做类别级语义规划、PPO 做物品级策略，KuaiSim 全会话仿真下 Tint/Rcum 显著超越 DNaIR 等 SOTA。

    Beyond Static LLM Policies: Imitation-Enhanced Reinforcement Learning for Recommendation

    用 LLM 轨迹作次优示范，经对抗逆强化学习提取奖励并加权模仿，离线 RL 策略在 Steam/Amazon 上累积奖励较 BiLLP 提升 13%+。

    Enhancing Personalized Multi-Turn Dialogue with Curiosity Reward

    将用户模型信念增益作为 PBRS 内在奖励注入多轮 RLHF，使 LLM 主动探询用户属性，习题推荐成功率 54%→87.5%。

    Fine-grained List-wise Alignment for Generative Medication Recommendation

    将用药推荐重构为逐药序列决策，提出逐步GRPO与势函数奖励塑形实现细粒度信用分配，在MIMIC-III上Jaccard达0.4836并支持安全-精度可控权衡。

    Learning Personalized Ad Impact via Contextual Reinforcement Learning under Delayed Rewards

    将自动出价建模为带延迟泊松奖励的CMDP，提出两阶段MLE与数据分割，实现个性化出价近最优遗憾界。

    MTRec: Learning to Align with User Preferences via Mental Reward Models

    用分布化逆强化学习(QR-IQL)从行为轨迹反推用户心理奖励分布，作为辅助对齐信号注入CTR/RL推荐模型，离线AUC/NCIS全面提升，工业短视频A/B观看时长+7%。

    Optimal Auction Design in the Joint Advertising

    联合广告单槽位Myerson最优机制+多槽位BundleNet束级IC约束神经网络，逼近理论最优并显著提升平台收益

    Personalized Exercise Recommendation with Semantically-Grounded Knowledge Tracing

    ExRec 用 LLM 自动标注知识点+对比学习语义表征+KT 校准，并以 KT 模型做 Model-Based Value Estimation 稳定 Q-learning，在四个教育推荐任务上显著提升知识状态增益。

    Think before Recommendation: Autonomous Reasoning-enhanced Recommender

    用纯 GRPO 强化学习替代教师蒸馏，让单个 LLM 自主习得「用户分析→物品分析→匹配→打分」推理链，评分预测 MAE 最高降 29.9%。

    ALM-MTA: Front-Door Causal Multi-Touch Attribution Method for Creator-Ecosystem Optimization

    以前门识别+对抗代理中介实现大规模推荐系统多触点因果归因，离线 AUC 0.907、线上创作者 +0.6%。

    Beyond Match Maximization and Fairness: Retention-Optimized Two-Sided Matching

    将双边匹配推荐重构为留存最大化问题，用凹性 Jensen 下界把 NP-hard 排序松弛为 O(NlogN) 的 argsort 打分，在合成与真实约会平台数据上以约 70% 匹配量取得最高留存率。

    COPF: An Online Framework for Deployment-Stable Counterfactual Fairness in Evolving Graphs

    以曝光反事实定义群体机会差，用倾向日志+GA-DR残差+Residual-OI证书在线审计并控制演化图链路推荐的部署稳定公平性。

    Incentivized Exploration with Stochastic Covariates: A Two-Stage Mechanism Design for Recommender System

    面向在线随机用户协变量的激励相容探索，提出两阶段 RCB 算法（冷启动补贴 + 逆比例间隙采样），在满足 ε-DBIC 约束下达到 $\tilde{O}(\sqrt{KdT})$ 遗憾。

    On the Coordination of Value-Maximizing Bidders

    证明价值最大化自动出价方在“最高价值者出价”协调机制下，RoS 合规与联盟总价值均优于独立出价，并给出充要条件与渐近最优性。

    Optimal and Efficient Contextual Combinatorial Semi-bandits with General Function Approximation

    提出 SquareCB.Comb，用回归 oracle + 对数障碍边际优化实现通用函数逼近下 CCSB 的极小极大最优 regret，并在网页推荐与最短路任务上验证。

    ProRL: Effective Reinforcement Learning for Proactive Recommendation via Rectified Policy Gradient Estimation

    揭示主动推荐中策略梯度的长度捷径与高方差缺陷，提出逐步奖励中心化与位置特定优势估计，三数据集全面超越 SOTA。

    PACE: A Personalized Adaptive Curriculum Engine for 9-1-1 Call-taker Training

    用技能图信念传播+个体学习/遗忘动力学+Thompson Sampling 上下文老虎机为 9-1-1 调度员推荐训练场景，Z2H 缩短 19.50%、终局掌握度提升 10.95%。

    A Unified Online-Offline Framework for Co-Branding Campaign Recommendations

    首个联名营销推荐系统性研究：二分图建模+方差感知CUCB在线学习+部分枚举离线预算分配，理论保证近优regret与1-1/e近似，真实数据收益提升12%-73%。

    An Adaptable Budget Planner for Enhancing Budget-Constrained Auto-Bidding in Online Advertising

    将竞价周期切分为多阶段，用 in-context RL 逐 episode 调整预算分配，few-shot 适配新广告主，仿真与线上 A/B 均提升累计价值。

    Beyond Advertising: Mechanism Design for Platform-Wide Marketing Service 'QuanZhanTui'

    提出全站推场景下的库存约束卖家模型与流式支付拍卖 LPA，在合成与真实数据上同时提升流式福利、用户体验与平台收入。

    Beyond Item Dissimilarities: Diversifying by Intent in Recommender Systems

    用实时意图概率驱动整页贪心重排，以贝叶斯后验更新替代物品相似度，YouTube 线上 DAU +0.05%、用户享受度 +0.09%。

    Leveraging the Power of Conversations: Optimal Key Term Selection in Conversational Contextual Bandits

    用平滑关键词语境与最小特征值自适应触发对话，将对话式上下文 Bandit 遗憾降至近极小极大最优 O(√(dT logT))，累积遗憾较基线降低至少 14.6%。

    Lightweight Auto-bidding based on Traffic Prediction in Live Advertising

    直播广告场景下，用LightGBM预测全时段累计成本/点击，结合LP对偶最优出价公式与投影梯度下降求解对偶变量，实现秒级轻量自动出价，线上GMV+4.28%。

    Measure Domain's Gap: A Similar Domain Selection Principle for Multi-Domain Recommendation

    用原型距离+bandit动态为每个域挑选相似域子集，解耦共享专家以缓解多域推荐负迁移，三数据集AUC稳定提升。

    Multi-task Offline Reinforcement Learning for Online Advertising in Recommender Systems

    用因果状态编码器+因果注意力+多任务解码器把广告渠道推荐与预算分配统一进离线RL，KuaiRand/Criteo 上 F1 提升约 7.5%/16.2%，线上 CTR +0.08。

    Revisiting Clustering of Neural Bandits: Selective Reinitialization for Mitigating Loss of Plasticity

    针对神经聚类 Bandit 的可塑性丧失问题，提出选择性重初始化框架 SeRe，配合自适应变点检测，在六个推荐数据集上最多降低 12.82% 累积遗憾。

    Session-Level Dynamic Ad Load Optimization using Offline Robust Reinforcement Learning

    将会话级广告加载建模为鲁棒MDP，用IPM不确定集导出免额外开销的鲁棒对决DQN，离线AUCC提升80%+，线上A/B双位数增益。

    Deep-learning Causal Retrieval Optimization for Efficient e-commerce Distribution in Pinterest

    Heterogeneous Multi-treatment Uplift Modeling for Trade-off Optimization in Short-Video Recommendation

    Hierarchical Residual Policy Optimization for Generative Recommendations

    HOBA: Hierarchical On-Policy Bidding Agents for Adaptive Online Advertising

    Learning Peer Influence Probabilities with Linear Contextual Bandits

    Uncertainty-Aware Adaptive Recommendation across User Lifecycle

    用 EPE Critic 与经验贝叶斯先验方差量化逐样本认知不确定性，对低活跃用户风险规避降权、高活跃用户 UCB 探索加成，14 天线上 A/B 验证留存与多样性双收益。

    Agentic Personalisation of Cross-Channel Marketing Experiences

    用 DiD 因果估计 + Thompson 采样构建模块化营销智能体，在 640 万用户线上 RCT 中显著提升漏斗事件与 GMV。

    Counterfactual Inference under Thompson Sampling

    推导 Thompson Sampling 下动作倾向性的精确可计算闭式解，使 IPS 类离线评估在 TS 策略下首次可行，OBP 仿真验证无偏收敛。

    Exploitation Over Exploration: Unmasking the Bias in Linear Bandit Recommender Offline Evaluation

    大规模实证揭示线性 Bandit 离线回放评估系统性偏袒纯利用策略，贪心模型在 89% 数据集上不劣于探索变体。

    Item-centric Exploration for Cold Start Problem

    提出以物品为中心的 Beta 后验过滤控制，在排序后剔除“错配受众”曝光，线上探索曝光降 20% 而满意度升 50%、可推荐语料扩 10%。

    Off-Policy Evaluation and Learning for Matching Markets

    面向双向匹配市场提出 DiPS/DPR 两阶段奖励 OPE 估计器，利用一阶段 scout 信号降方差，合成+Wantedly 真实 A/B 日志验证 MSE 与策略选择显著优于 DM/IPS/DR。

    Learned Cross-Task Relationships in Multi-Task Models

    用交叉标签/无条件辅助头显式逼近任务两两联合分布，在 YouTube 三大场景线上 A/B 验证迁移与 RL 状态增强双重收益。

    LLM Reasoning for Subjective Tasks: Failure Modes, Mitigation, and Dynamic Reasoning Routing

    揭示主观验证任务上显式推理与标准 RLVR 会引发推理崩溃，提出条件长度惩罚奖励与人格路由蓝图，Netflix 四任务 macro-F1 最高回升至 0.851。

    LLM-Based User Personas for Recommendations at Scale

    工业级实时生成自然语言用户兴趣画像，蒸馏+异步推理支撑十亿用户在线服务，A/B 测试观看时长 +0.04%

    Long-term User Engagement Optimization through Model-agnostic Downstream Rewards Learning

    以 P2P 兔子洞深度、浅层关闭负奖励与新用例采纳三类下游奖励替代稀疏留存标签，在 Pinterest 多场景线上 A/B 中稳定提升会话与留存指标。

    Progressive Alignment of Recommender Foundation Model through Multi-Phase Post-Training

    将推荐基础模型后训练拆为 LP→FFT→RFT 三阶段，用稠密隐式反馈训练策略、稀疏业务指标仅训练奖励模型，离线 Rank NDCG 0.437→0.463，线上全漏斗指标显著优于非 FM 基线。

    Self-Evolving Recommendation System: End-To-End Autonomous Model Optimization With LLM Agents
