    Coherency Improved Explainable Recommendation via Large Language Model

    用 LLaMA2 先预测评分再以软评分嵌入引导解释生成，配合课程学习与无标注一致性自动评测，解释一致性提升 7.3%。

    Harnessing Multimodal Large Language Models for Multimodal Sequential Recommendation

    用 MLLM 将商品图转为文本摘要，再以循环式提示推断动态用户偏好，SFT 微调 LLaVA 做多模态序列推荐，AUC 最高提升约 4.3%。

    Predicting User Behavior in Smart Spaces with LLM-Enhanced Logs and Personalized Prompts

    用 LLM 语义增强智能空间事件日志 + 个性化图软提示，在智能车/智能家居四数据集上显著提升下一行为预测，稀有事件 H@1 提升超 40%。

    Re2LLM: Reflective Reinforcement Large Language Model for Session-based Recommendation

    用 LLM 自反思生成纠错提示构建知识库，再以 PPO 训练轻量检索智能体按会话选提示，冻结主干即超越全量训练基线。

    Align$^3$GR: Unified Multi-Level Alignment for LLM-based Generative Recommendation

    Contextualizing Recommendation Explanations with LLMs: A User Study

    CroPS: Improving Dense Retrieval with Cross-Perspective Positive Samples in Short-Video Search

    用查询改写/推荐流/LLM 三源扩充正样本，配分层标签与 H-InfoNCE，快手搜索线上 CTR +0.87%、改写率 -0.65%

    G-UBS: Towards Robust Understanding of Implicit Feedback via Group-Aware User Behavior Simulation

    用 LLM 群组画像 + 群组感知 GRPO 强化学习为个体隐式反馈去噪，构建 IF-VR 多模态基准，推理准确率提升 14.9%。

    RecToM: A Benchmark for Evaluating Machine Theory of Mind in LLM-based Conversational Recommender Systems

    首个面向对话推荐场景的人类标注 ToM 基准，从认知推断与行为预测两维评估 LLM，揭示细粒度意图与谄媚偏差瓶颈

    A Federated Framework for LLM-based Recommendation

    A Generative Framework for Personalized Sticker Retrieval

    Bias Beware: The Impact of Cognitive Biases on LLM-Driven Product Recommendations

    GraphLoRA: Structure-Aware Low-Rank Adaptation for Large Language Model Recommendation

    Mirroring Users: Towards Building Preference-aligned User Simulator with User Feedback in Recommendation

    One Polluted Page Is Enough: Evaluating Web Content Pollution in LLM Recommenders

    ReasonRec: A Reasoning-Augmented Multimodal Agent for Unified Recommendation

    RecToolBench: Benchmarking Recommendation-Specific Tool Orchestration under Fuzzy User Intent

    ReRec: Reasoning-Augmented LLM-based Recommendation Assistant via Reinforcement Fine-tuning
