    🤝 协同过滤与双塔召回 (Collaborative Filtering & Two-Tower Retrieval)

    研究范畴：矩阵分解、双塔向量内积检索、ANN 索引量化、解耦表征与负采样理论

    当前方向共收录 54 篇顶会/顶刊论文解读：

    CroPS: Improving Dense Retrieval with Cross-Perspective Positive Samples in Short-Video Search

    用查询改写/推荐流/LLM 三源扩充正样本，配分层标签与 H-InfoNCE，快手搜索线上 CTR +0.87%、改写率 -0.65%

    Extracting Interaction-Aware Monosemantic Concepts in Recommender Systems

    用预测感知 SAE 从双塔嵌入中提取单义神经元，在 ML1M/Last.FM 上实现高纯度概念发现与事后可控干预。

    Fidelity-Aware Recommendation Explanations via Stochastic Path Integration

    将路径积分归因引入推荐解释，用随机基线采样适配稀疏二值交互，在三种模型三数据集上刷新反事实保真度基准。

    Generalization Bounds for Semi-supervised Matrix Completion with Distributional Side Information

    提出隐式反馈采样分布与评分矩阵共享低秩子空间的半监督矩阵完成范式，证明误差可解耦为两项独立界，并在 ML-100K/Douban/Yelp 上验证。

    ClusterRAG: Cluster-Based Collaborative Filtering for Personalized Retrieval-Augmented Generation

    用 HDBSCAN 将用户按画像嵌入聚类，簇内 ColBERTv2 排序选近邻，簇-文档两级检索融合协同画像做个性化 RAG，LaMP 全任务最优。

    DualSpectralCF: Training-Free Sign-Aware Spectral Collaborative Filtering

    在任意谱滤波骨干上以带符号输入信号与带符号物品算子注入显式负反馈，免训练即插即用，全库排序下 R@20 最高提升 32.6%，比 SIGformer 快 7.7–155.3 倍。

    Think-to-Personalize: Unifying Reasoning and Retrieval for User-Centric Personalized Dense Retrieval

    用 SFT+GRPO 两阶段让 LLM 显式推理用户历史生成意图增强查询并统一编码，Full-Ranking 下 Broad/LongTail 召回显著提升，线上订单量 +0.46%

    Training-Free LLM-Based Recommendation with Post-LLM Item Refinement Using Collaborative Signals

    提出 post-LLM 范式 CoRRe，用共购图方向细化与流行度幅度校准改造 LLM 物品表征，免训练即在三域 Amazon 上超越全部免训练基线并多数超越训练式方法。

    TransRetrieval: Scaling Up Transformer-Based Retrieval for Industrial Recommendation

    用加权平均聚合+目标Token压缩+位置式域嵌入，让Transformer在召回阶段实现对数线性Scaling，线上收入+2.53%。

    A Reproducible and Fair Evaluation of Partition-aware Collaborative Filtering

    在统一用户留出划分与 TPE 调参下复现 FPSR/FPSR+，发现 BISM 在 Amazon-CDs 反超，FPSR 家族在长尾显著占优。

    CollectiveKV: Decoupling and Sharing Collaborative Information in Sequential Recommendation

    用可学习全局 K/V 池跨用户共享协同信息，将 KV cache 压缩至 0.8% 且精度不降，解码延迟随 batch 增长近乎平坦。

    Generalizing Linear Autoencoder Recommenders with Decoupled Expected Quadratic Loss

    将 EDLAE 目标推广为 DEQL，首次给出 b>0 闭式解并用 Miller 矩阵逆定理把复杂度从 O(n^4) 降到 O(n^3)，在 9 个基准上稳定超越 b=0 基线。

    Obliviate: Efficient Unlearning in Recommender Systems

    两阶段低秩适配器+局部校准的推荐系统机器遗忘框架，20%删除率下兼顾遗忘完整性与效用，比全量重训快约 3 倍。

    Rejuvenating Cross-Entropy Loss in Knowledge Distillation for Recommender Systems

    揭示CE蒸馏损失与NDCG的闭包假设矛盾，提出师生协同子集拆分与自适应加权的RCE-KD，全库排序下NDCG@20最高提升11.76%。

    Two-Level Softmax Sampling Done Right: Correcting Bias from Size Imbalance and Dispersion

    揭示两级 softmax 采样因簇大小失衡与簇内相似度离散导致的系统性偏差，提出 S-2LS/SD-2LS 校正，KL 保真度提升 1–4 个数量级且开销近乎为零。

    DaV-Gen: End-to-End Generative Retrieval via Draft-and-Verify

    将生成式检索重构为“起草-验证”双阶段单模型范式，以混合稀疏-稠密表征与复合损失统一召回与排序，工业搜索延迟降至70ms。

    Beyond Instance-Level Alignment and Uniformity: Semantic Factor Learning for Collaborative Filtering

    用批次内语义因子路由+匹配构造语义潜在正对，替代GCN邻域聚合，在四个稀疏数据集全库排序下NDCG@20最高提升6.24%。

    Breaking Information Cocoons: A Hyperbolic Framework for Balancing Exploration and Exploitation in Recommender Systems

    洛伦兹双曲空间对齐 LLM 语义与协同信号，并用 Dasgupta 代价驱动的无超参层次聚类实现用户可调探索-利用权衡，效用最高 +5.49%、多样性 +11.39%。

    Collaborative Memory Augmentation for Generative Recommendation

    为生成式推荐引入跨用户协同记忆库，用可学习查询token压缩序列、目标感知检索与门控交叉注意力融合，Full-Ranking下NDCG@5最高提升23.7%。

    How Do Graph Signals Affect Recommendation: Unveiling the Mystery of Low and High-Frequency Graph Signals

    理论证明同绝对值低频/高频图信号在推荐中等价，提出频率信号缩放器与空间翻转插件，在四个数据集全库排序下 Recall@20 最高提升约 3.0%。

    Lower Bias, Higher Welfare: How Creator Competition Reshapes Bias-Variance Tradeoff in Recommendation Platforms?

    博弈论建模创作者竞争如何重塑平台正则化选择，理论与实验一致表明策略环境下应弱正则（低偏差）以最大化用户福利。

    Rethinking Popularity Bias in Collaborative Filtering via Analytical Vector Decomposition

    揭示 BPR 优化在嵌入空间刻出“流行度方向”的几何偏差，提出非对称方向分解校正 DDC，在 5 个骨干上 MRR@10 提升 6%–29% 且 AvgPop@10 降 21%–47%。

    Scaling Multilingual Semantic Search in Uber Eats Delivery

    基于 gte-Qwen2 双塔统一多语言多垂类语义召回，InfoNCE+Triplet NCE 两阶段训练与 MRL 多维度服务，Store R@20 相对 Legacy 提升 88%。

    EGR: Embedding-Native Generative Retrieval with a Shared LLM

    用单一共享 LLM 同时编码物品与用户历史，以双对比损失联合训练，免量化免 grounding，线上 CVR +2.91%

    Embedding Subspace Partitioning for Dynamic Multi-Objective Retrieval

    将双塔嵌入切分为任务感知正交子空间，用服务时可调权重的加权内积替代单一点积，单模型即可在线遍历多目标 Pareto 前沿。

    Mosaic: A Fleet of User Embedding Specialists for Recommendation at Meta

    以四类异构专家模型族构建用户表征舰队，配合 MRM 与余弦冗余损失最大化增量信息，并提出免日志 CoEval 评估，离线 NE 稳定下降、线上 A/B 显著提升。

    Multi-Probe Zero Collision Hash (MPZCH): Mitigating Embedding Collisions and Enhancing Model Freshness in Large-Scale Recommenders

    用线性探测+身份/元数据辅助张量与主动淘汰，在工业级嵌入表上实现零碰撞并提升新内容新鲜度，训练/推理延迟几乎不变。

    Multilingual Semantic Retrieval for Apple Music Search

    305M 多语双塔 + 课程式多目标微调，配合分位数校准混合召回，离线 Hit@10 相对提升 69%，线上尾部查询 CR 提升 7.93% 且无结果率降 86%。

    Parameter-Efficient Single Collaborative Branch for Recommendation

    用单支路权重共享替代用户/物品双塔，参数量减半，精度持平且覆盖率与流行度偏差显著改善。

    Personalizing Incremental Video Search with Hybrid Text and ID Embeddings

    面向 Apple TV 逐键增量搜索，用文本语义与 ID 协同双嵌入注入 XGBoost 排序器，短前缀 NDCG@10 提升 8.63%，线上 CTR +1.14%。

    RecEvolve: A Knowledge-Driven Autonomous Agent System for Recommender Systems

    将双塔召回模型的架构搜索全生命周期交给多智能体闭环，41 次生产级训练换来 NDCG@50 相对 +19.9%、线上满意度 +3.77%，并意外暴露奖励黑客漏洞。

    SMART: LLM-Augmented Hybrid Retrieval for Dynamic Product Ads

    揭示规则查询擅长 BM25 重定向、LLM 查询擅长 ANN 拓客的检索分解，用输出审计门控仅路由 10% 用户，线上转化率 +27.6%

    SPEAR: Selection-aware Personalized End-to-end Adaptive Rewriting and Retrieval for Community Search

    以梯度隔离双嵌入+乘性门控+动态改写选择器统一查询改写与检索，离线点击召回@10提升99.5%，线上QVCTR+0.259%。

    Training seeds and model-selection stability in recommender-system evaluation

    固定数据划分与超参、仅变训练种子，从用户级指标敏感性、验证选模稳定性、验证-测试一致性与推荐列表一致性四层量化种子噪声，主张种子应纳入评估协议。

    UniPinRec: Unifying Generative Retrieval and Ranking at Pinterest Scale

    用 MAM 掩码动作建模 + 混合样本 + 跨阶段 KV 缓存复用，将生成式召回与排序全栈统一，线上延迟降 11.1%、QPS 升 63.6%。

    CS3: Efficient Online Capability Synergy for Two-Tower Recommendation

    以塔内自校正、跨塔EMA同步与级联模型共享三机制增强双塔召回，离线三数据集AUC一致提升，线上广告收入+8.36%且QPS仅降0.59%。

    DIAURec: Dual-Intent Space Representation Optimization for Recommendation

    以原型意图与分布意图重构表征，用对齐-均匀性+粗细粒度匹配联合优化，Amazon-book R@20 相对提升 10.6%

    OCP: Orthogonal Constrained Projection for Sparse Scaling in Industrial Commodity Recommendation

    在 Item-ID 投影层上施加 Stiefel 流形正交约束，抑制稀疏缩放下的嵌入坍缩，京东线上 UCXR +12.97%、GMV +8.95%。

    ProMax: Exploring the Potential of LLM-derived Profiles with Distribution Shaping for Recommender Systems

    将 LLM 画像视为检索信号而非融合特征，用双路分布重塑（监督+自监督）引导基座模型，LightGCN 上 NDCG@10 最高提升 8.44%。

    Rethinking Semantic–Collaborative Integration: Why Alignment Is Not Enough

    论证语义-协同全局对齐假设过强，提出共享+私有潜结构与互补性诊断，最小融合在 Amazon 三域 Full-Ranking 上超越对齐范式最高 41.7%。

    SilverTorch: A Unified Model-based System to Democratize Large-Scale Recommendation on GPUs

    将 ANN 检索与特征过滤下沉为 PyTorch 模型层，GPU Bloom Index 与 Int8 融合 ANN 协同设计，吞吐提升 23.7×、成本效率提升 13.35×。

    Unified Supervision for Walmart's Sponsored Search Retrieval via Joint Semantic Relevance and Behavioral Engagement Modeling

    以语义相关性为主监督、互动为相关项内偏好信号，融合交叉编码器分级标签、多通道检索先验与去偏互动构建统一双塔训练目标，离线 P@25 +10.5%、NDCG@25 +5.7%。

    ZoRRO: A Zero-Weight Personalized Recommender System for Scalable News Recommendation

    零权重免训练新闻推荐框架，以时间衰减×表征相似度打分，离线全库排序超越 NRMS，线上 CTR 逼近 SOTA 且推理快 600 倍。

    LSNR: Learned Sparse News Recommendations with Attentive User Modeling

    用独立编码+注意力聚合替代 STAR 的历史拼接，构建双通路稀疏用户向量，MIND NDCG@10 较 STAR 提升 11%，短历史场景反超稠密模型。

    Memory Is No Longer a Bottleneck: Memory-Efficient Graph Filtering for Scalable Collaborative Filtering

    用逐用户 Krylov 子空间替代全量物品相似度图，实现免训练多项式图滤波，内存降 5.74×、推理加速 26× 且精度反超 SOTA。

    Mitigating Popularity Bias in Recommendation with Global Listwise Learning and Progressive Bi-Weighting

    用 IPS 加权多项似然实现列表级全局无偏学习，并以 Bi-Weighting 平滑倾向估计与渐进式去偏，六数据集 Recall@20 平均提升 9.43%。

    Have We Really Understood Collaborative Information? An Empirical Investigation

    以物品共现路径长度量化协作信息为0/1/2-hop协作关系，系统实证其在六个基准上的分布、对12种推荐算法的影响与预测依赖，揭示模型强于简单CR、弱于复杂CR的核心规律。

    Diversity-Augmented Negative Sampling for Implicit Collaborative Filtering

    用用户级缓存 + 多样性增强 k-DPP + mixup 合成负样本，解决两阶段负采样同质化问题，Full-Ranking 下 NDCG@20 最高提升 8.76%。

    Efficient Learning of Sparse Representations from Interactions

    在 ELSA 线性自编码器训练中渐进剪枝学习高维稀疏物品嵌入，实现最高 100× 压缩仅损 2.5% nDCG，并派生可解释语义分段。

    GRank: Towards Target-Aware and Streamlined Industrial Retrieval with a Generate-Rank Framework

    用训练期目标注入把 Target-Aware 能力蒸馏进 MIPS 兼容生成器，再以轻量交叉注意力重排，免结构化索引实现 Recall@500 +30% 与 1.7× QPS。

    Identifying and Upweighting Power-Niche Users to Mitigate Popularity Bias in Recommendations

    识别高活跃-小众偏好用户并对其在BPR损失中双重加权，在三个基准上实现性能与流行度去偏的帕累托双赢。

    PI2I: A Personalized Item-Based Collaborative Filtering Retrieval Framework

    放宽 I2I 截断保召回、Trigger-Target 负采样对齐离线在线、目标注意力精排打分，淘宝线上成交率 +1.05%

    Spattack: Subgroup Poisoning Attacks on Federated Recommender Systems

    首个联邦推荐子群投毒攻击：近似-提升范式+对比排斥与自适应加权，0.1%恶意客户端即达100% ER@5且几乎不伤非目标群。

    Talos: Optimizing Top-$K$ Accuracy in Recommender Systems

    用量化阈值把 Top-K 截断改写为分数-阈值比较，配合采样分位回归与约束项，直接优化 Precision@K/Recall@K 并具备 DRO 鲁棒性。
