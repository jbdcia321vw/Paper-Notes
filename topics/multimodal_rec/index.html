    🧩 多模态推荐与内容理解 (Multimodal Recommendation)

    研究范畴：视觉-文本-音频特征融合与解耦、多模态图对齐、短视频/微视频推荐与图文电商匹配

    当前方向共收录 31 篇顶会/顶刊论文解读：

    Beyond Modality Harmony: Orthogonal Purification and Topology-Guided MoE for Conflict-Aware Multimodal Recommendation

    以纯协同锚点为几何参考轴正交分解并保能截断模态噪声，配合解耦 Sigmoid 路由 MoE 与冲突感知 safe-SSL，在 Amazon 三数据集 8:1:1 划分下 R@20 最高提升 6.55%。

    Beyond Noisy Signals: Dual-Level Denoising for Multi-modal Sequential Recommendation

    图拉普拉斯低通滤波去特征噪声 + FFT 可学习频域滤波去序列噪声，四数据集 Full-Ranking 全面 SOTA，R@20 最高 +19.33%。

    One Graph, Multiple Gains: Single High-Quality Item-Item Graph for Multimodal Recommendation

    构建一次高质量物品-物品图，经三元闭包重加权后复用于表征、交互图与优化三阶段，四数据集全指标SOTA且训练更快更省显存。

    BRIDGE: Behavior-Guided Residual Integration with Dual-Frequency Graph Evidence

    揭示跨视图对齐存在有效区间与频谱共享/私有分裂，提出双频图证据+行为符号残差仅在 top-K 候选内校准，Baby/Sports/Electronics 全库排序 R@20 最高提升 7.3%。

    Information-Guided Selective Modality-Interest Alignment for Multimodal Recommendation

    以互信息/条件熵分解为理论视角，用行为校准图精炼+兴趣对比+共享子空间选择性对齐，三数据集 Full-Ranking 全面 SOTA。

    Native Multimodal Representation Learning for Click-Through Rate Prediction in E-Commerce Scenarios

    揭示端到端联合训练在强预训练编码器上失效的根因（CTR 监督多模态不可解释+梯度不一致），提出 Mine-Then-Train 挖掘三元组微调编码器，线上 CTR +1.5%、RPM +0.5%。

    Sequential Modality Dropout for Robust Multi-Modal Sequential Recommendation

    在融合点注入逐样本伯努利模态掩码，四行代码即插即用，使四种多模态序列骨干在模态缺失下 HR@10 留存率提升 1.0–3.2×。

    Sequential Multimodal Evidence Optimization for Product Media Ranking in E-Commerce

    将商品媒体排序建模为证据累积序列决策，两阶段解耦效用学习与生存加权自回归策略，离线 DR-CVR +5.4%、MSC −15.3%。

    Text-Guided Visual Representation Learning for Robust Multimodal E-Commerce Recommendation

    以结构化元数据初始化语义查询、双流解耦视觉证据并用可靠性双门控校准，在 134K 全库 I2I 检索上 H@100 相对提升 6.04%。

    Binge Watch: Reproducible Multimodal Benchmark Datasets for Large-Scale Movie Recommendation on MovieLens-10M and 20M

    为 ML-10M/20M 构建可复现多模态基准 M3L（剧情/海报/预告片文本-图像-视频-音频），保留>90%交互并验证音频模态的关键增益。

    IDProxy: CTR Prediction with Multimodal LLMs for Cold-Start Recommendation at Xiaohongshu

    用 MLLM 生成代理 ID 嵌入，经粗到细两阶段对齐工业 CTR 排序器，新笔记在线 AUC 提升约 2 倍于全局流量。

    Learning Sparse Representations of Multimodal Content for Enhanced Cold Item Recommendation

    将多模态内容冷启动表征改为 top-K 稀疏嵌入，并用 α-entmax 预稀疏激活诱导锐化与去噪，冷启动 NDCG@20 提升 16.6%–75.5% 且存储更低。

    A General Framework for Multimodal LLM-Based Multimedia Understanding in Large-Scale Recommendation Systems

    用 1.5B LLaMA2+BLIP-2 将图像转字幕并 token 化为类别特征注入 DLRM 精排，离线 AUC +0.35%、线上 +0.02%，延迟中性。

    CARD: Non-Uniform Quantization of Visual Semantic Unit for Generative Recommendation

    将文本/视觉/协同信号渲染为卡片式视觉语义单元，并用可学习可逆非均匀变换的 NU-RQ-VAE 量化，缓解码本失衡与生成偏置。

    Discrete Preference Learning for Personalized Multimodal Generation

    用模态专属LightGCN+RQ-VAE把协同偏好量化成离散token注入LLM与扩散模型，配合跨模态一致性奖励实现个性化图文生成。

    Dual-Diffusional Generative Fashion Recommendation

    双扩散 Transformer 联合生成时尚单品图像与属性级文本，实现可解释个性化穿搭推荐，PFITB/GOR 双任务全面领先。

    From Raw Features to Effective Embeddings: A Three-Stage Approach for Multimodal Recipe Recommendation

    用 VLM/LLM 摘要 + LightGCN 传播 + 跨视图对比学习三阶段增强多模态特征，全库排序下 Recall@10 提升 7-15%。

    MLLMRec: A Preference Reasoning Paradigm with Graph Refinement for Multimodal Recommendation

    用 MLLM 将图像转语义描述并推理用户偏好画像，配合阈值去噪与拓扑增强精修物品图，三数据集全库排序 SOTA。

    Multi-modal Relational Item Representation Learning for Inferring Substitutable and Complementary Items

    MMSC 融合冻结多模态基座与元路径行为编码器，用对比去噪与 LLM 辅助监督推断替代/互补关系，五数据集提升 26.1%/39.2%。

    Multimodal Large Language Models with Adaptive Preference Optimization for Sequential Recommendation

    面向 MLLM 序列推荐，用难度感知重加权 DPO + 高斯噪声正则分布优化，缓解样本难度失衡与跨模态语义偏差，三数据集 NDCG@3 提升 7.4%–11.0%。

    Robust Multimodal Recommendation via Graph Retrieval-Enhanced Modality Completion

    提出 GRE-MC，用模态感知子图检索+图 Transformer 联合编码+稀疏路由码本补全缺失模态，40% 缺失率下全库排序显著超越 SOTA。

    RQ-GMM: Residual Quantized Gaussian Mixture Model for Multimodal Semantic Discretization in CTR Prediction

    用高斯混合模型替代硬聚类做残差量化，将多模态嵌入离散为语义ID，提升码本利用率与重建精度，线上广告主价值+1.502%

    Structural and Disentangled Adaptation of Large Vision Language Models for Multimodal Recommendation

    提出 SDA 轻量框架，用结构对齐软教师与模态解耦 LoRA 适配 LVLM，在 Amazon 三数据集上 H@10 平均提升 6.15%。

    TimeMM: Time-as-Operator Spectral Filtering for Dynamic Multimodal Recommendation

    将交互时间衰减映射为参数化图算子族，构建轻量谱滤波器组，结合自适应谱滤波与模态路由实现动态多模态推荐，全库排序下全面超越 SOTA。

    Well Begun is Half Done: Training-Free and Model-Agnostic Semantically Guaranteed User Representation Initialization for Multimodal Recommendation

    用交互物品模态特征+聚类全局语义免训练初始化用户表征，弥合用户-物品语义鸿沟，六模型四数据集Recall@5最高提升36.4%。

    Tackling the Modality Inhibitance Effect with Wavelet-based Modality Integration in Multi-modal Recommendation

    提出模态抑制效应(MIE)概念，用Haar小波多分辨率分解提取各模态本质特征、结构感知多模态图学习与交叉加权自适应调节器，在4数据集Full-Ranking下平均提升6.48%。

    Training-free Graph-based Imputation of Missing Modalities in Multimodal Recommendation

    将缺失模态重铸为物品-物品共购图上的图特征插值，提出四种免训练传播式填补算子，可即插即用并保持甚至扩大多模态与传统推荐的性能差距。

    Adopting State-of-the-Art Pretrained Audio Representations for Music Recommender Systems

    系统评测 9 个 MIR 预训练音频表征在 5 类推荐器上的热/冷启动表现，揭示 MIR 性能无法直接迁移到推荐任务。

    Multimodal-enhanced Federated Recommendation: A Group-wise Fusion Approach

    将多模态表征学习卸载至服务器，以组感知聚合+偏好引导蒸馏把多模态语义注入联邦推荐，五数据集全库排序 HR@50 最高提升约 30%。

    Personalized Parameter-Efficient Fine-Tuning of Foundation Models for Multimodal Recommendation

    按兴趣分群并为每群挂载独立 PEFT 模块，使 CLIP 编码出用户条件化的物品表征，配合群内难负采样，NDCG@20 最高提升 15.3%。

    PRISM: Personalized Recommendation via Information Synergy Module

    用 MoE 显式分解模态唯一/冗余/协同信息并以用户偏好动态重加权，即插即用提升三类序列骨干，Yelp N@10 超最强基线 10.91%。
