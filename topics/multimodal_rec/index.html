    🧩 多模态推荐与内容理解 (Multimodal Recommendation)

    研究范畴：视觉-文本-音频特征融合与解耦、多模态图对齐、短视频/微视频推荐与图文电商匹配

    当前方向共收录 129 篇顶会/顶刊论文解读：

    BeFA: A General Behavior-driven Feature Adapter for Multimedia Recommendation

    用行为特征引导的轻量适配器解耦-过滤-重构预训练内容特征，修复信息漂移与遗漏，全库排序下平均提升约 9-11%。

    Beyond Graph Convolution: Multimodal Recommendation with Topology-aware MLPs

    用拓扑剪枝+邻域对齐损失替代GCN消息传递，以MLP建模多模态物品关系，全库排序下Recall@10最高提升7.53%

    Exploiting Fine-Grained Skip Behaviors for Micro-Video Recommendation

    将短视频跳过行为细分为高正/低正/负三级，构建双层正图与分层 BPR 损失，两数据集八项指标全面超越 FRAME 等基线。

    Harnessing Multimodal Large Language Models for Multimodal Sequential Recommendation

    用 MLLM 将商品图转为文本摘要，再以循环式提示推断动态用户偏好，SFT 微调 LLaVA 做多模态序列推荐，AUC 最高提升约 4.3%。

    MENTOR: Multi-level Self-supervised Learning for Multimodal Recommendation

    以 ID 嵌入为锚做四级跨模态分布对齐，叠加特征掩码与图扰动自监督，Amazon 三集 Recall@20 最高提升 74.73%

    Multi-Modal Recommendation Unlearning for Legal, Licensing, and Modality Constraints

    首个多模态推荐遗忘框架 MMRecUn，用反向 BPR 衰减遗忘集、正向 BPR 保真保留集，Recall 最高提升 49.85% 且比从头重训快 1.3 倍。

    STAIR: Manipulating Collaborative and Multimodal Information for E-Commerce Recommendation

    揭示电商场景模态信息弱于协同信号，提出逐步图卷积沿维度分配层权重实现协同-模态共存，并以反向逐步卷积约束更新缓解模态遗忘，三数据集全排序提升2-6%且开销近LightGCN。

    MoToRec: Sparse-Regularized Multimodal Tokenization for Cold-Start Recommendation

    用稀疏正则化 RQ-VAE 将多模态特征离散化为组合语义码，配合稀有度放大与多源图编码，冷启动物品 N@20 最高提升 12.58%。

    Multi-Aspect Cross-modal Quantization for Generative Recommendation

    在 RQ-VAE 量化各层注入跨模态对比与重建对齐，并在 GR 训练中加隐式/显式对齐，Full-Ranking 下 HR@10 最高提升约 9.4%。

    StyleTailor: Towards Personalized Fashion Styling via Hierarchical Negative Feedback

    首个统一个性化服装设计、购物推荐与虚拟试穿的协作智能体框架，以三级分层负反馈闭环迭代优化，在自建 64 样本基准上 Style Consistency 相对基线提升 39.4%。

    ICG: Improving Cover Image Generation via MLLM-based Prompting and Personalized Preference Alignment

    用 MLLM 元令牌+双路适配器把个性化上下文注入扩散模型，并以多奖励对齐实现无标签封面生成，下游 MMGCN 推荐 NDCG@10 提升 19.1%。

    MIRA: Empowering One-Touch AI Services on Smartphones with MLLM-based Instruction Recommendation

    用结构化推理+模板检索增强+前缀树约束解码，把长按图文触发对象映射到预定义手机AI指令，F1较SFT提升约60%。

    Muse: A Multimodal Conversational Recommendation Dataset with Scenario-Grounded User Profiles

    首个多模态对话推荐数据集，用场景锚定用户画像的多智能体框架合成 7K 段图文对话，并验证三种 MLLM 的可学习性。

    PREMISE: Matching-based Prediction for Accurate Review Recommendation

    以多尺度多字段语义匹配分数替代跨模态融合表征，用于多模态评论有用性排序，MAP 较 GBDT 提升 5–17 点且训练提速 42%。

    Re2A: Situated Conversational Recommendation via Rubric-based Preference Reasoning and Alignment

    将情境对话推荐重构为“先推理后对齐”两阶段，用自动评分标准引导偏好状态推理并以异构负例 DPO 实现用户-场景双重对齐，SIMMC 2.1 上 Hit@1 提升 8.17pt。

    ReasonRec: A Reasoning-Augmented Multimodal Agent for Unified Recommendation

    将推荐重构为 Observe-Deliberate-Act 三阶段 CoT 推理智能体，以证据视界课程学习与不确定性引导工具委派，在五数据集四任务上 HR@5 相对提升超 30% 并降低推理延迟。

    Two-Sided State-Space Models for Sequential Recommendation with Non-Random Multimodal Review Feedback

    将评论视为双侧状态空间中的内生事件，用 MNAR 观测模式、非对称评论结转与局部图传播联合演化用户/物品状态，Full-Ranking 下 R@20 较 BSARec 提升 14.8%–18.8%。

    Where and What: Reasoning Dynamic and Implicit Preferences in Situated Conversational Recommendation

    提出 SiPeR 框架，用场景转移估计解决“去哪”与贝叶斯逆向推理解决“要什么”，在 SIMMC 2.1 与 SCREEN 上 R@1 平均提升约 10.9%/10.6%。

    Dual-Phase Playtime-guided Recommendation: Interest Intensity Exploration and Multimodal Random Walks

    用双 Beta 分布解耦游玩时长强弱兴趣，并以多模态随机游走做跨类目探索，在 Steam 数据上同时提升准确率与覆盖度。

    Generating Negative Samples for Multi-Modal Recommendation

    用 MLLM 三步提示生成兼具凝聚力与难度的属性级负样本，并以因果学习解耦关键特征，全库排序下 Recall@10 最高提升 9.02%。

    I$^3$-MRec: Invariant Learning with Information Bottleneck for Incomplete Modality Recommendation

    将各模态视为独立语义环境做 IRM 不变学习，并用 IB 压缩模态特有信息，在模态缺失场景下 Full-Ranking Recall@20 稳定提升 2%–4%。

    Refining Contrastive Learning and Homography Relations for Multi-Modal Recommendation

    用元网络+正交约束精炼多模态对比学习，并补建用户兴趣图与物品共现图，全库排序下 R@20 最高提升约 9.8%。

    Beyond Modality Harmony: Orthogonal Purification and Topology-Guided MoE for Conflict-Aware Multimodal Recommendation

    以纯协同锚点为几何参考轴正交分解并保能截断模态噪声，配合解耦 Sigmoid 路由 MoE 与冲突感知 safe-SSL，在 Amazon 三数据集 8:1:1 划分下 R@20 最高提升 6.55%。

    Beyond Noisy Signals: Dual-Level Denoising for Multi-modal Sequential Recommendation

    图拉普拉斯低通滤波去特征噪声 + FFT 可学习频域滤波去序列噪声，四数据集 Full-Ranking 全面 SOTA，R@20 最高 +19.33%。

    One Graph, Multiple Gains: Single High-Quality Item-Item Graph for Multimodal Recommendation

    构建一次高质量物品-物品图，经三元闭包重加权后复用于表征、交互图与优化三阶段，四数据集全指标SOTA且训练更快更省显存。

    TRU: Targeted Reverse Update for Efficient Multimodal Recommendation Unlearning

    揭示多模态推荐遗忘中排序/模态/模块三层非均匀性，提出门控+分支缩放+参数组隔离的靶向反向更新，逼近重训练前沿且收敛更快。

    A Content-Driven Micro-Video Recommendation Dataset at Scale

    发布十亿级含原始视频模态的微视频推荐数据集 MicroLens，并系统基准 IDRec/VIDRec/VideoRec 三类范式，揭示端到端视频编码优于冻结特征的关键结论。

    BiListing: Modality Alignment for Listings

    用 LLM 生成视觉画像 + PhotoSet Transformer 聚合多图，将 CLIP 图文对齐扩展到多图多文本的房源实体，线上 NDCG +0.425%。

    Distribution-Guided Auto-Encoder for User Multimodal Interest Cross Fusion

    以行为粒度做模态内/模态间交叉融合，并用兴趣分布解码器作自监督约束，工业 A/B 上 CTR +12.9%。

    Do Recommender Systems Really Leverage Multimodal Content? A Comprehensive Analysis on Multimodal Representations for Recommendation

    用受控噪声实验证明多模态增益源于语义而非模型容量，并以 LVLM 结构化提示生成「原生多模态」[EOS] 嵌入替代晚期融合，Borda 聚合排名第一。

    Efficient Multimodal Streaming Recommendation via Expandable Side Mixture-of-Experts

    冻结 BERT/ViT 主干，用可扩展侧调 MoE 增量吸收新时段知识并按利用率剪枝，在三个流式数据集上 HR@10 全面超越 SOTA 且显存/训练时间更省。

    Empowering Large Language Model for Sequential Recommendation via Multimodal Embeddings and Semantic IDs

    揭示 LLM4SR 的嵌入坍缩与语义ID灾难性遗忘，用多模态嵌入+MMD重建+码本初始化破局，全库排序下 nDCG@5 提升 4.4%–10.5%。

    Hypercomplex Prompt-aware Multimodal Recommendation

    用 Cayley-Dickson 超复数多分量嵌入 + 超复数乘法非线性融合 + Prompt 动态补偿，在四个 Amazon 数据集 Full-Ranking 下 Recall@20 最高提升约 13%。

    MISS: Multi-Modal Tree Indexing and Searching with Lifelong Sequential Behavior for Retrieval Recommendation

    用多模态嵌入构建树索引，并以 Co-GSU/MM-GSU 双视角检索终身行为，快手线上召回@800 相对提升 37.9%。

    Modality Alignment with Multi-scale Bilateral Attention for Multimodal Recommendation

    提出 MambaRec，用多尺度空洞卷积+双注意力做局部图文对齐、MMD+InfoNCE 做全局分布对齐，Amazon 三数据集 Recall@20 最高提升约 5.4%。

    Multi-modal Adaptive Mixture of Experts for Cold-start Recommendation

    用双层 MoE（模态专属专家+动态门控融合）替代拼接/平均融合，在 Amazon 三域冷启动全库排序上 Recall@10 最高提升 16.17%。

    Progressive Semantic Residual Quantization for Multimodal-Joint Interest Modeling in Music Recommendation

    提出前缀语义约束的渐进残差量化 PSRQ 与多码本交叉注意力 MCCA，缓解语义漂移与跨模态建模缺口，冷启动 AUC 显著提升并完成工业上线。

    QARM: Quantitative Alignment Multi-Modal Recommendation at Kuaishou

    用业务 item-item 对微调 MLLM 做表示对齐，再以 VQ/RQ 量化成语义码实现端到端可学习，快手广告与电商线上 GMV+2.296%、冷启曝光+5.324%

    BRIDGE: Behavior-Guided Residual Integration with Dual-Frequency Graph Evidence

    揭示跨视图对齐存在有效区间与频谱共享/私有分裂，提出双频图证据+行为符号残差仅在 top-K 候选内校准，Baby/Sports/Electronics 全库排序 R@20 最高提升 7.3%。

    Information-Guided Selective Modality-Interest Alignment for Multimodal Recommendation

    以互信息/条件熵分解为理论视角，用行为校准图精炼+兴趣对比+共享子空间选择性对齐，三数据集 Full-Ranking 全面 SOTA。

    Native Multimodal Representation Learning for Click-Through Rate Prediction in E-Commerce Scenarios

    揭示端到端联合训练在强预训练编码器上失效的根因（CTR 监督多模态不可解释+梯度不一致），提出 Mine-Then-Train 挖掘三元组微调编码器，线上 CTR +1.5%、RPM +0.5%。

    Sequential Modality Dropout for Robust Multi-Modal Sequential Recommendation

    在融合点注入逐样本伯努利模态掩码，四行代码即插即用，使四种多模态序列骨干在模态缺失下 HR@10 留存率提升 1.0–3.2×。

    Sequential Multimodal Evidence Optimization for Product Media Ranking in E-Commerce

    将商品媒体排序建模为证据累积序列决策，两阶段解耦效用学习与生存加权自回归策略，离线 DR-CVR +5.4%、MSC −15.3%。

    Empowering Sequential Recommendation from Collaborative Signals and Semantic Relatedness

    双流 Transformer 分别编码 ID 与内容序列，用用户级/物品级分层对比对齐跨模态语义鸿沟，全库排序下 NDCG@10 最高提升 15.44%。

    TruthSR: Trustworthy Sequential Recommender Systems via User-generated Multimodal Content

    用评论-图片跨模态一致性降噪 + 主观逻辑证据融合做可信序列推荐，四数据集 Full-Ranking 全面超越 MMSRec。

    Are Multimodal Embeddings Truly Beneficial for Recommendation? A Deep Dive into Whole vs. Individual Modalities

    用模态剔除（常量/噪声替换）在14个模型上做受控实证，发现文本主导、图像近乎无效，简单融合基线增益源于架构伪影。

    CAMMSR: Category-Guided Attentive Mixture of Experts for Multimodal Sequential Recommendation

    用类别预测任务引导注意力 MoE 动态分配模态权重，并以模态交换对比学习对齐跨模态序列表征，Full-Ranking 下 NDCG@5 最高提升 15.3%。

    GALA: Generative Aligned Learning for Adaptive Multimodal Representation in the Taobao Shangou Recommender System

    三阶段流水线：行为三元组预训练 + GRPO 生成式行为对齐 + 自适应门控融合，离线 AUC +0.12/+0.20，线上订单量 +0.55%。

    FUSE: Failure-aware Usage of Subagent Evidence for MultiModal Search and Recommendation

    用紧凑 GDR 替代原始图像提示，系统对比 7 种上下文预算策略并以五阶段归因层定位失败，Context Compression 在意图/路由/召回/NDCG@5 全面最优且 p95 延迟降 45%。

    Scaling Multimodal Search and Recommendation with Small Language Models via Upside-Down Reinforcement Learning

    用 Llama-3 合成 5200 万意图-提示对蒸馏进 104M nanoGPT，并以倒置强化学习实现长度/模态可控的多任务提示生成，性能逼近 8B 模型而显存仅 500MB。

    Multimodal Quantitative Language for Generative Recommendation

    用 RQ-VAE 将多域多模态物品翻译为统一量化语言，配合多任务预训练微调实现知识迁移，全库排序下 NDCG@10 最高提升 14.82%。

    Structured Spectral Reasoning for Frequency-Adaptive Multimodal Recommendation

    将多模态图信号分解为等能量频带，用频带掩码一致性训练、低秩超谱算子与谱对比正则实现频率自适应融合，全库排序下冷启动 Recall@20 提升约 10%。

    VisualLens: Personalization through Task-Agnostic Visual History

    用任务无关的日常照片历史构建“图像-描述-方面词”谱系画像，经检索+网格化+联合微调实现个性化推荐，Hit@3 超 UniMP 5-10%。

    Can Complementary Signals Bridge Similarity Islands? Manifold-Augmented Graph Embedding for Multimodal Recommendation

    提出 MAGE，用离线 Soft Conceptor 残差注入 + 在线非对称双流 GNN 桥接互补品“相似性孤岛”，四个 Amazon 数据集 Full-Ranking 全面领先。

    Controllable and Content-Based Recommendations

    用多模态 LLM 将图像/音频/视频条目转述为文本画像，经标签监督与 InfoNCE 对齐冻结 CF 骨干，实现可读可编辑的文本瓶颈控制。

    IntentLens: Grounding Underspecified Multimodal Queries for Recommendation via Tool-Augmented Reasoning

    用 MLLM 工具增强推理将欠指定图文查询接地为结构化意图，再以轻量双塔排序，构建两个新基准并显著超越 MLLM 与检索基线。

    SituRecBench: Evaluating Frontier Models as Situated Recommendation Assistants in 3D Environments

    构建 UE5 三维购物环境与共享第一人称视角的交互式基准，统一评测 VLM 助手的对话质量、推荐效用与导航有效性。

    SynGR: Unleashing the Potential of Cross-Modal Synergy for Generative Recommendation

    用 PID 信息分解揭示多模态生成式推荐的协同信息缺失，提出显著性感知掩码+协同对比学习，Full-Ranking 下平均提升约 10%

    Token-Efficient Item Representation via Images for LLM Recommender Systems

    用单张物品图像替代冗长文本描述作为 LLM 推荐输入，配合 RISA 对齐与 RERI 检索式推荐，在 Amazon 四域上兼顾效率与效果。

    Rethinking Convolutional Networks for Attribute-Aware Sequential Recommendation

    用金字塔式降尺度卷积替代自注意力聚合属性感知序列，线性复杂度下在四个 Amazon 数据集上 HR@10 最高提升 4.08%。

    Collaborative Filtering Meets Spectrum Shift: Connecting User-Item Interaction with Graph-Structured Side Information

    揭示增广图频谱右移现象，提出仅含平移/缩放两因子的 SSC 校正，即插即用提升 LightGCN/JGCF 最高 23%，零额外开销。

    FindRec: Stein-Guided Entropic Flow for Multi-Modal Sequential Recommendation

    用 Stein 核对齐图文与 ID 流分布、MoE 路由动态筛选跨模态信号，Mamba 建模长序列，三数据集 NDCG@5 相对提升 1.4–3.1%。

    LaViC: Adapting Large Vision-Language Models to Visually-Aware Conversational Recommendation
