    研究范畴：图/序列对比数据增广 (SGL/SimGCL)、隐式反馈假阳性噪声过滤 (Denoising) 与鲁棒表征

    Augmenting Sequential Recommendation with Balanced Relevance and Diversity

    提出即插即用平衡增强插件 BASRec，以单序列随机算子+表征级 mixup 与跨序列非线性 mixup 兼顾相关性与多样性，全库排序下 SASRec 平均提升 33.8%。

    Contrastive Representation for Interactive Recommendation

    用偏好排序对比学习(PRCL)为 DRL 交互推荐提炼状态表征，冷启动下样本效率显著提升。

    Disentangled Modeling of Preferences and Social Influence for Group Recommendation

    解耦用户偏好与社会影响的双通道(超)图传播，配合社交重要性引导的对比学习，缓解群组推荐的偏好偏差与数据稀疏。

    From Pairwise to Ranking: Climbing the Ladder to Ideal Collaborative Filtering with Pseudo-Ranking

    用噪声注入构造伪排序并以多序分类排序损失替代成对损失，在四个数据集 Full-Ranking 下 NDCG@10 最高提升 38.9%。

    Future Sight and Tough Fights: Revolutionizing Sequential Recommendation with FENRec

    用时间相关软标签挖掘未来交互、用锚-负混合构造持久困难负样本，四数据集全库排序平均提升 6.16%。

    Lightweight yet Fine-grained: A Graph Capsule Convolutional Network with Subspace Alignment for Shared-account Sequential Recommendation

    用线性注意力胶囊图+低秩子空间对齐，在共享账户混合序列上做细粒度潜在用户解耦，精度大幅领先且参数/耗时更低。

    MENTOR: Multi-level Self-supervised Learning for Multimodal Recommendation

    以 ID 嵌入为锚做四级跨模态分布对齐，叠加特征掩码与图扰动自监督，Amazon 三集 Recall@20 最高提升 74.73%

    Exploiting Inter-Session Information with Frequency-enhanced Dual-Path Networks for Sequential Recommendation

    FreqRec 用可学习复数频域 MLP 双路建模跨会话群体节奏与用户局部高频，并加频域一致性损失，全库排序下 NDCG@10 最高提升 7.38%。

    G-UBS: Towards Robust Understanding of Implicit Feedback via Group-Aware User Behavior Simulation

    用 LLM 群组画像 + 群组感知 GRPO 强化学习为个体隐式反馈去噪，构建 IF-VR 多模态基准，推理准确率提升 14.9%。

    Hard vs. Noise: Resolving Hard-Noisy Sample Confusion in Recommender Systems via Large Language Models

    用 LLM 语义/逻辑双相关性信号区分困难样本与噪声样本，配合目标对齐与图对比抑制幻觉，全库排序下 Recall@20 平均提升约 45%。

    Generating Negative Samples for Multi-Modal Recommendation

    用 MLLM 三步提示生成兼具凝聚力与难度的属性级负样本，并以因果学习解耦关键特征，全库排序下 Recall@10 最高提升 9.02%。

    I$^3$-MRec: Invariant Learning with Information Bottleneck for Incomplete Modality Recommendation

    将各模态视为独立语义环境做 IRM 不变学习，并用 IB 压缩模态特有信息，在模态缺失场景下 Full-Ranking Recall@20 稳定提升 2%–4%。

    Refining Contrastive Learning and Homography Relations for Multi-Modal Recommendation

    用元网络+正交约束精炼多模态对比学习，并补建用户兴趣图与物品共现图，全库排序下 R@20 最高提升约 9.8%。

    Beyond Modality Harmony: Orthogonal Purification and Topology-Guided MoE for Conflict-Aware Multimodal Recommendation

    以纯协同锚点为几何参考轴正交分解并保能截断模态噪声，配合解耦 Sigmoid 路由 MoE 与冲突感知 safe-SSL，在 Amazon 三数据集 8:1:1 划分下 R@20 最高提升 6.55%。

    A Self-Supervised Mixture-of-Experts Framework for Multi-behavior Recommendation

    揭示多行为推荐在已访问/未访问物品上的性能鸿沟，提出双专家 MoE + 专家自适应 SSL（访问过滤/新颖性推断对比 + 行为生成）框架，全库排序下 HR@20 最高提升 65.46%。

    Empowering Denoising Sequential Recommendation with Large Language Model Embeddings

    Generative Data Augmentation in Graph Contrastive Learning for Recommendation

    用 VAE 式生成器自适应生成噪声替代固定随机扰动构造对比视图，并引入物品互补矩阵，在三个稀疏数据集上 Full-Ranking 提升约 3–6%。

    Modality Alignment with Multi-scale Bilateral Attention for Multimodal Recommendation

    提出 MambaRec，用多尺度空洞卷积+双注意力做局部图文对齐、MMD+InfoNCE 做全局分布对齐，Amazon 三数据集 Recall@20 最高提升约 5.4%。

    Multi-Item-Query Attention for Stable Sequential Recommendation

    用多物品查询窗口+虚拟物品替代单查询掩码注意力，缓解序列噪声敏感，ML-1M HR@5 提升 21.2%，LastFM 达 SOTA。

    Do All Nodes Benefit Equally from Knowledge Graphs? Adaptive Node-Aware KG Fusion for Recommendation

    以对抗扰动估计节点级 CF 不稳定性，自适应门控 KG 注入强度并配合自适应对比对齐，四数据集 Full-Ranking 平均排名第一。

    DualSpectralCF: Training-Free Sign-Aware Spectral Collaborative Filtering

    在任意谱滤波骨干上以带符号输入信号与带符号物品算子注入显式负反馈，免训练即插即用，全库排序下 R@20 最高提升 32.6%，比 SIGformer 快 7.7–155.3 倍。

    From Overlooked to Explored: Recovering Item Relations via Mixture of Perspectives for Sequential Recommendation

    揭示自注意力相似性偏置导致异构关系被系统性忽略，提出 K 个视角透镜（亲和/对比双视图）校准注意力，7 个基准全库排序平均提升 3–11%。

    GOD: Enhancing Generalization via Deep Grafting for Sequential Recommendation

    用「嫁接」构造教师条件混合源模型，对学生嵌入表/编码器做组件级蒸馏，Full-Ranking 下最高相对提升 13.92%。

    Information-Guided Selective Modality-Interest Alignment for Multimodal Recommendation

    以互信息/条件熵分解为理论视角，用行为校准图精炼+兴趣对比+共享子空间选择性对齐，三数据集 Full-Ranking 全面 SOTA。

    Neural Tree Collaborative Filtering: Rethinking Graph Collaborative Filtering as Tree Collaborative Filtering with Curvature-Aware Propagation Depth

    Learning Recommender Systems with Soft Target: A Decoupled Perspective

    Post-Training Denoising of User Profiles with LLMs in Collaborative Filtering Recommendation

    DaRec: A Disentangled Alignment Framework for Large Language Model and Recommender System

    Semantic Retrieval Augmented Contrastive Learning for Sequential Recommendation

    用 LLM 语义检索构建用户/物品候选池并配可学习样本合成器，替代随机增广与 K-Means 硬规则，全库排序下 HR@20 最高提升 11.82%。

    Can Recommender Systems Teach Themselves? A Recursive Self-Improving Framework with Fidelity Control

    提出 RSIR 递归自我改进框架，用模型自生成序列+保真度质量控制稠密化稀疏交互，理论证明其等价于流形切向隐式正则，多骨干多数据集 Full-Ranking 下 NDCG/Recall 稳定提升 3%–14%。

    GCIB: Graph Contrastive Information Bottleneck for Multi-Behavior Recommendation

    Rethinking Contrastive Learning for Graph Collaborative Filtering: Limitations and a Simple Remedy

    Towards Automatic Sampling of User Behaviors for Sequential Recommender Systems

    提出 AutoSAM，用轻量采样器+强化学习多目标奖励自适应丢弃低信息历史行为，在四个真实数据集全库排序下 NDCG@10 平均提升约 8%。

    Bridging Textual-Collaborative Gap through Semantic Codes for Sequential Recommendation

    用多视图文本量化语义码作桥梁，以码为 Query 交叉注意力融合文本，配合双重掩码自监督，Full-Ranking 下 R@10 最高提升 20.1%。

    Enhancing Graph Contrastive Learning with Reliable and Informative Augmentation for Recommendation

    用端到端多级向量量化学习离散码，将码作为虚拟邻居与语义正样本构建三重对比视图，Full-Ranking 下 NDCG@10 最高提升 17.5%。

    LightKG: Efficient Knowledge-Aware Recommendations with Simplified GNN Architecture

    MDVT: Enhancing Multimodal Recommendation with Model-Agnostic Multimodal-Driven Virtual Triplets

    用多模态融合表征动态构造虚拟三元组作为额外监督信号，配合三种预热阈值策略与增强 pairwise 损失，即插即用缓解数据稀疏，稀疏用户组 NDCG@10 最高提升 12.85%。

    OmniSage: Large Scale, Multi-Entity Heterogeneous Graph Representation Learning

    统一异构图 GNN、内容特征与用户序列的多任务对比学习框架，支撑 Pinterest 十亿级实体通用表征，线上全站 Repin 提升约 2.5%。

    Online Item Cold-Start Recommendation with Popularity-Aware Meta-Learning

    Shapley Value-driven Data Pruning for Recommender Systems

    Beyond Instance-Level Alignment and Uniformity: Semantic Factor Learning for Collaborative Filtering

    Dynamic Spectral Denoising with Global-Context Attention for Multi-Behavior Recommendation

    沿特征维做 RFFT 学习视图自适应谱调制净化表征，再以净化全局锚做可靠性感知注意力融合，全库排序下 Taobao HR@10 相对提升 26.17%。

    ProEx: A Unified Framework Leveraging Large Language Model with Profile Extrapolation for Recommendation

    VI-MMRec: Similarity-Aware Training Cost-free Virtual User-Item Interactions for Multimodal Recommendation

    Decoupled Entity Representation Learning for Pinterest Ads Ranking

    提出解耦式上游-下游实体表征框架 DERM，三塔+对比自监督+滑动平均聚合，离线 AUC 提升 0.19%、线上 CTR +1.38%、CPA -1.61%

    SGCL: Unifying Self-Supervised and Supervised Learning for Graph Recommendation

    Distribution-Level Contrastive Supervision for Generative Recommendation

    Data Augmentation as Free Lunch: Exploring the Test-Time Augmentation for Sequential Recommendation

    Disentangling and Generating Modalities for Recommendation in Missing Modality Scenarios

    Intent Representation Learning with Large Language Model for Recommendation

    Intent-aware Diffusion with Contrastive Learning for Sequential Recommendation

    Invariance Matters: Empowering Social Recommendation via Graph Invariant Learning

    Squeeze and Excitation: A Weighted Graph Contrastive Learning for Collaborative Filtering

    仅扰动末层GCN视图并用SENet动态加权特征，在三个数据集上实现最高24.45%的NDCG@20提升。

    AsarRec: Adaptive Sequential Augmentation for Robust Self-supervised Sequential Recommendation

    将五种序列增强统一为半双随机变换矩阵，用可微 Semi-Sinkhorn 学习用户自适应增强，四数据集全排序下 HR/NDCG 平均提升约 7-8%。

    Differentiable Semantic ID for Generative Recommendation

    用 Gumbel 噪声+不确定性衰减实现可微语义ID联合训练，Leave-One-Out 全库排序下 R@10 相对 TIGER 提升约 12%。

    Divergence Meets Consensus: A Multi-Source Negative Sampling Framework for Sequential Recommendation

    借鉴 ZPD 理论构建 Teacher-Peer-Self 多源负采样，用分歧重排提升多样性、共识蒸馏复用打分开销，六数据集全库排序下 Recall@20 最高提升 27.3%。

    Don't Contrast the Impossible: Region-Constrained Batching for Contrastive User Modeling on a Local Community Platform

    识别地理约束下 in-batch 负样本中的“不可能负样本”问题，提出区域同质批采样 RCBS，仅改批构造即显著提升用户表征与线上指标。

    FLAME: Condensing Ensemble Diversity into a Single Network for Efficient Sequential Recommendation

    用冻结+可学习双网络的子模块组合模拟指数级集成多样性，推理仅用单网络，NDCG@20 最高提升 9.70% 且收敛快 7.69 倍。

    From Raw Features to Effective Embeddings: A Three-Stage Approach for Multimodal Recipe Recommendation

    用 VLM/LLM 摘要 + LightGCN 传播 + 跨视图对比学习三阶段精炼食谱多模态特征，Full-Ranking 下 Recall@10 提升 7–15%。

    Multi-modal Relational Item Representation Learning for Inferring Substitutable and Complementary Items

    融合多模态基础模型与元路径行为编码，以自监督对比去噪与 LLM 校验弱监督推断可替代/互补关系，M@10 平均提升 26.1%/39.2%。

    QAGCF: Graph Collaborative Filtering for Q&A Recommendation

    将问答对解耦为用户-问题/用户-答案双协同图与问题-答案/问题-问题双语义图，融合为全局异质图后用 Jacobi 多项式图滤波器分离高低频信号，配合噪声对比学习，在知乎与商业数据集 Full-Ranking 下 Recall@10 提升 5.16%–5.34%。

    ReST: A Plug-and-Play Spatially-Constrained Representation Enhancement Framework for Local-Life Recommendation

    以物品为中心，用属性语义预热+空间约束难负采样对比学习增强长尾物品ID表征，离线AUC最高+5.90%，线上GMV+2.804%。
