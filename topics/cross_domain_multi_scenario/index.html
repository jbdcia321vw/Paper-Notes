    🌐 跨域与多场景推荐 (Cross-Domain & Multi-Scenario Recommendation)

    研究范畴：跨域知识迁移 (CDR)、重叠/非重叠用户对齐、多业务场景联合建模 (STAR/PEPNet 等)

    当前方向共收录 72 篇顶会/顶刊论文解读：

    Behavior Importance-Aware Graph Neural Architecture Search for Cross-Domain Recommendation

    用一次性免重训超网为各域定制 GNN 架构，并以双层隐式梯度学习源域行为重要性权重，Amazon 与微信广告数据 AUC 最高提升 10.57%。

    One for Dozens: Adaptive REcommendation for All Domains with Counterfactual Augmentation

    用分层专家+彩票假设掩码剪枝为数十域学专属子网，并以流行度反事实增强少数域，DomainAUC 提升 2‰~8.4‰。

    From IDs to Semantics: A Generative Framework for Cross-Domain Recommendation with Adaptive Semantic Tokenization

    用领域自适应语义ID分词+对称动态路由的生成式跨域推荐框架，Leave-Last-Out全库排序下全面超越SOTA。

    Tokenize Once, Recommend Anywhere: Unified Item Tokenization for Multi-domain LLM-based Recommendation

    提出 TokenMoE+码本+互信息校准的统一物品分词框架 UniTok，单模型跨 10 域训练，NDCG@10 最高提升 51.89%，参数量降 9.63×。

    HORIZON: A Benchmark for In-the-wild User Behaviour Modeling

    重构 Amazon Reviews 为 54M 用户跨域长程基准，提出时间-用户双轴四象限评估与 LLM 查询改写/长程建模任务，揭示 ID 模型在时间外推下崩塌。

    Leveraging Multimodal Data and Side Users for Diffusion Cross-Domain Recommendation

    用 MLLM 抽取多模态特征做初步对齐，再以边侧用户+重叠用户两阶段扩散生成目标域冷启动用户向量，Amazon 三任务 MAE 最高降 13.6%。

    A Soft-partitioned Semi-supervised Collaborative Transfer Learning Approach for Multi-Domain Recommendation

    用软分区动态参数缓解主导域压制、用主导域伪标签加权迁移缓解稀疏域过拟合，离线全库AUC与美团线上A/B双验证。

    Benefit from Rich: Tackling Search Interaction Sparsity in Search Enhanced Recommendation

    用 LLM+RQ-VAE 将用户搜索/推荐偏好离散为码本，构建 User-Code 图做消息传递，把搜索富用户信号传给稀疏用户，Qilin 上 HR@1 相对 UniSAR 提升 12.1%。

    Global-Distribution Aware Scenario-Specific Variational Representation Learning Framework

    用变分推断为每个场景下的用户/物品学习分布表征，并以全局行为模式与物品属性构造先验，缓解稀疏场景表征欠学习，即插即用提升 PEPNet/MARIA。

    Scenario-Wise Rec: A Multi-Scenario Recommendation Benchmark

    首个多场景推荐统一基准，整合 6 个公开数据集与 12 个 MSR 模型，统一数据处理/训练/评测管线并附工业广告数据验证。

    A Dual-Expert Strategy Integrating LLMs to Mitigate Negative Transfer in Cross-Domain Sequential Recommendation

    用域门控双专家+物品级注意力掩码+双池负采样对比学习，抑制 LLM 跨域序列推荐中的负迁移，10 域上超越 26 个基线，线上 CTR 相对提升 47.6%。

    Cross-Country Code-Mixing for Generative Recommendation

    借鉴多语言 code-switching，用双约束 token 级跨国混码合成混合序列并做上下文自适应重加权，在无重叠 ID 的跨国场景显著提升小国召回。

    Cross-Domain Sequential Recommendation with Representation-Level User Transfer

    仅通过用户表征级迁移实现跨域序列推荐，融合层注入源域用户向量，兼容纵向联邦与部分重叠用户，全库排序下 NDCG@10 提升 7.4–24.1%。

    FedCGR: Federated Cross-Domain Generative Recommendation

    以固定 SID 词表为跨域通信接口，用可靠性感知 CF 残差与原型个性化聚合解决联邦生成式 CDR 的语义瓶颈与负迁移，全库排序下显著超越联邦生成基线。

    LFM4Ads: Large Foundation Model for Ads Recommendation

    腾讯广告提出预训练-迁移范式，联合迁移用户/物品/交叉表征，以时间感知EMA聚合样本级CR解耦上游推理，三级粒度下游复用，离线AUC+0.0189、线上GMV+2.45%。

    TransRetrieval: Scaling Up Transformer-Based Retrieval for Industrial Recommendation

    用加权平均聚合+目标Token压缩+位置式域嵌入，让Transformer在召回阶段实现对数线性Scaling，线上收入+2.53%。

    UniScale: Synergistic Entire Space Data and Model Scaling for Search Ranking

    提出数据-架构协同缩放框架：ES³全空间样本系统扩展训练信号，HHSFT异构分层Transformer吸收跨域分布，离线AUC+1.14%、线上GMV+2.04%。

    A Unified Framework for Adaptive Representation Enhancement and Inversed Learning in Cross-Domain Recommendation

    解耦共享/专属表征，用 LightGCN 域内增强 + 自注意力跨域自适应融合 + GRL 逆向约束，全库排序下 Recall@20 最高提升 8.31%。

    Cross-Domain Causal Preference Learning for Out-of-Distribution Recommendation

    用域对抗抽取域共享偏好、DAG 学习潜属性因果结构，缓解目标域稀疏下的 OOD 泛化，OOD 测试 HR@10 提升约 2-6%。

    Personalized Multi-Interest Modeling for Cross-Domain Recommendation to Cold-Start Users

    用归一化流增强神经过程，将单峰高斯先验转为多峰分布以建模用户多兴趣，并引入偏好池捕获跨用户共同偏好，五场景 MAE 平均降约 45%。

    Adversarial Alignment and Disentanglement for Cross-Domain CTR Prediction with Domain-Encompassing Features

    提出 A²DCDR，用 DC-MMD 对抗对齐 + CLUB 互信息解耦 + 特征重构，保留域不变与有价值非对齐特征，四组 Amazon 场景 HR@10 最高 +6.96，线上 CTR +7.18%。

    User Representation via Cross Multi-source Behavior Pre-training for Mobile Games

    面向设备级多源多粒度行为日志，提出跨源级联掩码预训练 CM-PTM，以源→类目→App→操作逐级预测统一建模跨源依赖，离线 AUC 提升 1.05%–2.85%，线上 A/B 提升 1.28%。

    Effective Two-Stage Knowledge Transfer for Multi-Entity Cross-Domain Recommendation

    提出 MKT 两阶段多实体知识迁移框架，用异构特征对齐与极化分布损失解决异质特征 schema 下的负迁移，线上 CTR +4.13%。

    Exploring Preference-Guided Diffusion Model for Cross-Domain Recommendation

    用源域交互历史构造偏好引导信号，逐步注入扩散逆向过程生成目标域冷启动用户表征，三场景 MAE 最高降 32.60%。

    Measure Domain's Gap: A Similar Domain Selection Principle for Multi-Domain Recommendation

    用原型距离+bandit动态为每个域挑选相似域子集，解耦共享专家以缓解多域推荐负迁移，三数据集AUC稳定提升。

    PERSCEN: Learning Personalized Interaction Pattern and Scenario Preference for Multi-Scenario Matching

    用用户专属特征图 + VQ 码本蒸馏场景感知偏好 + 渐进式 GLU 融合，在 KuaiRand/Alimama 四场景召回上全面超越 ADIN/SASS/M5。

    Revisiting Self-attention for Cross-domain Sequential Recommendation

    将跨域序列推荐重构为推荐损失与跨域注意力抑制的双目标帕累托优化，以即插即用方式改造自注意力，平均提升 Recall@10 达 9.8%/16.0%。

    Atomic Intent Reasoning: Bringing LLM Semantics to Industrial Cross-Domain Recommendations

    将 LLM 意图推理离线化为原子行为-意图对缓存，在线经意图树构建与目标感知检索实现约 400× 加速，快手 A/B 测试 GMV +3.446%。

    MergeRec: Model Merging for Data-Isolated Cross-Domain Sequential Recommendation

    提出数据隔离跨域序列推荐新设定，用任务向量模型合并+伪用户数据+推荐/蒸馏联合目标，Recall@10 平均提升 17.21%。

    Meta Lattice: Model Space Redesign for Cost-Effective Industry-Scale Ads Recommendations

    以模型空间重构统一碎片化广告组合，融合归因窗口混合、帕累托特征选择与推理期知识迁移，线上Topline +10%、容量省20%。

    Sharpness-aware Model Merging with Salience Recovery for LLM-based Cross-Domain Sequential Recommendation

    用锐度感知平坦极小值对齐 + 重尾重参数化恢复显著偏好信号，破解 LLM 跨域序列推荐模型合并中的参数冲突与多域饱和瓶颈。

    Affect-aware Cross-Domain Recommendation for Art Therapy via Music Preference Elicitation

    以音乐偏好诱导替代纯视觉诱导，提出 Mozart/Haydn/Salieri 三种情感感知跨域艺术治疗推荐，200 人用户研究验证情绪改善。

    Heterogeneous User Modeling for LLM-based Recommendation

    用压缩提示+[USER]锚点token将跨域异构行为压成单一用户表征，并以域重要性平滑加权缓解域跷跷板，六域全库排序R@10最高提升约30%。

    Impacts of Mainstream-Driven Algorithms on Recommendations for Children Across Domains: A Reproducibility Study

    跨电影/音乐/图书三域复现儿童与主流用户偏好偏差，并引入流行度偏差指标，揭示推荐算法对儿童群体的域特异性失效。

    Leave No One Behind: Fairness-Aware Cross-Domain Recommender Systems for Non-Overlapping Users

    为无源域数据的非重叠用户生成虚拟源域画像，双注意力+限制器实现模型无关的跨域公平性纠偏，UGF最高降94.13%且整体精度不降。

    RankGraph: Unified Heterogeneous Graph Learning for Cross-Domain Recommendation

    构建跨产品异构异质图，用 GPU 加速 RGCN + 对比学习产出图 token 注入推荐基础模型，线上 CTR +0.92%、CVR +2.82%。

    Zero-shot Cross-domain Knowledge Distillation: A Case study on YouTube Music

    用 YouTube 视频大教师零样本蒸馏到低流量 YouTube Music 双排序模型，离线 AUC 微增但线上新发内容互动 +11.39%。

    Empowering Cross-Domain Sequential Recommendation with Hybrid Tokenization and Serial-Parallel Decoding

    跨域共享-专属多塔 RQ-VAE 混合分词 + 两段式串并解码，Leave-One-Out 全库排序下精度 +1.5%、时延 -85.1%。

    Adaptive Domain Scaling for Personalized Sequential Modeling in Recommenders

    用域特征动态生成序列物品的个性化MLP权重与候选物品的多查询表示，改造目标注意力实现多域序列建模，抖音双场景线上GMV+0.79%、ADVV+1.00%。

    Adaptive Graph Integration for Cross-Domain Recommendation via Heterogeneous Graph Coordinators

    用异质自适应图协调器把多域图拼成统一结构做多域预训练，再以图提示迁移到目标域，Full-Ranking 下全面超越 9 个基线。

    AgentCF++: Memory-enhanced LLM-based Agents for Popularity-aware Cross-domain Recommendations

    以双层记忆+两步融合+兴趣组共享记忆，令 LLM 用户智能体在跨域场景显式建模流行度影响，采样排序 MRR 平均超 AgentCF 14.6%。

    Bridge the Domains: Large Language Models Enhanced Cross-domain Sequential Recommendation

    用 LLM 语义嵌入+分层画像桥接跨域物品与用户偏好，破解重叠困境与转移复杂性，三数据集 H@10 最高提升 31.7%。

    CDC: Causal Domain Clustering for Multi-Domain Recommendation

    用孤立/混合双亲和矩阵+因果发现系数自适应融合，联合优化目标域簇与训练源域集，50+域上DomainAUC提升4.14‰/6.76‰，线上eCPM+4.9%

    Learning Universal User Representations Leveraging Cross-domain User Intent at Snapchat

    将 Snapchat 多业务面事件拼接为统一序列训练 Transformer 用户塔，产出跨域通用用户表征，线上多场景 A/B 全面正向。

    X-Cross: Dynamic Integration of Language Models for Cross-Domain Sequential Recommendation

    逐层动态集成多个 LoRA 源域语言模型，仅用 25% 参数与 50-75% 更少微调数据即达/超 LoRA 跨域序列推荐效果。

    Bridging Behavior and Semantics for Time-aware Cross-Domain Sequential Recommendation

    用神经 ODE 解耦长短期行为、LLM 离散时间 token 反事实增强语义、门控自适应域迁移，1:999 采样排序下 MRR 最高提升 30.5%。

    FedMM: Federated Collaborative Signal Quantization for Multi-Market CTR Prediction

    用双层 RQ-VAE 码本作联邦传输介质，对齐跨市场不相交 ID 空间，AUC 全面超越本地/联邦基线且通信量降 20×。

    LLM-EDT: Large Language Model Enhanced Cross-domain Sequential Recommendation with Dual-phase Training

    用可迁移物品增广+双阶段训练+域感知画像，缓解CDSR域不平衡与域迁移难题，全库排序下H@10最高提升26.96%

    Reinforcing User Interest Evolution in Multi-Scenario Learning for recommender systems

    用 Double Q-learning 估计场景级行为置信度作为门控，加权三元组对比损失以抑制多场景负迁移，KuaiSAR 全库排序 N@20 提升约 3.3 倍。

    Universal Item Tokenization for Transferable Generative Recommendation

    用 MLLM+树状码本构建跨域通用物品分词器，结合内容重建与共现协同对齐，实现可迁移生成式推荐，全库排序下全面超越基线。

    MARCO: A Cooperative Knowledge Transfer Framework for Personalized Cross-domain Recommendations

    将多源跨域推荐建模为协作式多智能体强化学习，每源域一个 Agent 估计贡献并加熵正则，冷启动 MAE 最高降 32.6%。

    Automated Prompting for Non-overlapping Cross-domain Sequential Recommendation

    用可学习连续 Prompt（域无关+域特定+冻结标签）替代域对齐约束，实现无重叠实体、仅隐式反馈的双目标跨域序列推荐，Movie-Book 上 HR@10 相对最优基线提升约 17.8%。

    Federated User Preference Modeling for Privacy-Preserving Cross-Domain Recommendation

    用评论+潜在正物品挖掘综合偏好，再以 LDP 原型经联邦聚合跨域迁移，四组 CDR 任务 HR@10 平均提升约 13%。

    A Unified Framework for Multi-Domain CTR Prediction via Large Language Models

    用 LLM 分层语义表征作跨域共享底座、可插拔 DSN 建模域特性，掩码损失解耦梯度，AUC 相对提升 24%–63% 并支持零样本新域。

    Causal Deconfounding via Confounder Disentanglement for Dual-Target Cross-Domain Recommendation

    显式解耦单域/跨域观测混杂因子，经后门调整保留正向效应并消除负向偏差，七数据集 HR@10 平均提升 6.17%。

    Coherence-guided Preference Disentanglement for Cross-domain Recommendations

    用全局-局部图 + 一致性约束抽取跨域共享物品属性，并以流行度加权 Softmax 将共享用户偏好解耦为兴趣/从众，六组双目标 CDR 任务 HR@10 最高提升约 37%。

    Federated Semantic Learning for Privacy-preserving Cross-domain Recommendation

    提出 FFMSR，用多层 PLM+MoE 提取语义、服务器端聚类融合跨域语义、FFT 滤波去噪，在完全非重叠联邦场景下 Full-Ranking 提升 1.4%–5.6%。

    One Model for All: Large Language Models are Domain-Agnostic Recommendation Systems

    用 LLM 编码跨域混合标题序列实现域无关推荐，采样 1000 负例评测，SPIAO 上较最优基线相对提升约 19%。

    Causal-Invariant Cross-Domain Out-of-Distribution Recommendation

    统一建模跨域与单域双重分布偏移，用双层因果结构与 LLM 引导混杂因子发现实现跨域 OOD 推荐，HR@10 平均提升 6.34%。

    Review-Based Hyperbolic Cross-Domain Recommendation

    将评论文本嵌入双曲空间做跨域推荐，用度数归一化与尺度对齐避免域对齐引发的层级坍塌，NDCG@10 较 SER 提升约 10.4%。

    Towards Personalized Federated Multi-Scenario Multi-Task Recommendation

    首个联邦多场景多任务推荐框架 PF-MSMTrec，通过专家参数解耦、联邦批归一化与冲突协调缓解数据/模型/任务三级冲突，AliExpress 与 Tenrec 上 CTR/CTCVR AUC 全面超越 SOTA。

    Automated Information Flow Selection for Multi-scenario Multi-task Recommendation

    用 LoRA 解耦四类场景-任务信息单元并以可学习掩码剪枝无效信息流，AUC 全面超越 HiNet/M3oE，线上 CVR 均涨 2.46%。

    ABXI: Invariant Interest Adaptation for Task-Guided Cross-Domain Sequential Recommendation

    用任务引导对齐消除预测错配，并以 dLoRA/iLoRA 双 LoRA 抽取域不变兴趣，三数据集 MRR 大幅超越 CDSR 基线。

    Image Fusion for Cross-Domain Sequential Recommendation
