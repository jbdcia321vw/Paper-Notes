    🗣️ 对话推荐与智能体仿真 (Conversational & Agentic Recommendation)

    研究范畴：多轮主动追问对话推荐 (CRS)、基于 LLM Agent 的用户行为模拟沙盒、可解释性推荐理由生成

    当前方向共收录 116 篇顶会/顶刊论文解读：

    LLM-Powered User Simulator for Recommender System

    用 LLM 离线蒸馏物品优缺点关键词，构建关键词匹配+语义相似+序列统计三模型集成用户模拟器，为 RL 推荐提供可解释高保真环境。

    Contextualizing Recommendation Explanations with LLMs: A User Study

    预注册在线实验(N=759)+访谈(N=30)对比无解释/通用解释/情境化解释，情境化解释显著提升认知需求与观看意愿，但对功利/情感需求增益有限。

    RecToM: A Benchmark for Evaluating Machine Theory of Mind in LLM-based Conversational Recommender Systems

    首个面向对话推荐场景的人类标注 ToM 基准，从认知推断与行为预测两维评估 LLM，揭示细粒度意图与谄媚偏差瓶颈

    Seeking Help, Facing Harm: Auditing TikTok's Mental Health Recommendations

    30个LLM智能体7天控制审计TikTok推荐流，揭示交互行为主导心理健康内容曝光、求助意图无法形成安全边界。

    StyleTailor: Towards Personalized Fashion Styling via Hierarchical Negative Feedback

    首个统一个性化服装设计、购物推荐与虚拟试穿的协作智能体框架，以三级分层负反馈闭环迭代优化，在自建 64 样本基准上 Style Consistency 相对基线提升 39.4%。

    When Top-ranked Recommendations Fail: Modeling Multi-Granular Negative Feedback for Explainable and Robust Video Recommendation

    三智能体协同建模多粒度负反馈，S-GRPO 渐进奖励实现可解释视频推荐，线上快滑率降 9.4%

    A Survey on LLM-powered Agents for Recommender Systems

    系统综述 LLM Agent 推荐的三范式（推荐/交互/仿真）与四模块架构，梳理数据集与评测协议并指出统一评测缺失。

    Empowering Retrieval-based Conversational Recommendation with Contrasting User Preferences

    用 LLM 抽取并扩增 like/dislike 对比偏好，以三路相似度线性打分做稠密检索式对话推荐，INSPIRED 上 Recall@10 相对提升 99.72%。

    Enhancing Recommendation Explanations through User-Centric Refinement

    提出 RefineX 多智能体推理期精炼框架，以 plan-then-refine 与分层反思将 PETER 解释在事实性/个性化/连贯性三维度大幅提升。

    Exploring the Potential of LLMs as Personalized Assistants: Dataset, Evaluation, and Analysis

    提出 HiCUPID 个性化助手基准（1.5k 合成用户、17k token 长对话、单/多跳 QA），并蒸馏 Llama-3.2 评估器对齐人类偏好，揭示 SFT+DPO 最优而纯 DPO 崩溃。

    iAgent: LLM Agent as a Shield between User and Recommender Systems

    提出 user-agent-platform 新范式，用个体指令感知 LLM Agent 在用户与平台间做重排护盾，四数据集平均提升 16.6%。

    Muse: A Multimodal Conversational Recommendation Dataset with Scenario-Grounded User Profiles

    首个多模态对话推荐数据集，用场景锚定用户画像的多智能体框架合成 7K 段图文对话，并验证三种 MLLM 的可学习性。

    PersonaX: A Recommendation Agent Oriented User Modeling Framework for Long Behavior Sequence

    面向推荐智能体的离线多画像用户建模框架，用聚类+原型-多样性均衡采样压缩长行为序列，30-50%数据即超越全量基线并大幅降低在线延迟。

    Q-STRUM Debate: Query-Driven Contrastive Summarization for Recommendation Comparison

    用双人格辩论式提示替代单次摘要，为查询驱动的推荐对比摘要注入对比性与多样性，在酒店/餐厅/旅游三域 Win Rate 最高达 89%。

    Refining Text Generation for Realistic Conversational Recommendation via Direct Preference Optimization

    用 DPO 对齐 LLM 生成的对话摘要与物品推荐信息，使评分器更准，Tabidachi 上 HR@1 提升 21.3%。

    Stereotype or Personalization? User Identity Biases Chatbot Recommendations

    揭示 LLM 聊天机器人无论用户显式还是隐式透露种族身份都会产生刻板推荐，且在被追问时系统性掩盖种族影响，跨 7 个主流模型、4 个种族、12 万条合成请求验证。

    Towards Personalized Conversational Sales Agents: Contextual User Profiling for Strategic Action

    提出 CSALES 对话销售任务与 CSUSER 真实画像用户模拟器，CSI 智能体通过上下文画像驱动统一动作空间，SR 提升约 15-20pt、SWR 提升约 5-10pt。

    TripTailor: A Real-World Benchmark for Personalized Travel Planning

    构建50万真实POI与近4000条真人行程的个性化旅行规划基准，提出可行性/合理性/个性化三维评估与奖励模型对比框架，揭示SOTA LLM行程超越真人比例不足10%。

    Decisive: Guiding User Decisions with Optimal Preference Elicitation from Unstructured Documents

    将决策解耦为文档客观打分矩阵与贝叶斯偏好推断，用决策感知信息增益主动提问，Top-1 准确率最高提升约 20%。

    From Recall to Forgetting: Benchmarking Long-Term Memory for Personalized Agents

    提出 Memora 长周期记忆基准与 FAMA 遗忘感知指标，揭示 LLM 与记忆智能体在记忆突变下频繁复用失效记忆。

    HARPO: Hierarchical Agentic Reasoning for User-Aligned Conversational Recommendation

    将对话推荐重构为多维质量驱动的结构化决策，用分层偏好奖励引导树搜索推理，ReDial R@10 达 29.8%（+18.7%）。

    Intent-Driven Semantic ID Generation for Grounded Conversational News Recommendation

    用 LLM 直接生成三层语义 ID 前缀再模糊匹配新闻池，结构上消除幻觉，冷启动 L1 达 18.0%，延迟 85ms。

    Mirroring Users: Towards Building Preference-aligned User Simulator with User Feedback in Recommendation

    用 LLM 生成 EKB 决策过程作澄清、按认知不确定性蒸馏并拒绝采样去噪，微调 3B 模拟器在 8 域上超越 GPT-5 与教师模型。

    Re2A: Situated Conversational Recommendation via Rubric-based Preference Reasoning and Alignment

    将情境对话推荐重构为“先推理后对齐”两阶段，用自动评分标准引导偏好状态推理并以异构负例 DPO 实现用户-场景双重对齐，SIMMC 2.1 上 Hit@1 提升 8.17pt。

    RecToolBench: Benchmarking Recommendation-Specific Tool Orchestration under Fuzzy User Intent

    首个基于 MCP 的模糊意图推荐工具编排基准，1288 条四级难度可执行任务，揭示语法合法≠推荐成功的执行-结果鸿沟。

    ReRec: Reasoning-Augmented LLM-based Recommendation Assistant via Reinforcement Fine-tuning

    用双图奖励塑形、推理感知优势估计与在线课程调度改造 RFT，使 3B LLM 在复杂查询推荐上大幅超越 GRPO 系基线并保留通用能力。

    Towards Effective Structured Context Modeling for Conversational Recommender Systems via Dual-node Monte Carlo Tree Search

    将对话上下文建模为双节点 MCTS 树，ELNode 搜索追问动作、EXNode 精炼检索查询，Redial/OpenDialKG 上 SR 平均提升 9.07%。

    Where and What: Reasoning Dynamic and Implicit Preferences in Situated Conversational Recommendation

    提出 SiPeR 框架，用场景转移估计解决“去哪”与贝叶斯逆向推理解决“要什么”，在 SIMMC 2.1 与 SCREEN 上 R@1 平均提升约 10.9%/10.6%。

    STARec: An Efficient Agent Framework for Recommender Systems via Autonomous Deliberate Reasoning

    将每位用户建模为具备快/慢双认知的 LLM Agent，用 SFT 蒸馏 + GRPO 排序奖励两阶段训练，仅用 0.4% 数据即在 ML-1M/CDs 上超越全量训练基线。

    STEP: Stepwise Curriculum Learning for Context-Knowledge Fusion in Conversational Recommendation

    用三阶段课程学习驱动 F-Former 对齐对话与知识图谱，再以双前缀提示注入冻结 PLM，ReDial R@1 提升 15.7%。

    Temporal-Aware User Behaviour Simulation with Large Language Models for Recommender Systems

    用动态画像更新、时序模式抽取与自适应聚合构建 LLM 用户模拟器，在 ML-1M 上 nDCG@5 相对 RecAgent 提升约 27.8%。

    A Behavioral Trait Leaks into Preferences: Diagnosing Trait Interference in LLM User Simulators

    揭示 LLM 用户模拟器中活跃度特质干扰偏好边界并导致评估失效，提出页面级质量锚点 PQA 恢复特质独立性。

    Ask to Be Sure: Informative Interactions for Confident Multi-Turn LLM Recommendation

    以推荐列表采样熵的下降量作为信息增益奖励，免真值微调 LLM 多轮对话策略，INSPIRED/ReDial 上 Hit 与对话效率双升。

    From Counterfactual Edits to Human Narratives: LLM-Driven Interpretations for Recommender System Explanations

    用 LLM 将冗长反事实编辑列表摘要为高层偏好叙事，并以人类校准指标评估正确性/信息量/语言质量。

    On Mitigating Data Sparsity in Conversational Recommender Systems

    DACRS 用 LLM 两阶段对话增强 + KG 实体替换与相似度约束 + 对话引导注意力融合，缓解对话与实体双重稀疏，ReDial R@50 提升 11.46%。

    Retrieval, Scoring, and Decoding Shape Performance and Stability in LLM-based Conversational Recommendation

    在 ReDial 上系统解耦候选池规模、一阶段检索器与解码温度对 LLM 重排器的影响，揭示协议选择可移动 NDCG@10 超过模型差距。

    Curr-RLCER: Curriculum Reinforcement Learning For Coherence Explainable Recommendation

    用三阶段课程强化学习（CTR→评分→解释生成）训练 LLM，并设计一致性奖励与评估方案，使解释与评分双向对齐。

    Improving Conversational Recommendation with Contextual Adaptation of External Recommenders and LLM-based Reranking

    用轻量实体级序列推荐器产出候选、LLM 做上下文适配重排，ReDial/INSPIRED 上 H@5 平均提升 54%/25%。

    Interplay: Training Independent Simulators for Reference-Free Conversational Recommendation

    训练独立用户/推荐双模拟器，以目标属性替代目标物品消除 oracle 泄漏，8B 模型 Recall@1 超 32B 基线 15 倍。

    UserSimCRS v2: Simulation-Based Evaluation for Conversational Recommender Systems

    升级对话推荐用户模拟评测工具包，引入 LLM 模拟器、统一数据格式与 LLM-as-a-Judge 指标，案例揭示模拟器间系统排序显著分歧。

    Bi-NAS: Towards Effective and Personalized Explanation for Recommender Systems via Bi-Level Neural Architecture Search

    用双层 NAS 自动搜索交叉注意力与特征交互算子，再以零样本 LLM 提示生成个性化解释，四数据集上推荐与解释指标双优。

    FUSE: Failure-aware Usage of Subagent Evidence for MultiModal Search and Recommendation

    用紧凑 GDR 替代原始图像提示，系统对比 7 种上下文预算策略并以五阶段归因层定位失败，Context Compression 在意图/路由/召回/NDCG@5 全面最优且 p95 延迟降 45%。

    PersoPilot: An Adaptive AI-Copilot for Transparent Contextualized Persona Classification and Personalized Response Generation

    双模式智能体 Copilot：PersoAgent 做上下文人格抽取与社区推荐，Analytic Tools 用 Phi-4-mini+TF-IDF 主动学习闭环做可解释人格分类，UniEval 四维均分 0.84–1.0。

    Reasoning over User Preferences: Knowledge Graph-Augmented LLMs for Explainable Conversational Recommendations

    COMPASS 用图实体描述预训练+知识感知指令微调，让 LLM 生成可解释文本偏好摘要并以门控注入现有 CRS，ReDial/INSPIRED 上 HR@10 最高提升 44.76%。

    An Efficient and Effective Agentic Group Shilling Attack on Recommender Systems

    提出协调者驱动的角色切换多智能体群体托攻击框架 AGAS，黑盒免训练、动态策略，HR@10 相对提升 155%–198% 且显著削弱检测器。

    AgentRecBench: Benchmarking LLM Agent-based Personalized Recommender Systems

    首个 LLM 智能体推荐系统基准，构建 U-R-I 文本交互环境与三类场景，揭示结构化工作流智能体显著优于传统与朴素 Agent。

    Context Steering: Controllable Personalization at Inference Time

    免训练解码期个性化：用有/无上下文两次前向的似然差线性缩放上下文影响力，实现可控个性化推荐与贝叶斯意图反演。

    Enhancing Personalized Multi-Turn Dialogue with Curiosity Reward

    将用户模型信念增益作为 PBRS 内在奖励注入多轮 RLHF，使 LLM 主动探询用户属性，习题推荐成功率 54%→87.5%。

    AgentSelect: Benchmark for Narrative Query-to-Agent Recommendation

    将异构评测产物统一为叙事查询到可部署智能体配置的推荐基准，揭示长尾一次性监督下内容感知匹配的必要性。

    ProPerSim: Developing Proactive and Personalized AI Assistants through User-Assistant Simulation

    提出 ProPerSim 仿真任务与 ProPerAssistant 基线，用 LLM 用户智能体+四维评分准则+DPO 偏好学习，让助手在时机与内容上同时个性化，14 天内平均满意度从 2.2 升至 3.3/4。

    SituRecBench: Evaluating Frontier Models as Situated Recommendation Assistants in 3D Environments

    构建 UE5 三维购物环境与共享第一人称视角的交互式基准，统一评测 VLM 助手的对话质量、推荐效用与导航有效性。

    LaViC: Adapting Large Vision-Language Models to Visually-Aware Conversational Recommendation

    用视觉知识自蒸馏把商品图压成5个[CLS] token，再做推荐提示微调，在新建Reddit-Amazon三域上HR@1最高提升54.2%。

    Leveraging the Power of Conversations: Optimal Key Term Selection in Conversational Contextual Bandits

    用平滑关键词语境与最小特征值自适应触发对话，将对话式上下文 Bandit 遗憾降至近极小极大最优 O(√(dT logT))，累积遗憾较基线降低至少 14.6%。

    Why Not Together? A Multiple-Round Recommender System for Queries and Items

    提出 MAGUS 多轮查询-物品联合推荐框架，以词组合关系图桥接查询与物品，用标签传播在线吸收反馈，可插拔接入 12 种基座模型。

    Hierarchical Long-Term Semantic Memory for LinkedIn's Hiring Agent

    HLTM 用 schema 对齐的层级记忆树 + 多视图表示 + 无损增量索引，为 LinkedIn 招聘智能体实现低延迟、隐私隔离的长期个性化记忆，正确率提升 5%+、检索 F1 提升 10%+。

    HOBA: Hierarchical On-Policy Bidding Agents for Adaptive Online Advertising

    三层时间尺度解耦出价：LLM 小时级推理超参、SARSA 分钟级因果去偏选专家、专家池逐次拍卖执行，AuctionNet 与线上 A/B 双验证。

    MGFRec: Towards Reinforced Reasoning Recommendation with Multiple Groundings and Feedback

    将单步 grounding 扩展为多轮物品空间接地并引入用户 Agent 反馈，用 GRPO 训练 LLM 推理推荐，Full-Ranking 下 H@5 最高提升约 8.8%。

    SafeCRS: Personalized Safety Alignment for LLM-Based Conversational Recommender Systems

    提出 SafeRec 个性化安全基准与 Safe-SFT+Safe-GDPO 两阶段框架，在 SafeMovie 上将安全违规率相对降低 96.5% 且保持竞争力推荐质量。

    Consistent Explainers or Unreliable Narrators? Understanding LLM-generated Group Recommendations

    用社会选择聚合策略作多基线对4个LLM的群组推荐与解释做一致性审计，发现推荐近似ADD、解释常称平均但夹带未定义流行度/相似度/多样性。

    Failure Prediction in Conversational Recommendation Systems

    提出监督式对话性能预测任务，用AE与L1收缩多轮预测器区分系统失败与目录失败，揭示目录缺失场景下预测精度显著下降。

    Image-Seeking Intent Prediction for Cross-Device Product Search

    用语音查询+商品摘要预测图像意图，以可微精度损失抑制误触发，离线 Precision 达 78.5。

    USB-Rec: An Effective Framework for Improving Conversational Recommendation Capability of Large Language Model

    用带标签用户模拟器自动构造偏好对做 RL 训练，再在推理期用内部用户模拟器+树搜索自增强，iEval 全面超越 SOTA。

    $τ$-Rec: A Verifiable Benchmark for Agentic Recommender Systems

    用可验证目录谓词奖励、reveal-tagged 信息揭示机制与 pass^k 可靠性指标替代 LLM-as-judge，揭示智能体推荐在隐藏约束下的可靠性悬崖。

    A Position Paper on Recommender Systems in the Era of Autonomous Agents

    提出人-智能体-平台三方混合推荐生态，将智能体视为用户侧独立代理，重构任务定义、评估范式与四大研究方向。
