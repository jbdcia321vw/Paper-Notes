    ⚖️ 多任务学习与列表级重排 (Multi-Task Learning & Listwise Re-ranking)

    研究范畴：MMoE/PLE 多任务多目标精排、帕累托最优、上下文列表重排 (Re-ranking) 与粗精排级联一致性

    当前方向共收录 58 篇顶会/顶刊论文解读：

    Driving Engagement in Daily Fantasy Sports with a Scalable and Urgency-Aware Ranking Engine

    在 DIN 上注入实时紧迫度特征与时间位置编码，配合 neuralNDCG 列表损失，在 6.5 亿用户级工业数据上 nDCG@1 相对 LightGBM 提升 9%。

    BRIDGE: Behavior-Guided Residual Integration with Dual-Frequency Graph Evidence

    揭示跨视图对齐存在有效区间与频谱共享/私有分裂，提出双频图证据+行为符号残差仅在 top-K 候选内校准，Baby/Sports/Electronics 全库排序 R@20 最高提升 7.3%。

    Efficient Offline Learning of Ranking Policies via Top-$k$ Policy Decomposition

    将排序策略分解为 top-$k$ 策略梯度与 bottom 回归两段，在 CPC 条件下无偏且大幅降方差，小样本与大规模排序空间下显著优于 IPS/DR/RIPS/IIPS。

    Personalized Task Dependency Graphs for Mitigating Signal Erosion in Multi-Task Recommendation

    用低秩个性化任务依赖图+硬因果掩码GCN替代刚性漏斗，缓解深层稀疏任务信号侵蚀，离线AUC最高+1.45%，线上CVR+1.2%。

    RecSoup: Efficient Model Merging Approach for Controllable Multi-Objective Recommendation

    用剪枝+可学习门控做任务向量合并，实现推理时可控多目标推荐，HV 提升 8.5% 且延迟快 165–228 倍。

    Revisiting N2DCG: An Empirically Grounded Reformulation of Carousel Recommendation Evaluation

    修正 N2DCG 的理想排序类别约束与镜像 F 型折扣，提出类别感知归一化与行-页折扣，在眼动数据与 2 万次布局仿真中显著提升评估保真度。

    SelfDR: Self-Distillation from Reasoning for LLM-Based Recommendation

    用下游推荐奖励训练同源 Reasoner 生成理由，构建推理增强教师，再自蒸馏出免推理的直接推荐学生，重排 HR@1 提升约 15%。

    Sequential Multimodal Evidence Optimization for Product Media Ranking in E-Commerce

    将商品媒体排序建模为证据累积序列决策，两阶段解耦效用学习与生存加权自回归策略，离线 DR-CVR +5.4%、MSC −15.3%。

    SORT: A Systematically Optimized Ranking Transformer for Industrial-scale Recommenders

    以请求为中心组织样本、局部注意力+查询剪枝、生成式预训练与稀疏MoE重构工业精排Transformer，线上GMV+8.65%且延迟降62%。

    Task-Blind No MORE: Multi-Task Information Flow in Unified Ranking Backbones

    将多任务信息流下沉至统一排序主干，以共享/私有 Anchor Token 逐层共演化，离线七任务全胜、线上时长+3.0%、P99 延迟降约30%。

    Explain, Then Forget: Recommendation Unlearning under Asymmetric Access Constraint

    面向 MLaaS 非对称访问约束的免参数推荐遗忘框架，用因果解释定位最小支持集并做输出级分数干预，遗忘效果逼近全量重训且延迟降低 9–55 倍。

    Eating for a Sustainable Planet: Personalized Sustainable Diet Recommendation via Constraint-Aware Decision-Making Modeling

    将可持续饮食推荐重构为约束感知决策问题，用可学习用户约束阈值替代偏好建模，在自建 SusDiet 上兼顾偏好精度与四维可持续性。

    Goal-Conditioned Supervised Learning for Multi-Objective Recommendation

    将 GCSL 的标量目标扩展为多维向量目标，用 Transformer 编码器 + 交叉熵直接做多目标下一物品预测，无需复杂架构与权重调参，在 RetailRocket/Challenge15 上购买 HR@10 相对提升约 4-17%。

    GoalRank: Group-Relative Optimization for a Large Ranking Model

    证明单生成器排序器近似误差严格优于多生成器-评估器，提出组相对优化训练大排序模型，离线 H@6 最高 +25.4%，线上全量部署。

    Optimal and Efficient Contextual Combinatorial Semi-bandits with General Function Approximation

    提出 SquareCB.Comb，用回归 oracle + 对数障碍边际优化实现通用函数逼近下 CCSB 的极小极大最优 regret，并在网页推荐与最短路任务上验证。

    Bradley-Terry Rankings for Recommender Systems Across Dataset Taxonomies

    用 Bradley-Terry 概率排序替代指标均值聚合，在 14 算法×89 数据集上给出数据集感知的推荐算法排名与免运行预测。

    Breaking the Likelihood Trap: Consistent Generative Recommendation with Graph-structured Model

    用有向无环图解码器扩展非自回归生成空间，并以 Gumbel-Softmax 打通评估器梯度，破解似然陷阱，快手线上 Views +0.78%。

    DeGRe: Dense-supervised Generative Reranking for Recommendation

    离线束搜索挖掘前瞻序列+累积回归稠密监督蒸馏至轻量生成器，单次贪心解码逼近全局最优，线上GMV+3.75%

    Heterogeneous Multi-treatment Uplift Modeling for Trade-off Optimization in Short-Video Recommendation

    用异构多处理增益建模+在线动态权重，个性化权衡短视频消费与商业化指标，快手全量部署

    HMAF: A Hierarchical Multi-Slot GD-RTB Allocation Framework

    以 Plan-Calibrate-Execute 范式将 PV 约束对偶优化与在线列表级生成-评估排序耦合，美团线上 GD 交付率 +3.72%、广告总收入 +1.59%。

    MAC: A Conversion Rate Prediction Benchmark Featuring Labels Under Multiple Attribution Mechanisms

    首个多归因机制CVR公开基准MAC与PyMAL库，提出MoAE模型，GAUC最高提升0.39pt。

    Meta Lattice: Model Space Redesign for Cost-Effective Industry-Scale Ads Recommendations

    以模型空间重构统一碎片化广告组合，融合归因窗口混合、帕累托特征选择与推理期知识迁移，线上Topline +10%、容量省20%。

    OneRank: Unified Transformer-Native Ranking Architecture for Multi-Task Recommendation

    将多任务推理内化进 Transformer 栈，用任务私有 token 通道 + 梯度截断 + 匹配式打分替代编码器-预测器分离，Shopee 离线与线上 A/B 全面领先。

    Personalizing Marketplace Policies with Competing Objectives and Constrained Experiments: Evidence from a Job Marketplace

    双边市场免费额度阈值个性化：集成CATE+混合排序+线性外推，护栏风险降10%+，线上验证外推精度r=0.85

    Decoupled Learning and Selection in Slate Recommendation for Privacy and Stability Under Noisy Scores

    将列表推荐拆为随机打分器+确定性选择器，给出隐私后处理契约与可审计的 margin 稳定性证书，锚点加权使 Flip@K 降 53–81%。

    Embedding Subspace Partitioning for Dynamic Multi-Objective Retrieval

    将双塔嵌入切分为任务感知正交子空间，用服务时可调权重的加权内积替代单一点积，单模型即可在线遍历多目标 Pareto 前沿。

    From Click Modeling to Offline and Off-Policy Evaluation in Carousel Recommendation

    基于 RecGaze 眼动数据推翻轮播界面四大行为假设，提出以可观测变量为核心的点击模型设计框架、离散选择点击模型与 N2DCG 重构，并规划轮播专用 OPE 路线。

    GenPage: Towards End-to-End Generative Homepage Construction at Netflix

    用单个 Transformer 将用户上下文 token 化后自回归生成整页多行首页，WBC/RL 后训练，线上 +0.24% 核心参与度且延迟降 20%。

    Heterogeneous Ranking in Industrial-Scale Recommender Systems: A Case Study

    面向 Google Discover 异构信息流的 HA-MoE 多门控专家架构，配合 LENS 可观测性与 DL-AUC 双层评估，离线与线上均获稳定增益。

    Hierarchical GTV Estimation: Bridging the Gap between Container-Level Ranking and Item-Level Conversion

    面向容器式电商的层级 GTV 预估框架 HGE，用集合感知编码器 + 代理标签分解 + 残差融合解决粒度错配，离线 XAUC +0.63pp、线上 RPS +1.42%。

    Impression Share Prediction: An Offline Evaluation Task for Ranking Systems

    提出曝光份额预测作为离线评估新任务，用因果DAG证明反事实可识别，PatchTST编码器在首小时恢复+22% L1。

    Learned Cross-Task Relationships in Multi-Task Models

    用交叉标签/无条件辅助头显式逼近任务两两联合分布，在 YouTube 三大场景线上 A/B 验证迁移与 RL 状态增强双重收益。

    Lightweight Ranking Heads: Accelerating Multi-Task Experimentation in Production Recommender Systems

    以 stop-gradient + 无状态日训的轻量头动态注入新任务，免骨干重训，将多任务实验周期从数周压缩至数天。

    Long-term User Engagement Optimization through Model-agnostic Downstream Rewards Learning

    以 P2P 兔子洞深度、浅层关闭负奖励与新用例采纳三类下游奖励替代稀疏留存标签，在 Pinterest 多场景线上 A/B 中稳定提升会话与留存指标。

    Multi-Objective Ranking for Live-Streaming: Balancing Fresh and Delayed Signals with Segment-Aware Targeting

    Twitch 直播精排用延迟窗口+新鲜/延迟双模型分离+分段推理加权+MMoE，DAV +0.09%、D 段 ARPU +0.56%。

    Normative Alignment of Recommender Systems via Internal Label Shift

    将编辑/公平目标建模为属性层内部标签偏移，用免重训的闭式重加权实现系统级规范对齐，KL 大幅下降且 AUC 基本无损。

    Pairwise Ranking Outperforms Single-Action RL for Offline Explanation Selection: A Practical Lesson

    将 LLM 解释生成离线化为冻结候选池，用 CPU 端 LambdaRank 逐候选打分选择，F1=0.500 超越 G-Refer/XRec 且延迟<100ms。

    Personalized Recommendation Tool Learning via Autonomous Language Agents

    让 LLM 智能体做个性化工具选择、传统推荐模型做全库打分，以架构设计绕开幻觉与上下文长度限制，Full-Ranking 下 R@10 最高提升 68.8%。

    Position Bias Undermines Preference Consistency in Listwise LLM-Based Reranking

    将 LLM 列表重排的候选置换视为诱导偏好系统，提出 PPI/GPI/LOC 三层一致性度量，揭示有效性、曝光均衡与置换一致性三者可背离。

    Shape Your Feed: An LLM-based Agentic System for Conversational Recommendation

    三层 Agentic 架构（感知/服务/自进化）实现多模态实时用户可控重排，离线对齐打分 98.85% 准确率，线上 dislike 降 2.74%。

    Towards Full Candidate Interaction: A Comprehensive Comparison Network for Better Route Recommendation

    提出比较优先范式，用非重叠路段构造显式比较张量并在成对空间直接推理，线上CR +1.2%、偏航率 -0.8%。

    Additive Control Variates Dominate Self-Normalisation in Off-Policy Evaluation

    证明最优加性基线 β*-IPS 在 MSE 上渐近严格优于 SNIPS，并给出精确方差差解析式与排序场景 β*⊥⊥-IPM 扩展。

    Equip Pre-ranking with Target Attention by Residual Quantization

    用残差量化码本近似 Target Attention，将交互式建模引入粗排，AUC 0.799、线上 GMV +7.57%。

    Equity vs. Equality: Optimizing Ranking Fairness for Tailored Provider Needs

    提出以增益为基的公平框架与 EquityRank 梯度重排算法，按提供者异质偏好分配曝光与销量收益，离线/在线仿真均取得更优效果-公平权衡。

    Exploring Test-time Scaling via Prediction Merging on Large-Scale Recommendation

    提出预测合并式测试时缩放，用异构架构与同构随机种子生成多样 logit 并平均融合，三数据集八骨干上稳定超越参数缩放。

    Following the Eye-Tracking Evidence: Established Web-Search Assumptions Fail in Carousel Interfaces

    用 RecGaze 眼动数据系统证伪 F 型注意力、层级点击与标题导航等四条 Web 搜索假设，提出轮播界面特有的 L 型注视模式。

    One Pass, Any Order: Position-Invariant Listwise Reranking for LLM-Based Recommendation

    用结构化注意力掩码+共享位置框架在架构层消除候选顺序依赖，单次前向实现近完美排列不变性，nDCG 仅微降。

    Post-hoc Provider Fairness Adaptation via Hierarchical Exposure Alignment

    冻结基座+轻量公平适配器，用分层曝光对齐(HEFA)与可微NDCG联合优化，实现即插即用的提供方曝光公平。

    The Attention Market: Interpreting Online Fair Re-ranking as Manifold Optimization under Walrasian Equilibrium

    将在线公平重排建模为注意力市场瓦尔拉斯均衡，用供需双侧梯度校正对齐排序流形，7 数据集 42 设置几乎全胜。

    Think When Needed: Model-Aware Reasoning Routing for LLM-based Ranking

    提出轻量即插即用的模型感知推理路由器，在生成前逐实例决定 Think/Non-Think，以 Pareto 前沿策略在降 token 的同时提升排序效用。

    Towards End-to-End Alignment of User Satisfaction via Questionnaire in Video Recommendation

    用 LoRA+MoE 独立参数通路隔离稀疏问卷满意度信号，并以在线 DPO 对齐主排序模型，离线 NDCG@5 提升约 3%，线上 Q-Satisfied 提升 0.5–0.9%。

    Uniboost: Global Coordination with Value Alignment for Fair and Efficient Traffic Allocation

    用后验价值对齐把抽象混合分映射到有效完播率语义空间，再以独立线性 boosting 解耦多业务加权，线上 A/B 全指标正向。

    Unifying Search and Recommendation in LLMs via Gradient Multi-Subspace Tuning

    用梯度多子空间分解+零空间投影替代 LoRA，在统一 S&R 生成式建模中消解任务梯度冲突并保住通用知识，Qilin/Amazon 上大幅超越 SOTA。

    Robustness Analysis of Pareto-based Joint Evaluation of Fairness and Relevance in Recommender Systems

    提出 DPFR：以测试集真实标签构建相关性-公平性帕累托前沿，用模型得分到前沿参考点的距离联合评估推荐系统，比现有联合度量更稳健。

    Automated Information Flow Selection for Multi-scenario Multi-task Recommendation

    用 LoRA 解耦四类场景-任务信息单元并以可学习掩码剪枝无效信息流，AUC 全面超越 HiNet/M3oE，线上 CVR 均涨 2.46%。

    Cold-Starting Podcast Ads and Promotions with Multi-Task Learning on Spotify

    Spotify 用单一 5 任务 MTL 模型统一播客广告与推广定向，靠非对称损失掩码与源平衡采样实现跨渠道迁移，线上 eCPS 降 22%、i2s 升 18–24%。

    GRank: Towards Target-Aware and Streamlined Industrial Retrieval with a Generate-Rank Framework

    用训练期目标注入把 Target-Aware 能力蒸馏进 MIPS 兼容生成器，再以轻量交叉注意力重排，免结构化索引实现 Recall@500 +30% 与 1.7× QPS。

    Not All Candidates are Created Equal: A Heterogeneity-Aware Approach to Pre-ranking in Recommender Systems

    针对粗排异构候选的梯度冲突与算力错配，提出 GHCL 分组对比损失与难度感知双模型路由，AUC 全面超越 SOTA 且线上降本 6%。
