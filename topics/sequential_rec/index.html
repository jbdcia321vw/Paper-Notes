    Wavelet Enhanced Adaptive Frequency Filter for Sequential Recommendation

    HORIZON: A Benchmark for In-the-wild User Behaviour Modeling

    TATK: Triple-Aware Top-K Learning with Knowledge-Grounded Verification for LLM-based Sequential Recommendation

    What Makes LLMs Effective Sequential Recommenders? A Study on Preference Intensity and Temporal Context

    揭示二元偏好对齐丢失偏好强度与时序上下文，提出自适应奖励边际 RecPO，五数据集 HR@1 全面领先 S-DPO。

    Decoupled Temporal Encoding for Generative Recommendation

    IntSR: An Integrated Generative Framework for Search and Recommendation

    DynamicPO: Dynamic Preference Optimization for Recommendation

    Pre-trained LLMs Meet Sequential Recommenders: Efficient User-Centric Knowledge Distillation

    Memory Has Geometry: Non-Uniform Geometric Memory for Long-Horizon Personalized AI

    Revisiting Self-Attentive Sequential Recommendation Beyond the LLM Paradigm

    MergeRec: Model Merging for Data-Isolated Cross-Domain Sequential Recommendation

    提出数据隔离跨域序列推荐新设定，用任务向量模型合并+伪用户数据+推荐/蒸馏联合目标，Recall@10 平均提升 17.21%。

    MixFormer: Co-Scaling Up Dense and Sequence in Industrial Recommenders

    用单一参数空间统一序列建模与稠密特征交叉，配合用户-物品解耦实现请求级复用，AUC 提升 1.28% 且 FLOPs 降 36%。

    One Sequential Recommendation Model Pretrained from Synthetic Priors Predicts Multiple Datasets

    用 hDCSBM 合成先验预训练 PFN，以支持集条件化实现免更新推理的序列推荐，五基准平均超最优基线 7.53%。

    S$^2$GR: Stepwise Semantic-Guided Reasoning in Latent Space for Generative Recommendation

    在每级 SID 码生成前插入受码本聚类语义对比监督的思考 token，实现逐步可验证潜在推理，工业短视频 A/B 显著提升时长。

    Scaling Recommender Transformers to One Billion Parameters

    The Pitfall of Scaling Up: Uncovering and Mitigating Popularity Bias Amplification in Scaling Transformer-based Recommenders

    揭示 Transformer 序列推荐随深度加深发生谱坍缩并放大流行度偏差，提出逐层注意力列和与 FFN 谱范数正则 SPRINT，在 6 数据集上同时提升准确率与长尾公平性。

    Understanding Generative Recommendation with Semantic IDs from a Model-scaling View

    揭示 SID 式生成推荐在编码器/量化器/RS 三轴扩展均快速饱和，归因于 SID 语义容量瓶颈，并证明 Text-based GR 具备更优扩展性且 CF 能力随规模提升。

    Unleashing the Potential of Neighbors: Diffusion-based Latent Neighbor Generation for Session-based Recommendation

    用检索先验与多模态信号双路引导扩散模型生成“潜在邻居”，突破可观测邻居边界，Full-Ranking 下 P@20 最高提升 18.45%。

    Addressing Cross-Stage Decoupling of Semantic and Collaborative Signals in Generative Recommendation

    提出 SCRec，通过协同增强分词、语义引导生成与双曲流形对齐三模块双向补全语义与协同信号，在 Amazon 三数据集 Full-Ranking 下 NDCG@10 相对提升 18.7%–26.6%。

    Building a User Foundation Model for the Open Web
