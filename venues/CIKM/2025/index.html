    🏛️ CIKM 2025 推荐系统论文解读

    72 篇 CIKM 2025 论文解读，覆盖 16 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🤝 协同过滤与双塔召回 (2)

    A Node-Aware Dynamic Quantization Approach for Graph Collaborative Filtering

    提出节点感知动态量化 GNAQ，用参数共享学习每节点量化步长并以图消息传递更新，2-bit 下 Recall@10 平均提升 27.8%。

    Patient Clustering via Integrated Profiling of Clinical and Digital Data

    用掩码约束非负低秩分解统一融合诊断码与门户浏览/搜索行为，同时产出可解释软聚类与患者嵌入，聚类与推荐双任务全面领先。

    🕸️ 图神经网络与知识图谱推荐 (3)

    Enhancing Graph Collaborative Filtering with FourierKAN Feature Transformation

    用 Fourier KAN 替代 NGCF 中被误删的交互特征变换 W2，在 7:1:2 时间切分全库排序下 R@20 最高提升 7.8%，且可作即插即用骨干。

    SPARK: Adaptive Low-Rank Knowledge Graph Modeling in Hybrid Geometric Spaces for Recommendation

    用 Tucker 低秩去噪 KG、SVD 初始化双曲/欧氏并行 GNN，并按物品流行度自适应融合多源信号，长尾推荐 R@10 最高提升 10.8%。

    Ultra Fast Warm Start Solution for Graph Recommendations

    将 SVD Folding-In 的闭式解迁移到 UltraGCN，用一次矩阵-向量乘精确更新热用户嵌入，比 SGD 微调快 30 倍且质量更优、覆盖率更高。

    🔄 自监督对比学习与交互去噪 (3)

    A Self-Supervised Mixture-of-Experts Framework for Multi-behavior Recommendation

    揭示多行为推荐在已访问/未访问物品上的性能鸿沟，提出双专家 MoE + 专家自适应 SSL（访问过滤/新颖性推断对比 + 行为生成）框架，全库排序下 HR@20 最高提升 65.46%。

    Empowering Denoising Sequential Recommendation with Large Language Model Embeddings

    用 LLM 语义嵌入与协同嵌入做跨模态兴趣对齐，缓解冷门物品过度去噪，四数据集全排序 HR/NDCG 显著提升。

    Generative Data Augmentation in Graph Contrastive Learning for Recommendation

    用 VAE 式生成器自适应生成噪声替代固定随机扰动构造对比视图，并引入物品互补矩阵，在三个稀疏数据集上 Full-Ranking 提升约 3–6%。

    ⏱️ 序列与会话推荐 (6)

    Climber: Toward Efficient Scaling Laws for Large Recommendation Models

    面向推荐场景改造 Transformer：多尺度子序列抽取降复杂度、自适应温度调制注意力，配合单用户多物品批处理与 KV 缓存，线上指标 +12.19%。

    Continual Recommender Systems

    系统梳理持续推荐的两大技术路线（经验回放与正则化），并延伸至资源受限与序列交互场景，给出可信性、基础模型与搜推统一三大开放方向。

    CPMR: Context-Aware Incremental Sequential Recommendation with Pseudo-Multi-Task Learning

    提出伪多任务学习范式，用历史图与上下文图双通道演化用户/物品时序状态，在四个数据集上 MRR 平均提升 30.98%。

    MUFFIN: Mixture of User-Adaptive Frequency Filtering for Sequential Recommendation

    双分支频域滤波+用户自适应滤波器，兼顾全谱与频带局部建模，五数据集全库排序平均 R@10 提升 4.12%。

    Multi-Item-Query Attention for Stable Sequential Recommendation

    用多物品查询窗口+虚拟物品替代单查询掩码注意力，缓解序列噪声敏感，ML-1M HR@5 提升 21.2%，LastFM 达 SOTA。

    TransAct V2: Lifelong User Action Sequence Modeling on Pinterest Recommendation

    用 NN 检索压缩终身序列 + 下一动作对比损失 + Triton 融合推理，Pinterest 线上 Repin +6.35%、Hide -12.80%。

    ✨ 生成式推荐与离散语义 ID (6)

    Asymmetric Diffusion Recommendation Model

    用特征丢弃替代高斯噪声做离散前向、在隐空间做非对称反向去噪，抖音音乐全量A/B活跃天数+0.131%。

    DAS: Dual-Aligned Semantic IDs Empowered Industrial Recommender System

    提出单阶段双对齐语义ID框架，联合优化RQ-VAE量化与CF去偏对齐，快手全场景A/B eCPM+3.48%、冷启动+8.98%。

    Empowering Large Language Model for Sequential Recommendation via Multimodal Embeddings and Semantic IDs

    揭示 LLM4SR 的嵌入坍缩与语义ID灾难性遗忘，用多模态嵌入+MMD重建+码本初始化破局，全库排序下 nDCG@5 提升 4.4%–10.5%。

    MTGR: Industrial-Scale Generative Recommendation Framework in Meituan

    以用户级样本聚合复用 HSTU 编码器并保留 DLRM 交叉特征，实现 65× FLOPs 下线上 CTCVR +1.02%、推理成本降 12%

    Progressive Semantic Residual Quantization for Multimodal-Joint Interest Modeling in Music Recommendation

    提出前缀语义约束的渐进残差量化 PSRQ 与多码本交叉注意力 MCCA，缓解语义漂移与跨模态建模缺口，冷启动 AUC 显著提升并完成工业上线。

    TBGRecall: A Generative Retrieval Model for E-commerce Recommendation Scenarios

    提出 Next Session Prediction 会话级非自回归生成召回，配合 Session Mask、MSP/MoE 与部分增量训练，淘宝线上成交额 +2.16%。

    🧠 大语言模型推荐 (LLM4Rec) (6)

    Alibaba International E-commerce Product Search Competition DcuRAGONs Team Technical Report

    以 Gemma-3-12B 为骨干，用翻译增强+任务自适应预训练+类别感知查询分组划分，在阿里国际电商多语言相关性竞赛夺冠（F1_avg≈89.1）。

    Exploring the Upper Limits of Text-Based Collaborative Filtering Using Large Language Models: Discoveries and Insights

    将 TCF 物品编码器从 125M 一路放大到 175B，系统检验缩放极限、通用表征、对 IDCF 的竞争力与零样本迁移四项命题。

    LLM-Enhanced Linear Autoencoders for Recommendation

    用 LLM 语义矩阵构造 item-item 相关阵并以知识蒸馏正则注入 EASE 闭式解，全库排序下 R@20 平均提升 27.6%。

    Prompt Tuning as User Inherent Profile Inference Machine

    将用户潜在画像建模为可训练软提示，用因果掩码+EM 推断、码本量化成协同 ID，AUC 最高相对提升 4.77%，已上线华为应用市场。

    SELF: Surrogate-light Feature Selection with Large Language Models in Deep Recommender Systems

    用多 LLM 迭代提示生成语义特征排序，再以可学习桥接向量对齐任务空间，实现轻量特征选择，AUC 全面领先且线上 CTR +3.01%。

    TRAWL: External Knowledge-Enhanced Recommendation with LLM Assistance

    用 LLM 从原始外部文本抽取推荐知识，再以对比学习适配器对齐语义与行为空间，ML-1M 上 AUC 稳定提升且微信线上 A/B 三项指标正向。

    🗣️ 对话推荐与智能体仿真 (3)

    STARec: An Efficient Agent Framework for Recommender Systems via Autonomous Deliberate Reasoning

    将每位用户建模为具备快/慢双认知的 LLM Agent，用 SFT 蒸馏 + GRPO 排序奖励两阶段训练，仅用 0.4% 数据即在 ML-1M/CDs 上超越全量训练基线。

    STEP: Stepwise Curriculum Learning for Context-Knowledge Fusion in Conversational Recommendation

    用三阶段课程学习驱动 F-Former 对齐对话与知识图谱，再以双前缀提示注入冻结 PLM，ReDial R@1 提升 15.7%。

    Temporal-Aware User Behaviour Simulation with Large Language Models for Recommender Systems

    用动态画像更新、时序模式抽取与自适应聚合构建 LLM 用户模拟器，在 ML-1M 上 nDCG@5 相对 RecAgent 提升约 27.8%。

    🧩 多模态推荐与内容理解 (9)

    A Content-Driven Micro-Video Recommendation Dataset at Scale

    发布十亿级含原始视频模态的微视频推荐数据集 MicroLens，并系统基准 IDRec/VIDRec/VideoRec 三类范式，揭示端到端视频编码优于冻结特征的关键结论。

    BiListing: Modality Alignment for Listings

    用 LLM 生成视觉画像 + PhotoSet Transformer 聚合多图，将 CLIP 图文对齐扩展到多图多文本的房源实体，线上 NDCG +0.425%。

    Distribution-Guided Auto-Encoder for User Multimodal Interest Cross Fusion

    以行为粒度做模态内/模态间交叉融合，并用兴趣分布解码器作自监督约束，工业 A/B 上 CTR +12.9%。

    Do Recommender Systems Really Leverage Multimodal Content? A Comprehensive Analysis on Multimodal Representations for Recommendation

    用受控噪声实验证明多模态增益源于语义而非模型容量，并以 LVLM 结构化提示生成「原生多模态」[EOS] 嵌入替代晚期融合，Borda 聚合排名第一。

    Efficient Multimodal Streaming Recommendation via Expandable Side Mixture-of-Experts

    冻结 BERT/ViT 主干，用可扩展侧调 MoE 增量吸收新时段知识并按利用率剪枝，在三个流式数据集上 HR@10 全面超越 SOTA 且显存/训练时间更省。

    Hypercomplex Prompt-aware Multimodal Recommendation

    用 Cayley-Dickson 超复数多分量嵌入 + 超复数乘法非线性融合 + Prompt 动态补偿，在四个 Amazon 数据集 Full-Ranking 下 Recall@20 最高提升约 13%。

    MISS: Multi-Modal Tree Indexing and Searching with Lifelong Sequential Behavior for Retrieval Recommendation

    用多模态嵌入构建树索引，并以 Co-GSU/MM-GSU 双视角检索终身行为，快手线上召回@800 相对提升 37.9%。

    Modality Alignment with Multi-scale Bilateral Attention for Multimodal Recommendation

    提出 MambaRec，用多尺度空洞卷积+双注意力做局部图文对齐、MMD+InfoNCE 做全局分布对齐，Amazon 三数据集 Recall@20 最高提升约 5.4%。

    QARM: Quantitative Alignment Multi-Modal Recommendation at Kuaishou

    用业务 item-item 对微调 MLLM 做表示对齐，再以 VQ/RQ 量化成语义码实现端到端可学习，快手广告与电商线上 GMV+2.296%、冷启曝光+5.324%

    👥 社交与群组推荐 (2)

    Community-Aware Social Community Recommendation

    提出 CASO，用模块度最大化、社交紧密度聚合与协同编码三路解耦用户表征，并以 HSIC 互斥与 KL 社区检测损失优化，在 6 个真实社交网络上 Full-Ranking 全面超越 9 个基线。

    Heterogeneous Influence Maximization in User Recommendation

    将异质传播概率与 RR 集影响力最大化引入好友邀请推荐，HeteroIR/HeteroIM 在 NSpread/Recall/NDCG 全面领先并落地腾讯游戏 A/B 提升 8.5%/10%。

    ❄️ 冷启动与长尾推荐 (4)

    CSRM-LLM: Embracing Multilingual LLMs for Cold-Start Relevance Matching in Emerging E-commerce Markets

    多语言 LLM 联合翻译任务、检索式查询增强与多轮自蒸馏，解决新兴市场零标注相关性匹配，离线 F1 0.965、线上缺陷率降 45.8%。

    Harnessing Light for Cold-Start Recommendations: Leveraging Epistemic Uncertainty to Enhance Performance in User-Item Interactions

    用集成 CVAE 生成暖化嵌入，并以 Sinkhorn 散度版 PaiDE 估计认知不确定性做优化，在冷启动 CTR 上稳定超越 CVAR 等基线。

    Multi-modal Adaptive Mixture of Experts for Cold-start Recommendation

    用双层 MoE（模态专属专家+动态门控融合）替代拼接/平均融合，在 Amazon 三域冷启动全库排序上 Recall@10 最高提升 16.17%。

    Shallow AutoEncoding Recommender with Cold Start Handling via Side Features

    将用户/物品侧特征拼入 EASE 输入矩阵，并用内容相似度矩阵作冷物品权重先验，闭式解统一处理双冷启动。

    🌐 跨域与多场景推荐 (4)

    A Soft-partitioned Semi-supervised Collaborative Transfer Learning Approach for Multi-Domain Recommendation

    用软分区动态参数缓解主导域压制、用主导域伪标签加权迁移缓解稀疏域过拟合，离线全库AUC与美团线上A/B双验证。

    Benefit from Rich: Tackling Search Interaction Sparsity in Search Enhanced Recommendation

    用 LLM+RQ-VAE 将用户搜索/推荐偏好离散为码本，构建 User-Code 图做消息传递，把搜索富用户信号传给稀疏用户，Qilin 上 HR@1 相对 UniSAR 提升 12.1%。

    Global-Distribution Aware Scenario-Specific Variational Representation Learning Framework

    用变分推断为每个场景下的用户/物品学习分布表征，并以全局行为模式与物品属性构造先验，缓解稀疏场景表征欠学习，即插即用提升 PEPNet/MARIA。

    Scenario-Wise Rec: A Multi-Scenario Recommendation Benchmark

    首个多场景推荐统一基准，整合 6 个公开数据集与 12 个 MSR 模型，统一数据处理/训练/评测管线并附工业广告数据验证。

    📍 时空轨迹与 POI 本地生活推荐 (1)

    Harnessing Large Language Models for Group POI Recommendations

    用语义增强 POI Token + QLoRA 双适配器 + 行程目的自监督，破解群体 POI 推荐偏好多样与数据极稀疏难题，HR@10 平均提升 4.4%–9.0%。

    🎯 CTR/CVR 预估与特征交叉 (5)

    HIT Model: A Hierarchical Interaction-Enhanced Two-Tower Model for Pre-Ranking Systems

    用双生成器预生成跨塔粗粒度向量+多头子空间细粒度匹配，在保持双塔预缓存效率下逼近全交互模型精度，腾讯线上GMV+1.66%。

    InterFormer: Effective Heterogeneous Interaction Learning for Click-Through Rate Prediction

    提出交错式双向信息流的 InterFormer，用独立 Cross Arch 做选择性聚合，在三个公开集与 Meta 工业集上取得 SOTA，线上 NE 提升 0.15% 且 QPS 提升 24%。

    Personalized Tree-Based Progressive Regression Model for Watch-Time Prediction in Short Video Recommendation

    将TPM固定满二叉树改为样本级可学习剪枝树，并用IPS校正条件建模选择偏差，离线MAE/XAUC全面领先，线上观看时长+0.428%。

    RankMixer: Scaling Up Ranking Models in Industrial Recommenders

    用无参多头Token Mixing替代自注意力、Per-token FFN隔离特征子空间，配合ReLU路由稀疏MoE，在抖音万亿级数据上将MFU从4.5%提至45%，参数扩100倍而延迟不增。

    See Beyond a Single View: Multi-Attribution Learning Leads to Better Conversion Rate Prediction

    将多归因标签作为辅助任务联合学习，用笛卡尔积辅助训练增强监督信号，离线GAUC+0.51%、线上ROI+2.6%

    ⚖️ 多任务学习与列表级重排 (4)

    GReF: A Unified Generative Framework for Efficient Reranking via Ordered Multi-token Prediction

    用双向编码器+动态匹配自回归解码器统一生成式重排，Rerank-DPO 端到端对齐用户偏好，OMTP 多token并行解码将延迟压至 12.97ms，快手线上转发+2.98%。

    MPFormer: Adaptive Framework for Industrial Multi-Task Personalized Sequential Retriever

    用目标条件化 Transformer 统一多目标召回，并以排序分数监督动态配额分配，在快手 4 亿 DAU 上实现 +0.43% 总时长与 66.7% 推理资源节省。

    ORCA: Mitigating Over-Reliance for Multi-Task Dwell Time Prediction with Causal Decoupling

    用因果解耦显式建模并减去CTR对停留时间预测的负迁移，恢复中时长分桶语义，DT指标平均提升10.6%且不损CTR。

    You Only Evaluate Once: A Tree-based Rerank Method at Meituan

    用树状多尺度上下文提取+上下文缓存实现单阶段全排列重排，离线GAUC显著提升并落地美团外卖。

    🎮 强化学习与动态探索推荐 (5)

    Energy-Guided Diffusion Sampling for Long-Term User Behavior Prediction in Reinforcement Learning-based Recommendation

    用扩散策略替代行为克隆以提升离线RL4RS策略表达能力，并以Q值能量引导采样降低随机性，六数据集与仿真环境全面领先。

    Expert-Guided Diffusion Planner for Auto-bidding

    用专家轨迹引导条件扩散规划器生成出价序列，配合混合强制训练与跳步采样，线上转化+11.29%、收入+12.36%。

    KP-Agent: Keyword Pruning in Sponsored Search Advertising via LLM-Powered Contextual Bandits

    将关键词剪枝建模为上下文赌博机，用 LLM Agent 生成代码片段执行剪枝，美团真实数据上累计利润最高提升 49.28%。

    Maximum In-Support Return Modeling for Dynamic Recommendation with Language Model Prior
