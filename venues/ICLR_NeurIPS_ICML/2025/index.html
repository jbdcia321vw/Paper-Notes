    🏛️ ICLR / NeurIPS / ICML (RecSys) 2025 推荐系统论文解读

    38 篇 ICLR / NeurIPS / ICML (RecSys) 2025 论文解读，覆盖 11 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🤝 协同过滤与双塔召回 (2)

    Covariate-moderated Empirical Bayes Matrix Factorization

    用协变量调制的经验贝叶斯先验统一矩阵分解，MovieLens 100K 上 RMSE 全面优于 EBMF/MFAI/VAE 系基线。

    Recommendations with Sparse Comparison Data: Provably Fast Convergence for Nonconvex Matrix Factorization

    将成对比较反馈建模为低秩矩阵分解下的离散选择似然，证明稀疏数据下投影梯度下降在热启动邻域内指数收敛，样本复杂度近最优。

    🕸️ 图神经网络与知识图谱推荐 (1)

    ContextGNN: Beyond Two-Tower Recommendation Systems

    提出局部成对表征+全局双塔回退的混合GNN架构，在RelBench十个任务上平均MAP较最强成对基线提升20%。

    ⏱️ 序列与会话推荐 (4)

    Long-Sequence Recommendation Models Need Decoupled Embeddings

    揭示长序列推荐中注意力与表征共享嵌入导致的梯度支配与冲突，提出双嵌入表 DARE，AUC 最高提升 9‰ 并加速检索 50%。

    PANTHER: Generative Pretraining Beyond Language for Sequential User Behavior Modeling

    将支付交易视为行为 token 做生成式预训练，SPRM 卷积+原型交叉注意力捕捉周期模式，用户画像对比学习，微信支付线上欺诈召回 +38.6%。

    Semantic Retrieval Augmented Contrastive Learning for Sequential Recommendation

    用 LLM 语义检索构建用户/物品候选池并配可学习样本合成器，替代随机增广与 K-Means 硬规则，全库排序下 HR@20 最高提升 11.82%。

    TV-Rec: Time-Variant Convolutional Filter for Sequential Recommendation

    用图信号处理中的时变图滤波器替代固定卷积核与自注意力，在6个基准上全库排序平均提升7.49%且推理更快。

    ✨ 生成式推荐与离散语义 ID (6)

    ActionPiece: Contextually Tokenizing Action Sequences for Generative Recommendation

    首个上下文感知的动作序列分词器，将动作建模为无序特征集，用加权共现合并+集合置换正则实现同一动作在不同上下文下差异化分词，NDCG@10 相对提升 6.0%–12.8%。

    Efficient Inference for Large Language Model-based Generative Recommendation

    将投机解码引入 LLM 生成式推荐，提出 N-to-K 验证下的 AtSpeed-S/R 对齐目标与松弛采样验证，实现近 2×–2.5× 无损/近似无损加速。

    Listwise Preference Diffusion Optimization for User Behavior Trajectories Prediction

    将 Plackett-Luce 列表级排序信号注入扩散 ELBO，实现多步用户行为轨迹的连贯生成，并提出 SeqMatch 轨迹级指标，Full-Ranking 下 SeqMatch@50 最高提升 36.8%。

    Multimodal Quantitative Language for Generative Recommendation

    用 RQ-VAE 将多域多模态物品翻译为统一量化语言，配合多任务预训练微调实现知识迁移，全库排序下 NDCG@10 最高提升 14.82%。

    On Efficiency-Effectiveness Trade-off of Diffusion-based Recommenders

    用时间一致性正则平滑去噪函数实现一步生成，再用自适应偏好对齐修正轨迹偏差，兼顾扩散推荐效率与效果。

    Preference Diffusion for Recommendation

    将 BPR 改写为对数似然排序目标并推导变分上界，为扩散推荐器注入多负样本偏好信号，Full-Ranking 下 R@5 最高提升 19.35%。

    🧠 大语言模型推荐 (LLM4Rec) (10)

    Can LLMs Outshine Conventional Recommenders? A Comparative Evaluation

    RecBench 系统对比 17 个 LLM 与 DLRM 在 4 种物品表征、CTR/SeqRec 双任务上的精度-效率权衡，LLM 精度领先但推理慢千倍。

    Context Steering: Controllable Personalization at Inference Time

    免训练解码期个性化：用有/无上下文两次前向的似然差线性缩放上下文影响力，实现可控个性化推荐与贝叶斯意图反演。

    FACE: A General Framework for Mapping Collaborative Filtering Embeddings into LLM Tokens

    用解耦投影+RQ-VAE 将 CF 嵌入映射为冻结 LLM 词表中的离散 token，配合对比对齐实现免微调的语义可解释与性能增益。

    Fine-grained List-wise Alignment for Generative Medication Recommendation

    将用药推荐重构为逐药序列决策，提出逐步GRPO与势函数奖励塑形实现细粒度信用分配，在MIMIC-III上Jaccard达0.4836并支持安全-精度可控权衡。

    Improving LLMs for Recommendation with Out-Of-Vocabulary Tokens

    用元路径聚类生成 OOV 层级 token 构建用户/物品 META ID，兼顾记忆性与多样性，序列推荐 HR@10 最高提升 30%+。

    Language Representations Can be What Recommenders Need: Findings and Potentials

    揭示语言空间与推荐行为空间同构，提出纯语言表征的 AlphaRec，在 Amazon 三数据集 Full-Ranking 上超越 ID-based CF 6.8%–9.8%。

    R$^2$ec: Towards Large Recommender Models with Reasoning

    双头架构统一推理生成与物品打分，RecPO 融合奖励 RL 联合优化，Full-Ranking 下 NDCG@10 最高提升 72%。

    SLMRec: Distilling Large Language Models into Small for Sequential Recommendation

    发现 LLM 中间层冗余，用逐层分块特征蒸馏将 8 层教师压缩为 4 层学生，仅 13% 参数达 6.6x/8.0x 加速且性能不降。

    Think before Recommendation: Autonomous Reasoning-enhanced Recommender

    用纯 GRPO 强化学习替代教师蒸馏，让单个 LLM 自主习得「用户分析→物品分析→匹配→打分」推理链，评分预测 MAE 最高降 29.9%。

    Tree of Preferences for Diversified Recommendation

    用 LLM 构建粗到细偏好树挖掘欠探索兴趣并合成交互去偏，在 Twitter/Weibo/Amazon 上同时提升多样性与相关性。

    🗣️ 对话推荐与智能体仿真 (2)

    AgentRecBench: Benchmarking LLM Agent-based Personalized Recommender Systems

    首个 LLM 智能体推荐系统基准，构建 U-R-I 文本交互环境与三类场景，揭示结构化工作流智能体显著优于传统与朴素 Agent。

    Enhancing Personalized Multi-Turn Dialogue with Curiosity Reward

    将用户模型信念增益作为 PBRS 内在奖励注入多轮 RLHF，使 LLM 主动探询用户属性，习题推荐成功率 54%→87.5%。

    🧩 多模态推荐与内容理解 (2)

    Structured Spectral Reasoning for Frequency-Adaptive Multimodal Recommendation

    将多模态图信号分解为等能量频带，用频带掩码一致性训练、低秩超谱算子与谱对比正则实现频率自适应融合，全库排序下冷启动 Recall@20 提升约 10%。

    VisualLens: Personalization through Task-Agnostic Visual History

    用任务无关的日常照片历史构建“图像-描述-方面词”谱系画像，经检索+网格化+联合微调实现个性化推荐，Hit@3 超 UniMP 5-10%。

    📍 时空轨迹与 POI 本地生活推荐 (1)

    SPOT-Trip: Dual-Preference Driven Out-of-Town Trip Recommendation

    首次形式化异地行程推荐，用知识图谱静态偏好+Neural ODE动态偏好解耦建模，F1最高提升17.01%。

    🎯 CTR/CVR 预估与特征交叉 (1)

    Optimal Auction Design in the Joint Advertising

    联合广告单槽位Myerson最优机制+多槽位BundleNet束级IC约束神经网络，逼近理论最优并显著提升平台收益

    🎮 强化学习与动态探索推荐 (3)

    Learning Personalized Ad Impact via Contextual Reinforcement Learning under Delayed Rewards

    将自动出价建模为带延迟泊松奖励的CMDP，提出两阶段MLE与数据分割，实现个性化出价近最优遗憾界。

    MTRec: Learning to Align with User Preferences via Mental Reward Models

    用分布化逆强化学习(QR-IQL)从行为轨迹反推用户心理奖励分布，作为辅助对齐信号注入CTR/RL推荐模型，离线AUC/NCIS全面提升，工业短视频A/B观看时长+7%。

    Personalized Exercise Recommendation with Semantically-Grounded Knowledge Tracing

    ExRec 用 LLM 自动标注知识点+对比学习语义表征+KT 校准，并以 KT 模型做 Model-Based Value Estimation 稳定 Q-learning，在四个教育推荐任务上显著提升知识状态增益。

    🛡️ 去偏公平、可信隐私与工业架构 (6)

    Bridging Jensen Gap for Max-Min Group Fairness Optimization in Recommendation

    揭示MMF约束下小批量采样引发Jensen Gap，提出对偶重加权算法FairDual，在三个数据集六种骨干上同时提升准确率与公平性。

    FACTER: Fairness-Aware Conformal Thresholding and Prompt Engineering for Enabling Fair LLM-Based Recommender Systems

    用保形分位数阈值+违规触发提示工程，在黑盒 LLM 推荐器上闭环降低人口统计偏见，MovieLens 违规数降 95.5% 且精度基本不掉。

    ORBIT: Open Recommendation Benchmark for Reproducible Research with Hidden Tests

    统一可复现推荐基准，含5个公开数据集标准化划分与ClueWeb-Reco隐私安全网页推荐隐藏测试集，评测12个模型并引入LLM-QueryGen基线。

    RecFlow: An Industrial Full Flow Recommendation Dataset

    首个覆盖工业六阶段漏斗全流程的推荐数据集，含1.9B阶段样本，揭示训练-服务分布偏移并验证阶段样本作为难负例与级联蒸馏的显著收益。

    SecEmb: Sparsity-Aware Secure Federated Learning of On-Device Recommender System with Large Embedding

    用 FSS 点函数对稀疏物品嵌入更新做无损安全聚合，通信降 90x、端侧计算降 70x 且不泄露评分物品索引。

    Truthful Aggregation of LLMs with an Application to Online Advertising

    MOSAIC 用重要性采样+循环单调性支付实现 LLM 广告拍卖的真实报价与最优分布收敛，20 候选即近最优。
