    🏛️ SIGIR 2025 推荐系统论文解读

    86 篇 SIGIR 2025 论文解读，覆盖 15 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🤝 协同过滤与双塔召回 (3)

    A Learnable Fully Interacted Two-Tower Model for Pre-Ranking System

    用可学习 Item Meta Matrix 实现显式早期交互、行/列 FC 相似度矩阵实现晚期交互，在保持双塔解耦推理效率下 AUC 相对提升 4.6%–14.3%。

    Graph Spectral Filtering with Chebyshev Interpolation for Recommendation

    用切比雪夫插值逼近非线性图滤波器，直接以原始交互为信号，突破 LightGCN 的截断线性低通瓶颈，Full-Ranking 下全面 SOTA 且推理快 8.1 倍。

    IRA: Adaptive Interest-aware Representation and Alignment for Personalized Multi-interest Retrieval

    用可累积/剪枝的文本化 Interest Unit 表征多兴趣，语义对齐替代点击信号做 ANN 召回，离线 H@20 提升 20%，线上点击 +5.4%。

    🕸️ 图神经网络与知识图谱推荐 (2)

    Benchmarking Recommendation, Classification, and Tracing Based on Hugging Face Knowledge Graph

    构建 260 万节点 HuggingKG 与三任务 HuggingBench，揭示稀疏领域 KG 上 KGRec 类方法失效、TransE 反超复杂模型的关键现象。

    Comprehending Knowledge Graphs with Large Language Models for Recommender Systems

    用 LLM 理解 KG 局部子图并构建语义物品图做全局检索增强，离线预计算语义嵌入后接入 LightGCN，全库排序下全面超越 12 个基线。

    🔄 自监督对比学习与交互去噪 (1)

    Squeeze and Excitation: A Weighted Graph Contrastive Learning for Collaborative Filtering

    仅扰动末层GCN视图并用SENet动态加权特征，在三个数据集上实现最高24.45%的NDCG@20提升。

    ⏱️ 序列与会话推荐 (12)

    AI Guided Accelerator For Search Experience

    挖掘电商查询转移链并做意图一致性过滤，再用 Solar-10B 指令微调生成多样化替代收敛查询，线上 CTR +32.2%、转化 +38.3%。

    AlphaFuse: Learn ID Embeddings for Sequential Recommendation in Null Space of Language Embeddings

    将语言嵌入 SVD 分解为语义丰富行空间与语义稀疏零空间，在裁剪后的零空间内学习 ID 嵌入，无需适配器即插即用地融合语义与协同信号。

    CSRec: Rethinking Sequential Recommendation from A Causal Perspective

    将序列推荐重构为因果干预下的决策接受概率建模，用递归约束隔离系统影响，AHR@0.2 提升约 1.5–3 倍。

    Data Augmentation as Free Lunch: Exploring the Test-Time Augmentation for Sequential Recommendation

    将数据增强从训练期迁移到推理期，提出 TNoise 与 TMask 两个免训练、免参数的测试时增强算子，在 Full-Ranking 协议下平均提升 14%–30%。

    DIFF: Dual Side-Information Filtering and Fusion for Sequential Recommendation

    频域滤波去噪 + 早期/中间双重融合的侧信息序列推荐，Full-Ranking 下 R@20 最高提升 14.1%

    FIM: Frequency-Aware Multi-View Interest Modeling for Local-Life Service Recommendation

    多视图搜索分离本地生活多周期需求，FFT 频域感知演化建模周期兴趣，Kuaishou 线上 GMV +8.46%。

    HeterRec: Heterogeneous Information Transformer for Scalable Sequential Recommendation

    将物品拆解为异构特征 token 序列并设计层级因果 Transformer 与列表级多步预测损失，在工业与 Amazon 数据上 Recall@100 提升 3.8%–4.2%。

    Improving Sequential Recommenders through Counterfactual Augmentation of System Exposure

    用 Decision Transformer 建模全量曝光序列，并以随机/自改进反事实增广+用户模拟器挖掘未曝光兴趣，KuaiRand 上 Recall@20 相对提升约 87%。

    Intent-aware Diffusion with Contrastive Learning for Sequential Recommendation

    用 K-means 意图原型引导条件扩散生成意图对齐正视图替代随机增强，在 5 个数据集 Full-Ranking 下 NDCG 平均提升 20.68%。

    Linear Item-Item Model with Neural Knowledge for Session-based Recommendation

    将神经会话模型的转移知识蒸馏为物品-物品矩阵正则项，与线性自蒸馏相似度统一闭式求解，R@20 最高提升 14.78% 且推理 FLOPs 降低 813 倍。

    ✨ 生成式推荐与离散语义 ID (4)

    Addressing Missing Data Issue for Diffusion-based Recommendation

    用双侧 Thompson 采样在引导序列中模拟缺失数据，以一致性正则化让扩散推荐模型外推抵抗真实缺失，YooChoose NDCG@20 提升 26.95%。

    Generative Recommender with End-to-End Learnable Item Tokenization

    提出 ETEGRec 双编码器-解码器框架，用序列-物品对齐与偏好-语义对齐将 RQ-VAE 分词器与 T5 推荐器端到端联合优化，全库排序下 Recall@10 相对 LETTER 提升约 5%。

    Killing Two Birds with One Stone: Unifying Retrieval and Ranking with a Single Generative Recommendation Model

    将召回与排序统一为单生成模型的位置级序列生成任务，配合排序驱动增强器与梯度自适应加权实现协同与同步优化，全库排序下召回排序双提升。

    Order-agnostic Identifier for Large Language Model-based Generative Recommendation

    提出无序集合标识符范式，用CF+语义多token集合表示物品并同时生成，T5上Recall@10平均提升约50%，推理提速8-18倍。

    🧠 大语言模型推荐 (LLM4Rec) (14)

    ADORE: Autonomous Domain-Oriented Relevance Engine for E-commerce

    用 CoT-LLM 自动挖掘难样本、KTO 对齐用户行为、错误类型感知合成对抗样本，再以关键属性显式蒸馏到轻量 BERT，离线 F1 85.45%、线上 CTR +1.24%。

    CORONA: A Coarse-to-Fine Framework for Graph-based Recommendation with Large Language Models

    用 LLM 做偏好/意图推理在交互图上逐级缩小候选子图，再由 GNN 精排，全库排序下 Recall 平均相对提升 18.6%。

    Do LLMs Memorize Recommendation Datasets? A Preliminary Study on MovieLens-1M

    用少样本提示探测 GPT/Llama 对 MovieLens-1M 的物品、用户与交互记忆覆盖率，揭示记忆量与推荐性能强相关且放大流行度偏置。

    Efficiency Unleashed: Inference Acceleration for LLM-based Recommender Systems with Speculative Decoding

    将检索式推测解码引入 LLM 离线知识生成，用定制检索池与松弛验证实现 3-5× 无损加速，线上省 67% 算力。

    Improving LLM-powered Recommendations with Personalized Information

    将用户偏好与物品感知两条 CoT 显式抽取并注入 CRM 召回与 LLM 重排，Leave-One-Out 全库排序下 Hit@10 最高提升约 11%，并显著降低位置偏差。

    Intent Representation Learning with Large Language Model for Recommendation

    用 LLM 思维链抽取文本意图，与交互意图双塔对齐+动量蒸馏匹配，作为模型无关插件在三个数据集上稳定提升 Recall/NDCG。

    Large Language Models Enhanced Hyperbolic Space Recommender Systems

    HyperLLM 用 LLM 生成层级标签与偏好摘要，经元优化两阶段训练将结构/语义层级信息注入双曲推荐，Recall@20 最高提升 41.7%。

    MSL: Not All Tokens Are What You Need for Tuning LLM as a Recommender

    提出掩码 Softmax 损失屏蔽虚构物品 token，并配自适应温度策略，四数据集 NDCG@10 平均提升 42.24%。

    Multi-Grained Patch Training for Efficient LLM-based Recommendation

    用层次化 item/session patch 压缩长交互历史，两阶段训练让 LLM 理解压缩表征，同 token 预算下 HR@20 最高提升 72%。

    Pre-train, Align, and Disentangle: Empowering Sequential Recommendation with Large Language Models

    用 MK-MMD 特征核做推荐锚定对齐，再以三专家频率门控解耦，Full-Ranking 下冷物品 HR@10 提升最高 462%。

    🗣️ 对话推荐与智能体仿真 (7)

    AgentCF++: Memory-enhanced LLM-based Agents for Popularity-aware Cross-domain Recommendations

    以双层记忆+两步融合+兴趣组共享记忆，令 LLM 用户智能体在跨域场景显式建模流行度影响，采样排序 MRR 平均超 AgentCF 14.6%。

    Agentic Feedback Loop Modeling Improves Recommendation and User Simulation

    用记忆驱动的推荐智能体-用户智能体多轮反馈闭环，同时提升下一物品推荐与用户行为模拟，并验证不放大流行度/位置偏差。

    MSCRS: Multi-modal Semantic Graph Prompt Learning Framework for Conversational Recommender Systems

    构建协同/文本/图像三模态语义图并以共享嵌入融合，图提示注入 DialoGPT，ReDial 与 INSPIRED 全指标 SOTA。

    PSCon: Product Search Through Conversations

    提出人-人教练式采集协议构建双市场双语真实 CPS 数据集 PSCon，定义六子任务流水线并给出 Transformer 统一基准模型。

    PUB: An LLM-Enhanced Personality-Driven User Behaviour Simulator for Recommender System Evaluation

    用大五人格驱动 LLM Agent 生成合成交互日志，Jaccard 相似度 0.31 逼近真实序列，并复现 7 种推荐算法的 nDCG 排序趋势。

    Search-Based Interaction For Conversation Recommendation via Generative Reward Model Based Simulated User

    用生成式奖励模型构建无标签模拟用户，通过属性评论与生成式打分驱动束搜索交互，INSPIRED 上 Recall@10 相对最优基线提升 83%。

    Simulating Before Planning: Constructing Intrinsic User World Model for User-Tailored Dialogue Policy Planning

    用扩散模型刻画用户画像、布朗桥预判用户反馈，构建内在用户世界模型以定制对话策略，P4G/ESConv 上 SR 显著提升。

    🧩 多模态推荐与内容理解 (6)

    COHESION: Composite Graph Convolutional Network with Dual-Stage Fusion for Multimodal Recommendation

    用行为模态早期精炼+晚期注意力融合的双阶段融合，配合异质/同质复合图与自适应BPR，在三个 Amazon 数据集上 R@20 相对提升 4.4%–6.1%。

    Diffusion-based Multi-modal Synergy Interest Network for Click-through Rate Prediction

    用 PLE 式共享/独有专家解耦模态知识、以扩散式多步跨模态去噪捕捉协同信号，FDAF 非侵入融合，四数据集 AUC 全面领先。

    Disentangling and Generating Modalities for Recommendation in Missing Modality Scenarios

    将模态特征解耦为通用/特有分量并用互信息损失分离，再以跨模态对齐特征与用户模态偏好生成缺失模态，缺失场景全库排序 R@20 相对提升 4.7%–8.2%。

    Multi-Modal Multi-Behavior Sequential Recommendation with Conditional Diffusion-Based Feature Denoising

    用条件扩散分别对模态与行为特征去噪，并以多专家网络解耦共性/特性兴趣，在 Rec-Tmal/Kuaishou 上 HR@10 提升约 4-8%。

    Short Video Segment-level User Dynamic Interests Modeling in Personalized Recommendation

    将短视频切分为5秒片段，用CLIP视觉+ID双模态跨注意力建模片段级动态兴趣，以段内排序损失解决标签缺失，在跳看预测与视频推荐两任务上大幅超越基线。

    U-Sticker: A Large-Scale Multi-Domain User Sticker Dataset for Retrieval and Personalization

    构建含 22K 用户、370K 贴纸、8.3M 消息的多领域多语言贴纸数据集，支撑个性化贴纸检索与用户建模。

    👥 社交与群组推荐 (2)

    FROG: Effective Friend Recommendation in Online Games via Modality-aware User Preferences

    面向在线游戏好友推荐，用模态感知双向匹配+局部/全局双路注意力建模用户偏好，离线 HR/NDCG 最高提升 15.82%/14.59%，线上 accRate 提升 33.3%。

    Invariance Matters: Empowering Social Recommendation via Graph Invariant Learning

    用图不变学习替代社交图硬过滤：多环境生成器+不变风险最小化+对抗环境探索，Full-Ranking 下 NDCG@20 较 GBSR 提升 5.4%–8.7%。

    🌐 跨域与多场景推荐 (6)

    Adaptive Domain Scaling for Personalized Sequential Modeling in Recommenders

    用域特征动态生成序列物品的个性化MLP权重与候选物品的多查询表示，改造目标注意力实现多域序列建模，抖音双场景线上GMV+0.79%、ADVV+1.00%。

    Adaptive Graph Integration for Cross-Domain Recommendation via Heterogeneous Graph Coordinators

    用异质自适应图协调器把多域图拼成统一结构做多域预训练，再以图提示迁移到目标域，Full-Ranking 下全面超越 9 个基线。

    Bridge the Domains: Large Language Models Enhanced Cross-domain Sequential Recommendation

    用 LLM 语义嵌入+分层画像桥接跨域物品与用户偏好，破解重叠困境与转移复杂性，三数据集 H@10 最高提升 31.7%。

    CDC: Causal Domain Clustering for Multi-Domain Recommendation

    用孤立/混合双亲和矩阵+因果发现系数自适应融合，联合优化目标域簇与训练源域集，50+域上DomainAUC提升4.14‰/6.76‰，线上eCPM+4.9%

    Learning Universal User Representations Leveraging Cross-domain User Intent at Snapchat

    将 Snapchat 多业务面事件拼接为统一序列训练 Transformer 用户塔，产出跨域通用用户表征，线上多场景 A/B 全面正向。

    X-Cross: Dynamic Integration of Language Models for Cross-Domain Sequential Recommendation

    逐层动态集成多个 LoRA 源域语言模型，仅用 25% 参数与 50-75% 更少微调数据即达/超 LoRA 跨域序列推荐效果。

    📍 时空轨迹与 POI 本地生活推荐 (2)

    CoMaPOI: A Collaborative Multi-Agent Framework for Next POI Prediction Bridging the Gap Between Trajectory and Language

    用 Profiler/Forecaster/Predictor 三智能体把数值轨迹转语言画像、动态收缩候选集并反向推理微调，三数据集全指标提升 4%–12%。

    SEP-GCN: Leveraging Similar Edge Pairs with Temporal and Spatial Contexts for Location-Based Recommender Systems

    以时空相似交互边对构建边级相似图并注入LightGCN传播，在NYC/Gowalla/Brightkite全库排序上Recall@20最高提升14.89%。

    🎯 CTR/CVR 预估与特征交叉 (8)

    Deep Multiple Quantization Network on Long Behavior Sequence for Click-Through Rate Prediction

    用多码本量化将超长行为序列端到端压缩为约百个兴趣簇码字，配合 HSTU 簇间交互与候选感知注意力，消除两阶段检索的相关性分布偏差，线上 CTR +3.5%、RPM +2.0%。

    DLF: Enhancing Explicit-Implicit Interaction via Dynamic Low-Order-Aware Fusion for CTR Prediction

    以残差感知低阶交互网络与逐层注意力融合，动态平衡显隐式特征交叉，四数据集AUC全面SOTA。

    ELEC: Efficient Large Language Model-Empowered Click-Through Rate Prediction

    伪孪生增益/朴素双网络+分数级CLID与表示级MSE双蒸馏，在线仅跑表格DCNv2，AUC较FLIP提升0.0020/0.0034。

    Hybrid Advertising in the Sponsored Search

    提出混合广告拍卖模型与 HRegNet 神经网络机制，在近 DSIC/IR 约束下联合优化独立店铺与店铺-品牌捆绑包的广告位分配与定价，真实数据上收益显著超越 VCG 与 JRegNet。

    Interest Changes: Considering User Interest Life Cycle in Recommendation System

    用曝光/点击/交互直方图+VQ聚类刻画兴趣生命周期，经特征重校准与专家网络融合注入MMOE精排，Lofter线上CTR+0.38%、CVR+1.04%。

    LREA: Low-Rank Efficient Attention on Modeling Long-Term User Behaviors for CTR Prediction

    用低秩分解+矩阵吸收把万级长行为序列压到秩 r 维做目标注意力，配非负正则保非线性，线上仅增 3ms 延迟、CTR +5.88%。

    Multi-objective Aligned Bidword Generation Model for E-commerce Search Advertising

    用判别器提供相关性/真实性/CPM三维奖励，扩展MODPO做多目标偏好对齐，驱动LLM生成高商业价值竞价词，线上广告收入+2.13%。

    NAM: A Normalization Attention Model for Personalized Product Search In Fliggy

    用逆物品频率(IIF)对注意力做全局归一化并门控个性化强度，解决热门物品高估/长尾低估，离线CTCVR AUC+0.001、线上CTCVR+0.8%。

    ⚖️ 多任务学习与列表级重排 (4)

    Comprehensive List Generation for Multi-Generator Reranking

    提出多生成器-评估器重排框架与列表全面性指标，用 CLIG 自动学习互补生成器，离线 AUC 提升 0.9%、线上观看时长 +0.48%。

    CSMF: Cascaded Selective Mask Fine-Tuning for Multi-Objective Embedding-Based Retrieval
