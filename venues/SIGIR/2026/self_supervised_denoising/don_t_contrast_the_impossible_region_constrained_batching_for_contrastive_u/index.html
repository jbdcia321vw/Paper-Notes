    TL;DR (核心速览)

    本地社区平台（Karrot）的曝光受地理半径硬约束，标准 in-batch 负采样把“平台根本不会曝光”的用户-物品对当作负例，产生大量不可能负例 (impossible negatives)，稀释对比信号。本文提出 Region-Constrained Batch Sampling (RCBS)：仅改变 mini-batch 的构造方式（按区域同质采样用户），不改模型架构与 InfoNCE 损失，把不可能负例比例 \(\rho_{train}\) 从 0.98 降到 0.30，等价于自动引入更难的可行负例。离线 R@10 从 0.100 提升至 0.149（+49%），下游首页召回 R@10 +7.56%、广告排序 PR-AUC +3.38%，线上 A/B 点击 +10.0%、广告 CTR +7.46%，已全量上线。

    Background & Motivation (背景与动机)

    • 领域背景与主流范式: 大规模推荐系统的用户表征学习已形成“行为序列 + 双塔 + InfoNCE 对比预训练”的标准范式（PinnerFormer、PinFM、Meta 用户表征 scaling 等）。其隐含假设是 universal exposure：任意用户都可能被曝光任意物品，因此 batch 内其他正例物品可安全地当作负例。
    • 现有方法局限 (Limitations of Prior Work):
    • 曝光可行性被忽略：Karrot 上 86% 以上交易发生在 5km 半径内，用户只能看到同区域或相邻区域的物品；随机 batch 中绝大多数负例是“平台策略决定永不曝光”的物品，非参与并不反映偏好。
    • IPS 类去偏方法失效：IPS 需要 positivity assumption（每个 user-item 对曝光概率严格为正），而地理策略造成结构性 positivity violation（不可能对的曝光概率恒为 0），没有可重加权的观测交互。
    • 显式难负例挖掘成本高：现有 hard-negative mining（VSE++、SimCSE、RocketQA、混合负采样、跨 batch 负采样）需要额外检索/合成/维护负例池，工业落地代价大。
    • 核心挑战 (Key Challenge): 在曝光受地理硬约束的场景下，如何在不改模型、不加算力的前提下，让对比学习的负例分布与真实曝光分布对齐？
    • 核心洞察与切入点 (Key Insight): 作者将负例二分为 feasible negatives（可曝光但用户未交互，携带真实偏好信号）与 impossible negatives（因平台规则永不曝光，信号≈噪声）。关键观察是：可行负例天然比不可能负例更难——因为可行负例与正例同区域、特征更相似，模型必须学得更细才能区分。因此只需把 batch 构造成区域同质，即可“免费”获得难负例。

    Problem Formulation & Method (问题定义与方法架构)

    1. 符号定义与输入表征 (Notations & Input Representations)

    • 用户集 \(\mathcal{U}\)，物品集 \(\mathcal{I}\)；用户 \(u\) 的行为序列 \(S_u=\{s_{u,1},\dots,s_{u,T}\}\)，其中 \(s_{u,t}=(a_{u,t},\tau_{u,t},i_{u,t})\) 分别为动作类型（点击/观看/聊天）、时间戳、交互物品，\(i_{u,t}\in\mathcal{I}\)。
    • 用户塔 \(f_{\text{user}}\)（Pre-LN Transformer）输出 \(H_u=\{h_{u,t}\}_{t=1}^{T}=f_{\text{user}}(S_u)\in\mathbb{R}^{T\times d}\)；物品塔 \(f_{\text{item}}\)（3 层 MLP）输出 \(v_i=f_{\text{item}}(i)\in\mathbb{R}^d\)。
    • 双方 \(\ell_2\) 归一化，亲和度 \(s(h_{u,t},v_i)=h_{u,t}^\top v_i\)。
    • 区域划分：地理空间离散为区域单元 \(r\in\mathcal{R}\)，映射函数 \(r(u)\)、\(r(i)\)；用户特定曝光半径 \(\delta_u\in\{0,1,2,\dots\}\)（由平台策略/用户配置决定）。

    2. 整体流水线 (Overall Architecture)

    flowchart TD
    A["输入层: 用户行为序列 S_u (截断 1024) + 物品多模态特征 (标题/正文/元数据/图像经预训练嵌入模型)"] --> B["区域约束批采样 RCBS: 按 r(u) 采样区域同质 mini-batch B_r"]

    3. 核心模块设计与数学原理 (Key Designs & Formulations)

    (1) 曝光可行性定义 (Exposure Feasibility)

    \[\text{feas}(u,i)=\mathbb{1}\left[\text{dist}\big(r(u),r(i)\big)\le \delta_u\right]\]

    其中 \(\text{dist}(\cdot,\cdot)\) 为区域单元间非负对称距离，\(\delta_u\) 为用户特定曝光半径（以区域单元计）。\(\delta_u=0\) 要求精确同区域，\(\delta_u>0\) 纳入相邻区域。不可能负例定义为 \(\text{feas}(u,i)=0\) 的负例物品。物理直觉：把“平台策略”从“用户偏好”中剥离出来。

    (2) 区域约束批采样 (RCBS)

    \[\mathcal{B}_r=\{(u_b,S_{u_b})\}_{b=1}^{M},\quad u_b\sim\text{Uniform}(U_r),\ U_r=\{u\in\mathcal{U}\mid r(u)=r\}\]

    即每个 mini-batch 只从单一区域 \(r\) 的用户池中采样。由于同 batch 用户共享曝光约束，batch 内绝大多数物品对每个用户都是可行负例。

    (3) 不可能负例比例的理论刻画

    精确区域匹配（\(\delta_u=0\)）下，batch 内不可能负例期望比例为：

    \[\rho=1-\sum_{r\in\mathcal{R}}p_r^2\]

    其中 \(p_r\) 为 batch 中用户属于区域 \(r\) 的概率。随机采样时 \(p_r\) 近似均匀，\(\rho\approx 1-\frac{1}{\min(|\mathcal{B}|,|\mathcal{R}|)}\)，随系统规模增大而恶化；RCBS 将概率质量集中于单一区域（\(p_r\approx 1\)），\(\rho\to 0\)，且与 batch size 和区域数无关。这是本文最漂亮的理论论证：随机 batch 的负例质量会随平台扩张而系统性退化，RCBS 则免疫。

    实践中 \(\rho\) 不会严格为 0，原因有二：(i) 用户 \(\delta_u\) 不同，大半径用户的可行物品对小半径用户可能不可行；(ii) 用户搬迁导致历史交互跨区域。

    (4) 与 IPS 的关系（互补而非替代）

    IPS 是 loss 级校正（按逆曝光概率重加权观测交互），要求 \(p(o=1\mid u,i)>0\)；RCBS 是 data 级校正（改变 Eq.(4) 分母中出现哪些物品）。不可能对曝光概率恒为 0，IPS 无从重加权；RCBS 先保证 batch 由可行对构成，IPS 再在区域同质 batch 内校正残余曝光不均衡。二者可叠加。

    4. 训练目标、负采样与推理复杂度 (Optimization, Negative Sampling & Complexity)

    • 损失函数: 标准 InfoNCE（温度 \(\tau>0\)），未做任何修改：
    \[\mathcal{L}_{\text{NCE}}=-\frac{1}{BT}\sum_{b=1}^{B}\sum_{t=1}^{T}\log\frac{\exp\!\big(s(h_{b,t},v^+_{b,t})/\tau\big)}{\sum_{b'=1}^{B}\sum_{t'=1}^{T}\exp\!\big(s(h_{b,t},v^+_{b',t'})/\tau\big)}\]
    • 训练负采样策略: In-batch 负采样，但负例池由 RCBS 的区域同质 batch 决定。batch size \(B=18\)，序列长度 \(T=1024\)，每 mini-batch 共 \(18\times1024=18{,}432\) 个候选。原文未报告 \(\tau\) 的具体取值。
    • 时间与空间复杂度: 原文未报告训练单 epoch 耗时、峰值显存或在线推理延迟（ms/request）。RCBS 仅改变采样器，理论复杂度与随机 batch 完全一致（无额外前向/反向、无额外负例池存储），这是其工业价值的核心。用户表征每日离线计算（最近 1024 行为过用户塔后 mean-pool），下游以特征/塔注入方式使用。

    2. 消融实验与控制变量分析 (Ablation Study)

    原文未设传统“逐模块移除”消融，而是以批采样粒度作为核心控制变量：

    • Random-Train → RCBS-Train (coarse) → RCBS-Train (fine)：\(\rho_{train}\) 从 0.98 → 0.79 → 0.30，R@10 从 0.100 → 0.125 → 0.149，单调对应，直接验证“不可能负例比例越低、表征越好”的核心假设。
    • 控制变量严格性：batch size (18)、序列长度 (1024)、所有超参与训练步数完全固定，仅改变采样器，是干净的对照。但未做参数量对齐/图度数匹配类消融（本文无图结构，不适用）。
    • 评估期 batch 作为额外探针：RCBS-Eval 分数低于 Random-Eval，构成对“可行负例更难”的间接消融证据。

    • 长尾/冷启动分桶: 原文未报告按用户交互频次或物品热度分桶的细分结果。

    Highlights, Limitations & Critiques (亮点、局限与审稿级批判)

    • 核心亮点与可迁移性:
    • 问题定义精准且具普适性：将“曝光可行性”形式化为 \(\text{feas}(u,i)\)，把 impossible negatives 从“难负例”话语中独立出来，可迁移到外卖/生鲜（服务区约束）、约会（距离阈值）、招聘（地域）等一切 location-aware 推荐。
    • 零成本工业方案：不改模型、不改损失、不加算力，仅改 DataLoader 采样器，理论复杂度不变，这是 Industry Track 最看重的属性。
    • 理论刻画有说服力：\(\rho=1-\sum_r p_r^2\) 揭示了随机 batch 的负例质量随平台规模系统性退化，而 RCBS 免疫，给出了“为什么现在必须做”的论证。
    • 与 IPS 的互补性论述清晰：data-level vs loss-level 校正的分工，为后续“RCBS + IPS”组合留出接口。
    • 局限性与审稿视角批判 (Critical Limitations):
    • 评估协议披露不足：Recall 的候选池规模、是否 Full-Ranking、\(\tau\) 取值、训练耗时/显存均未报告，复现性受限（虽为工业保密可理解，但削弱学术说服力）。
    • 无统计显著性检验：离线与线上均未报告置信区间、多随机种子方差或配对检验，+0.53% 这类小幅增益（广告 R-A）的可靠性存疑。
    • 区域同质 batch 的副作用未讨论：batch 内用户高度同质会降低负例的跨区域多样性，可能损害跨区域泛化；对冷启动/搬迁用户（\(\rho\) 无法降为 0 的两类情形）缺乏专门分析。
    • 粒度选择依赖人工：coarse/fine 区域划分是手工设定，作者在结论中也承认“自适应区域分组”是未来工作，当前缺少自动选择机制。
    • baseline 偏弱：仅对比 Random-Train，未与显式 hard-negative mining（如跨 batch 负采样、混合负采样）或 IPS+CL 组合对比，无法证明 RCBS 优于“已有难负例方案”。
    • 理论假设较强：\(\rho\) 公式假设 \(\delta_u=0\) 且区域分布均匀，实际 \(\delta_u\) 异构时理论界不再紧。
