    🏛️ SIGIR 2026 推荐系统论文解读

    54 篇 SIGIR 2026 论文解读，覆盖 14 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🤝 协同过滤与双塔召回 (1)

    CS3: Efficient Online Capability Synergy for Two-Tower Recommendation

    提出 CAS/CTS/CMS 三模块协同增强双塔召回，兼容在线学习，离线三数据集 AUC 提升，线上广告收入最高 +8.36% 且保持毫秒级延迟。

    🕸️ 图神经网络与知识图谱推荐 (1)

    DCGL: Dual-Channel Graph Learning with Large Language Models for Knowledge-Aware Recommendation

    双通道解耦LLM语义与ID行为信号，多级对比学习对齐，频率感知门控自适应融合，稀疏场景显著提升

    🔄 自监督对比学习与交互去噪 (2)

    AsarRec: Adaptive Sequential Augmentation for Robust Self-supervised Sequential Recommendation

    将五种序列增强统一为半双随机变换矩阵，用可微 Semi-Sinkhorn 自适应学习用户级增强，在噪声序列推荐上 Full-Ranking 显著提升。

    Don't Contrast the Impossible: Region-Constrained Batching for Contrastive User Modeling on a Local Community Platform

    针对本地社区平台地理曝光约束下的“不可能负例”问题，提出区域约束批采样 RCBS，仅改批构造不改模型与损失，离线与线上 A/B 均显著提升召回与排序。

    ⏱️ 序列与会话推荐 (5)

    Beyond Item IDs: Scaling Short-Form-Video Recommendation via Semantic-Native Long Sequence Modeling

    用深度截断 Bi-gram 语义ID替代正交Video ID，并以无参时间折叠压缩超长序列，在十亿用户短视频平台实现L=2000序列建模与线上显著增益。

    CASE: Cadence-Aware Set Encoding for Large-Scale Next Basket Repurchase Recommendation

    用日历时间二值信号+共享多尺度时序CNN+ISAB集合编码做下一篮复购推荐，全库候选排序下离线与生产均显著提升

    FLAME: Condensing Ensemble Diversity into a Single Network for Efficient Sequential Recommendation

    用冻结+可学习双网络的模块化集成模拟指数级多样性，推理仅用单网络实现零开销的集成级序列推荐。

    Pay Attention to Sequence Split: Uncovering the Impacts of Sub-Sequence Splitting on Sequential Recommendation Models

    揭示子序列切分(SSS)在数据读取阶段被隐性使用导致SR模型评估失真，系统分析SSS生效条件与机理并给出公平评估建议

    WPGRec: Wavelet Packet Guided Graph Enhanced Sequential Recommendation

    用平稳小波包变换生成等长平移不变子带，逐子带做 Chebyshev 图传播并以能量-谱平坦度门控融合，全排序协议下稀疏数据集 HR@20 提升 15.4%

    ✨ 生成式推荐与离散语义 ID (6)

    FAVE: Flow-based Average Velocity Establishment for Sequential Recommendation

    用语义锚先验替代高斯噪声并学习全局平均速度场，实现单步流匹配生成式序列推荐，全库排序下NDCG@20相对提升9.90%且推理加速20倍以上。

    Gated Bidirectional Linear Attention for Generative Retrieval

    提出线性时间双向注意力 GBLA，以 Conv1D+Key Gating+Gated RMSNorm 三件套替换编码器自注意力，混合 1:2 堆叠在 Yandex Music 上持平双向 SA 质量，L=32768 单层提速 8.2×。

    GenRec: A Preference-Oriented Generative Framework for Large-Scale Recommendation

    提出 Page-wise NTP + 线性 Token Merger + GRPO-SR 偏好对齐的工业级生成式召回框架，京东线上点击 +9.5%、成交 +8.7%。

    Learning Decomposed Contextual Token Representations from Pretrained and Collaborative Signals for Generative Recommendation

    DECOR 通过分解嵌入融合保留冻结预训练码本语义、上下文化 token 组合动态消歧，在 Amazon 三数据集 Full-Ranking 下 NDCG@10 最高提升 14%。

    Semantic IDs for Recommender Systems at Snapchat: Use Cases, Technical Challenges, and Design Choices

    Snapchat 工业级 SID 落地实践：STE 全码本反传与多模态融合缓解码本坍缩，启发式桶内消歧解决 SID-Item 碰撞，离线与线上 A/B 双验证。

    SIGMA: A Semantic-Grounded Instruction-Driven Generative Multi-Task Recommender at AliExpress

    多视图语义对齐+混合 SID/ID 分词+指令驱动多任务 SFT+三步生成与自适应概率融合，AliExpress 线上 GMV +7.84%

    🧠 大语言模型推荐 (LLM4Rec) (13)

    ACE: Anisotropy-Controllable Embedding for LLM-enhanced Sequential Recommendation

    用线性自编码器的谱收缩算子连续调控 LLM 物品嵌入的各向异性，在 Full-Ranking 留一法协议下 Recall@20 最高提升 12.4%。

    BEAR: Towards Beam-Search-Aware Optimization for Recommendation with Large Language Models

    揭示 SFT 训练与束搜索解码的训练-推理不一致，提出束搜索感知正则 BEAR，四数据集平均提升 12.50%

    Beyond Static Best-of-N: Bayesian List-wise Alignment for LLM-based Recommendation

    提出 BLADE 贝叶斯动态估计框架，融合静态先验与实时 rollout 证据构建自演化目标，突破静态 BoN 对齐的性能上界，在 NDCG/Recall/公平性/多样性上全面超越基线。

    Every Preference Has Its Strength: Injecting Ordinal Semantics into LLM-Based Recommenders

    将显式评分建模为序数语义锚点，在LLM隐空间做强度感知对齐，保留细粒度偏好强度，成对偏好准确率最高提升44.9%。

    Filling the Gaps: Selective Knowledge Augmentation for LLM Recommenders

    提出 KnowSA_CKP，用比较式知识探测量化 LLM 对物品的协同知识缺口，仅对知识贫乏物品做选择性增强，免微调提升 Recall@1 与上下文效率。

    ItemRAG: Item-Based Retrieval-Augmented Generation for LLM-Based Recommendation

    将 RAG 从粗粒度用户历史检索转向细粒度物品级检索，融合共购与语义信息为每个物品生成摘要，标准与冷启场景全面超越用户级 RAG 基线。

    L2Rec: Towards Dual-View Understanding of LLMs for Personalized Recommendation

    在 LLM 参数空间用双视图个性化 MoE (LoRA) 分别适配行为/语义视图，ACF 融合，四数据集 N@10 提升 3.87%–8.02%，线上 CTR +9.24%。

    Modular Representation Compression: Adapting LLMs for Efficient and Effective Recommendations

    揭示 LLM 中间层表示优势 (MRA) 现象，提出模块化解耦压缩框架 MARC，将 4096 维 LLM 表示压缩至 128 维，线上 A/B 测试 eCPM 提升 2.82%。

    Multimodal Large Language Models with Adaptive Preference Optimization for Sequential Recommendation

    面向 MLLM 序列推荐，提出难度感知重加权 (HaRS) 与噪声正则分布优化 (NoDO) 改进 DPO，在三个数据集上 NDCG@3 相对提升 7.39%–11.02%。

    Personalized Deep Research: A User-Centric Framework, Dataset, and Hybrid Evaluation for Knowledge Discovery

    将用户画像注入深度研究检索-推理闭环，构建四任务个性化基准与混合评测，个性化指标大幅领先商业系统。

    🗣️ 对话推荐与智能体仿真 (5)

    Bridging Passive and Active: Enhancing Conversation Starter Recommendation via Active Expression Modeling

    用对抗分布对齐+语义离散化把用户主动查询引入 Conversation Starter 推荐，打破曝光-点击闭环，离线 AUC +6.72%、线上特征渗透率 +0.54%

    Conv-FinRe: A Conversational and Longitudinal Benchmark for Utility-Grounded Financial Recommendation

    提出首个对话式纵向股票推荐基准，用逆优化推断用户潜在风险偏好，构建效用/动量/风险/用户选择四视图参考，诊断 LLM 是理性分析、行为模仿还是追涨杀跌。

    Meituan Merchant Business Diagnosis via Policy-Guided Dual-Process User Simulation

    从行为轨迹挖掘决策策略作为共享对齐层，锚定 LLM 语义推理与 ML 统计拟合双过程分支，群体模拟误差降至 8.80%。

    Task-Aware Automated User Profile Generation for Recommendation Simulation Using Large Language Models

    提出免训练三阶段自动画像生成框架 APG4RecSim，在 Full-Ranking 式判别/排序/评分任务上 nDCG@10 提升约 7%、JSD 降低约 8%。

    When and How to Ask: Dynamic Preference Elicitation Strategies for Conversational Recommendation

    提出 InPE 标注数据集与 COPE 混合专家架构，将对话推荐建模为结构化动作空间上的序贯决策，实现阶段感知的偏好诱导策略动态切换。

    🧩 多模态推荐与内容理解 (3)

    A General Framework for Multimodal LLM-Based Multimedia Understanding in Large-Scale Recommendation Systems

    用 LLaMA2-1.5B+BLIP-2 将图像转为 caption 并 tokenize 为类别特征注入 DLRM 精排，离线 AUC +0.35%、线上 +0.02%。

    Discrete Preference Learning for Personalized Multimodal Generation

    用模态专属LightGCN+RQ-VAE将连续偏好量化为离散token注入LLM/扩散生成器，配合跨模态一致性奖励实现个性化图文生成。

    Well Begun is Half Done: Training-Free and Model-Agnostic Semantically Guaranteed User Representation Initialization for Multimodal Recommendation

    提出免训练、模型无关的 SG-URInit，用交互物品模态特征+聚类全局语义初始化用户表征，弥合用户-物品语义鸿沟，全库排序下 Recall@10 最高提升 18.25%。

    ❄️ 冷启动与长尾推荐 (1)

    Sparse Contrastive Learning for Content-Based Cold Item Recommendation

    用 α-entmax 稀疏化 sampled softmax 训练纯内容编码器，以物品-物品相似度建模冷启动，并支持内容空间知识蒸馏，冷物品排序与曝光公平性双赢。

    🌐 跨域与多场景推荐 (1)

    FedMM: Federated Collaborative Signal Quantization for Multi-Market CTR Prediction

    用双层 RQ-VAE 码本做联邦传输介质，全局码本聚合跨市场协同信号、本地码本保留市场特异性，在 XMarket 2/3/4 市场 CTR 任务上以 AUC 超越联邦与集中式 MMR 基线。

    🎯 CTR/CVR 预估与特征交叉 (5)

    Beyond Dense Connectivity: Explicit Sparsity for Scalable Recommendation

    提出 filter-then-fuse 显式稀疏范式，用静态随机过滤与迭代竞争稀疏(ICS)替代稠密全连接，在十亿级工业数据上实现可扩展的CTR提升。

    FEDIN: Frequency-Enhanced Deep Interest Network for Click-Through Rate Prediction

    提出目标条件化频域滤波双分支网络，用注意力谱熵观察引导频域去噪，三数据集GAUC/AUC全面超越SOTA

    Follow the TRACE: Exploiting Post-Click Trajectories for Online Delayed Conversion Rate Prediction

    将点击后行为演化建模为反馈轨迹，用贝叶斯分解融合静态意图与动态轨迹，并以可靠性门控的回溯补全模块作为模型无关增强器，缓解延迟反馈假阴性偏差。

    Generative Bid Shading in Real-Time Bidding Advertising

    用自回归生成式模型端到端输出调价比例，并以CHNet奖励模型+GRPO偏好对齐优化短期与长期剩余，离线与美团线上A/B均显著提升。

    Unified Supervision for Walmart's Sponsored Search Retrieval via Joint Semantic Relevance and Behavioral Engagement Modeling

    以语义相关性为主监督、互动信号仅作相关物品内偏好精修，融合交叉编码器分级标签、多渠道检索先验与去偏互动构建统一监督目标训练双编码器，离线 P@25 +10.5%、NDCG@25 +5.7%，线上曝光 +0.60%。

    ⚖️ 多任务学习与列表级重排 (3)

    Equip Pre-ranking with Target Attention by Residual Quantization

    用残差量化把 Target Attention 近似搬进粗排，以码本查表替代逐候选交互，淘宝线上 CTR/CVR/GMV 全面显著提升

    One Pass, Any Order: Position-Invariant Listwise Reranking for LLM-Based Recommendation

    用结构化注意力掩码+共享位置框架在架构层面消除 LLM 列表重排的候选顺序敏感性，单次前向即达近完美排列稳健性

    Uniboost: Global Coordination with Value Alignment for Fair and Efficient Traffic Allocation

    提出后验价值对齐+独立线性提升的统一流量分配框架，解耦多业务加权方案，线上 A/B 提升 VV +1.69%、Valued VV +3.07%。

    🎮 强化学习与动态探索推荐 (1)

    Additive Control Variates Dominate Self-Normalisation in Off-Policy Evaluation

    证明最优加性基线 β*-IPS 在 MSE 上渐近严格优于 SNIPS，并扩展至 IPM 排序场景的 β*⊥⊥-IPM。

    🛡️ 去偏公平、可信隐私与工业架构 (7)

    Adaptive Autoguidance for Item-Side Fairness in Diffusion Recommender Systems

    用自适应自引导网络逐步学习引导权重，配合流行度正则化，在扩散推荐中低成本提升物品侧公平性。

    An Epistemic Position-Based Click Model: From Interactions to Epistemic Distributions of Relevance and Bias

    首个上下文认知型位置点击模型，用 Beta 分布刻画相关性与位置偏置的认知不确定性，提出自归一化与位置条件化梯度估计实现稳定优化

    KuaiLive: A Real-time Interactive Dataset for Live Streaming Recommendation

    首个含直播间生命周期、多行为与负反馈的实时直播推荐数据集，构建Top-K与CTR基准。

    Prompt-Unknown Promotion Attacks against LLM-based Sequential Recommender Systems

    黑盒LLM序列推荐下的提示蒸馏+双重投毒商品推广攻击，HR@50最高提升约3.9倍

    R&F-Inventory: A Large-Scale Dataset for Monotonic Inventory Estimation in Reach and Frequency Advertising

    发布首个含预算-触达曲线结构的 R&F 合约库存数据集，定义单点预测与多维单调曲线重建两任务及可复现基准。

    RecNextEval: A Reference Implementation for Temporal Next-Batch Recommendation Evaluation

    提出滑动时间窗 next-batch 评估框架，强制全局时间线数据释放以消除数据穿越，支持增量学习与宏/微平均指标聚合。

    SOLARIS: Speculative Offloading of Latent-bAsed Representation for Inference Scaling

    借鉴投机解码思想，异步预计算并缓存基础模型用户-物品交互表征，实现推理时知识蒸馏，Meta 广告线上收入 +0.67%。
