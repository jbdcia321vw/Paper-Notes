    🏛️ SIGIR 2026 推荐系统论文解读

    116 篇 SIGIR 2026 论文解读，覆盖 14 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🤝 协同过滤与双塔召回 (6)

    CS3: Efficient Online Capability Synergy for Two-Tower Recommendation

    以塔内自校正、跨塔EMA同步与级联模型共享三机制增强双塔召回，离线三数据集AUC一致提升，线上广告收入+8.36%且QPS仅降0.59%。

    DIAURec: Dual-Intent Space Representation Optimization for Recommendation

    以原型意图与分布意图重构表征，用对齐-均匀性+粗细粒度匹配联合优化，Amazon-book R@20 相对提升 10.6%

    OCP: Orthogonal Constrained Projection for Sparse Scaling in Industrial Commodity Recommendation

    在 Item-ID 投影层上施加 Stiefel 流形正交约束，抑制稀疏缩放下的嵌入坍缩，京东线上 UCXR +12.97%、GMV +8.95%。

    SilverTorch: A Unified Model-based System to Democratize Large-Scale Recommendation on GPUs

    将 ANN 检索与特征过滤下沉为 PyTorch 模型层，GPU Bloom Index 与 Int8 融合 ANN 协同设计，吞吐提升 23.7×、成本效率提升 13.35×。

    Unified Supervision for Walmart's Sponsored Search Retrieval via Joint Semantic Relevance and Behavioral Engagement Modeling

    以语义相关性为主监督、互动为相关项内偏好信号，融合交叉编码器分级标签、多通道检索先验与去偏互动构建统一双塔训练目标，离线 P@25 +10.5%、NDCG@25 +5.7%。

    ZoRRO: A Zero-Weight Personalized Recommender System for Scalable News Recommendation

    零权重免训练新闻推荐框架，以时间衰减×表征相似度打分，离线全库排序超越 NRMS，线上 CTR 逼近 SOTA 且推理快 600 倍。

    🕸️ 图神经网络与知识图谱推荐 (3)

    Aspect-Aware Content-Based Recommendations for Mathematical Research Papers

    面向数学论文的 aspect 条件异构图推荐，构建 GoldRiM/SilverRiM 数据集，AchGNN 在 Full-Ranking 下 MRR 相对 GraphCL 提升 26%

    DCGL: Dual-Channel Graph Learning with Large Language Models for Knowledge-Aware Recommendation

    双通道解耦 LLM 语义与 ID 行为信号，多级对比对齐 + 频率感知门控融合，四数据集全库排序全面超越 SOTA。

    QAGCF: Graph Collaborative Filtering for Q&A Recommendation

    将问答对解耦为用户-问题/用户-答案双协同图与问题-答案/问题-问题双语义图，融合为全局异质图后用 Jacobi 多项式图滤波器分离高低频信号，配合噪声对比学习，在知乎与商业数据集 Full-Ranking 下 Recall@10 提升 5.16%–5.34%。

    🔄 自监督对比学习与交互去噪 (2)

    AsarRec: Adaptive Sequential Augmentation for Robust Self-supervised Sequential Recommendation

    将五种序列增强统一为半双随机变换矩阵，用可微 Semi-Sinkhorn 学习用户自适应增强，四数据集全排序下 HR/NDCG 平均提升约 7-8%。

    Don't Contrast the Impossible: Region-Constrained Batching for Contrastive User Modeling on a Local Community Platform

    识别地理约束下 in-batch 负样本中的“不可能负样本”问题，提出区域同质批采样 RCBS，仅改批构造即显著提升用户表征与线上指标。

    ⏱️ 序列与会话推荐 (15)

    Beyond Item IDs: Scaling Short-Form-Video Recommendation via Semantic-Native Long Sequence Modeling

    用深度截断 Bi-gram 语义 ID 替代正交 Video ID，并以无参时间折叠压缩 Transformer 将序列扩至 2000，线上满意观看时长 +1.42%。

    CASE: Cadence-Aware Set Encoding for Large-Scale Next Basket Repurchase Recommendation

    以日历时间二值信号+共享多尺度时序卷积建模物品复购节奏，再用 ISAB 建模跨物品依赖，在四个杂货数据集与千万级生产系统上取得显著提升。

    CMSL: Constructive Multi-Sequence Learning for Recommendation Systems

    提出可学习多序列构造与线性注意力，缓解单序列上下文污染，Meta 四场景 NE 降 0.3%–0.6%。

    Divergence Meets Consensus: A Multi-Source Negative Sampling Framework for Sequential Recommendation

    借鉴 ZPD 理论构建 Teacher-Peer-Self 多源负采样，用分歧重排提升多样性、共识蒸馏复用打分开销，六数据集全库排序下 Recall@20 最高提升 27.3%。

    FEDIN: Frequency-Enhanced Deep Interest Network for Click-Through Rate Prediction

    以目标条件化频谱熵观察为动机，用目标感知频谱滤波+时域双分支做CTR预估，三数据集GAUC/AUC全面SOTA。

    FLAME: Condensing Ensemble Diversity into a Single Network for Efficient Sequential Recommendation

    用冻结+可学习双网络的子模块组合模拟指数级集成多样性，推理仅用单网络，NDCG@20 最高提升 9.70% 且收敛快 7.69 倍。

    From Time and Place to Preference: LLM-Driven Geo-Temporal Context in Recommendations

    用 LLM 从时间戳+粗粒度位置生成地理-时间上下文嵌入，以特征融合或辅助对齐损失注入 SASRec，并提出轻量信息量诊断测试。

    Fusion and Alignment Enhancement with Large Language Models for Tail-item Sequential Recommendation

    用自适应门控融合 ID/LLM 嵌入并以双层对齐+课程学习消除空间结构冲突，全库排序下尾部长尾 H@10 最高提升 427%。

    Learning to Forget: Satiation-Aware Long-Sequence Transducers for Mitigating Post-Purchase Redundancy

    将购买视为意图终止信号，用双路交叉注意力+自适应饱食门控+TTNP自监督学习商品复购周期，PPRR降超60%

    Pay Attention to Sequence Split: Uncovering the Impacts of Sub-Sequence Splitting on Sequential Recommendation Models

    揭示子序列切分(SSS)在数据读取阶段被隐性使用导致模型评估失真，系统分析SSS生效条件与数据分布重塑机理。

    ✨ 生成式推荐与离散语义 ID (19)

    A Cascaded Generative Approach for e-Commerce Recommendations

    提出级联生成式货架构建框架：LLM1 生成投放主题、LLM2 经 RAG 约束生成检索关键词，教师-学生蒸馏降本，线上购物车添加 +2.7%。

    Bi-Level Optimization for Generative Recommendation: Bridging Tokenization and Generation

    将分词器与推荐器建模为双层优化，用元学习+梯度手术让推荐损失直接监督RQ-VAE码本，Full-Ranking下全面超越TIGER/LETTER/ETEGRec。

    CARD: Non-Uniform Quantization of Visual Semantic Unit for Generative Recommendation

    将文本/图像/协同信号渲染为统一视觉语义单元，并用可逆非均匀变换校正偏斜分布，提升码本利用率与生成式推荐精度。

    Differentiable Semantic ID for Generative Recommendation

    用 Gumbel 噪声+不确定性衰减实现可微语义ID联合训练，Leave-One-Out 全库排序下 R@10 相对 TIGER 提升约 12%。

    Discrete Preference Learning for Personalized Multimodal Generation

    用模态专属LightGCN+RQ-VAE把协同偏好量化成离散token注入LLM与扩散模型，配合跨模态一致性奖励实现个性化图文生成。

    Dual-Diffusional Generative Fashion Recommendation

    双分支扩散 Transformer 联合生成时尚单品图像与属性级文本，以结构化偏好加权采样建模用户，PFITB/GOR 双任务个性化指标显著领先且训练提速约 7 倍。

    FAVE: Flow-based Average Velocity Establishment for Sequential Recommendation

    用语义锚先验替代高斯噪声、以平均速度场实现单步流匹配生成推荐，全库排序下 N@20 相对提升 9.9%，推理提速 20 倍以上。

    Gated Bidirectional Linear Attention for Generative Retrieval

    用 Conv1D 局部混合、序列级 Key 门控软遗忘与门控 RMSNorm 将核化线性注意力扩展为双向线性时间算子，1:2 混合编码器在 Yandex Music 上追平双向自注意力，32768 长度单层提速 8.2×。

    GenRec: A Preference-Oriented Generative Framework for Large-Scale Recommendation

    以 Page-wise NTP 解一对多歧义、线性 Token Merger 压缩 2× 输入、GRPO-SR 混合奖励对齐偏好，京东线上点击 +9.5%、成交 +8.7%。

    GFlowGR: Fine-tuning Generative Recommendation Frameworks with Generative Flow Networks

    将生成式推荐重构为集合级序列生成，用 GFlowNets 微调使生成概率正比于行为感知奖励，缓解曝光偏差，淘宝线上年收入相对提升 0.4%。

    🧠 大语言模型推荐 (LLM4Rec) (22)

    ACE: Anisotropy-Controllable Embedding for LLM-enhanced Sequential Recommendation

    用线性自编码器的谱收缩算子连续调控 LLM 物品嵌入的各向异性，在保持语义层级的同时缓解几何失衡，Full-Ranking 下 Recall@20 最高提升 12.4%。

    Agentic Multi-Source Grounding for Enhanced Query Intent Understanding: A DoorDash Case Study

    用目录实体检索+Agentic 网页搜索双源 grounding 替代 winner-takes-all 分类，输出有序双意图并由可插拔消歧层裁决，长尾意图准确率 +13.0pp。

    BEAR: Towards Beam-Search-Aware Optimization for Recommendation with Large Language Models

    揭示 SFT 训练与 beam search 推理的剪枝不一致，提出 token 级 top-B 必要条件的可微正则 BEAR，平均提升 12.50% 且训练开销几乎不变。

    Beyond Static Best-of-N: Bayesian List-wise Alignment for LLM-based Recommendation

    用贝叶斯后验融合静态先验与在线 rollout 证据，构建自演化 BoN 目标，突破静态对齐的性能上界，NDCG@5 相对提升 23.1%。

    Every Preference Has Its Strength: Injecting Ordinal Semantics into LLM-Based Recommenders

    将显式评分建模为LLM词表中的序数语义锚点，以强度感知对齐交互表征，在序列推荐Hit@1与成对偏好准确率上显著超越CF-LLM混合基线。

    Factorized Latent Reasoning for LLM-based Recommendation

    将 LLM 隐式推理拆为 K 个解耦偏好因子并配 GRPO 对齐，全库约束解码下 N@5 最高提升 10.26%

    Filling the Gaps: Selective Knowledge Augmentation for LLM Recommenders

    提出 CKP 比较式知识探测量化 LLM 对物品的协同知识缺口，仅对知识贫乏物品选择性注入属性与参考物品，免训练提升 Recall@1 与长尾覆盖。

    GenFacet: End-to-End Generative Faceted Search via Multi-Task Preference Alignment in E-Commerce

    将电商分面搜索重构为分面生成与查询改写两个耦合生成任务，经蒸馏+SFT+GRPO 对齐搜索效用，线上分面 CTR 相对提升 42.0%。

    ItemRAG: Item-Based Retrieval-Augmented Generation for LLM-Based Recommendation

    将 RAG 从粗粒度用户历史检索转向细粒度物品级检索，融合共购与语义信息，标准与冷启动场景全面超越用户级 RAG 基线。

    L2Rec: Towards Dual-View Understanding of LLMs for Personalized Recommendation

    以参数级双视图 LoRA-MoE 替代输入/输出级融合，个性化路由对齐行为与语义视图，四数据集 N@10 提升 3.87%–8.02%，线上 CTR +9.24%。

    🗣️ 对话推荐与智能体仿真 (8)

    A Standardized Re-evaluation of Conversational Recommender Systems on the ReDial Dataset

    统一复现 7 个 CRS 模型，揭示 Recall@1 复现粒度鸿沟、约 50% 精度来自重复捷径、增益多源于 LLM 骨干而非架构创新。

    Bridging Passive and Active: Enhancing Conversation Starter Recommendation via Active Expression Modeling

    用对抗分布对齐+RQ-VAE语义离散化把用户主动查询引入对话开场白推荐，打破曝光-点击回音室，线上活跃天数+0.04%。

    Conv-FinRe: A Conversational and Longitudinal Benchmark for Utility-Grounded Financial Recommendation

    用逆优化从纵向决策轨迹反推用户风险偏好，构建四视图多视角金融推荐基准，揭示 LLM 效用对齐与行为模仿的根本张力。

    Meituan Merchant Business Diagnosis via Policy-Guided Dual-Process User Simulation

    从行为轨迹挖掘决策策略作为共享对齐层，锚定 LLM 推理与 GBDT 拟合双过程分支，群体仿真误差降至 8.80%。

    RecQuest: Towards Estimating User Domain Knowledge in Conversational Recommender Systems

    提出游戏化数据采集协议 RecQuest 与知识估计新任务，用客观问卷替代自评建立 ground truth，并给出 LLM 零/少样本与微调基线。

    Task-Aware Automated User Profile Generation for Recommendation Simulation Using Large Language Models

    提出免训练三阶段画像生成框架 APG4RecSim，用语义合并+反事实因果映射将交互历史转为任务对齐画像，在判别/排序/评分三任务上取得最佳综合表现。

    TRACE: A Conversational Framework for Sustainable Tourism Recommendation with Agentic Counterfactual Explanations

    多智能体 LLM 框架以澄清提问+反事实解释实现可持续旅游推荐的非强制绿色引导，24 人用户研究验证。

    When and How to Ask: Dynamic Preference Elicitation Strategies for Conversational Recommendation

    提出 InPE 标注数据集与 COPE 分层 MoE 架构，显式建模“何时问、怎么问”的阶段感知偏好引导策略，Recall@10 相对最优基线提升 14.6%。

    🧩 多模态推荐与内容理解 (8)

    A General Framework for Multimodal LLM-Based Multimedia Understanding in Large-Scale Recommendation Systems

    用 1.5B LLaMA2+BLIP-2 将图像转字幕并 token 化为类别特征注入 DLRM 精排，离线 AUC +0.35%、线上 +0.02%，延迟中性。

    From Raw Features to Effective Embeddings: A Three-Stage Approach for Multimodal Recipe Recommendation

    用 VLM/LLM 摘要 + LightGCN 传播 + 跨视图对比学习三阶段精炼食谱多模态特征，Full-Ranking 下 Recall@10 提升 7–15%。

    MLLMRec: A Preference Reasoning Paradigm with Graph Refinement for Multimodal Recommendation

    用 MLLM 推理用户偏好画像替代噪声聚合初始化，并以阈值去噪+共现增强精修物品图，三数据集 11/12 指标 SOTA。

    Multi-modal Relational Item Representation Learning for Inferring Substitutable and Complementary Items

    融合多模态基础模型与元路径行为编码，以自监督对比去噪与 LLM 校验弱监督推断可替代/互补关系，M@10 平均提升 26.1%/39.2%。

    Robust Multimodal Recommendation via Graph Retrieval-Enhanced Modality Completion

    用模态感知子图检索替代 K 跳邻居聚合，配合图 Transformer 与稀疏路由码本补全缺失模态，40% 缺失率下 Recall@20 相对提升 4.2%–5.1%。

    Structural and Disentangled Adaptation of Large Vision Language Models for Multimodal Recommendation

    用模态内结构软教师对齐 LVLM 跨模态表征，并以专家化门控 LoRA 解耦梯度流，即插即用提升多模态与序列推荐，长尾增益最高 18.70%。

    TimeMM: Time-as-Operator Spectral Filtering for Dynamic Multimodal Recommendation

    将交互新近度映射为时间核加权图算子族，隐式实现免特征分解的多尺度谱滤波，配合自适应算子混合与模态路由，全库排序下 R@20 相对提升 3%–10%。

    Well Begun is Half Done: Training-Free and Model-Agnostic Semantically Guaranteed User Representation Initialization for Multimodal Recommendation

    用交互物品模态特征+聚类全局语义免训练初始化用户表征，弥合用户-物品语义鸿沟，六模型四数据集Recall@5最高提升36.4%。

    ❄️ 冷启动与长尾推荐 (2)

    GenRecEdit: Adapting Model Editing for Generative Recommendation with Cold-Start Items

    将 NLP 模型编辑迁移至生成式推荐，用逐位置定位-编辑+One-One 触发注入冷启动物品 SID 模式，仅需重训 9.5% 时间即大幅缓解冷启动坍缩。

    Sparse Contrastive Learning for Content-Based Cold Item Recommendation

    抛弃 CF 对齐、纯内容空间 item-item 相似度建模，用 α-entmax 稀疏化 sampled softmax 并支持内容空间蒸馏，冷物品排序与曝光公平性双赢。

    🌐 跨域与多场景推荐 (4)

    Bridging Behavior and Semantics for Time-aware Cross-Domain Sequential Recommendation

    用神经 ODE 解耦长短期行为、LLM 离散时间 token 反事实增强语义、门控自适应域迁移，1:999 采样排序下 MRR 最高提升 30.5%。

    FedMM: Federated Collaborative Signal Quantization for Multi-Market CTR Prediction
