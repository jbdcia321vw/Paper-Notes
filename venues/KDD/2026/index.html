    🤝 协同过滤与双塔召回 (3)

    Beyond Instance-Level Alignment and Uniformity: Semantic Factor Learning for Collaborative Filtering

    用批次内语义因子路由+匹配构造语义潜在正对，替代GCN邻域聚合，在四个稀疏数据集全库排序下NDCG@20最高提升6.24%。

    Breaking Information Cocoons: A Hyperbolic Framework for Balancing Exploration and Exploitation in Recommender Systems

    洛伦兹双曲空间对齐 LLM 语义与协同信号，并用 Dasgupta 代价驱动的无超参层次聚类实现用户可调探索-利用权衡，效用最高 +5.49%、多样性 +11.39%。

    Scaling Multilingual Semantic Search in Uber Eats Delivery

    基于 gte-Qwen2 双塔统一多语言多垂类语义召回，InfoNCE+Triplet NCE 两阶段训练与 MRL 多维度服务，Store R@20 相对 Legacy 提升 88%。

    🕸️ 图神经网络与知识图谱推荐 (1)

    How Do Graph Signals Affect Recommendation: Unveiling the Mystery of Low and High-Frequency Graph Signals

    理论证明同绝对值低频/高频图信号在推荐中等价，提出频率信号缩放器与空间翻转插件，在四个数据集全库排序下 Recall@20 最高提升约 3.0%。

    🔄 自监督对比学习与交互去噪 (1)

    Dynamic Spectral Denoising with Global-Context Attention for Multi-Behavior Recommendation

    沿特征维做 RFFT 学习视图自适应谱调制净化表征，再以净化全局锚做可靠性感知注意力融合，全库排序下 Taobao HR@10 相对提升 26.17%。

    ⏱️ 序列与会话推荐 (6)

    FuXi-$γ$: Efficient Sequential Recommendation with Exponential-Power Temporal Encoder and Diagonal-Sparse Positional Mechanism

    用艾宾浩斯遗忘曲线启发的指数幂时间编码器替代分桶查表，配合 Toeplitz 对角稀疏位置剪枝，在 Full-Ranking 下精度 SOTA 且训练/推理加速最高 4.74×/6.18×。

    JourneyFormer: Encoding Airbnb Guest Journey with Sequence Modeling

    Airbnb 搜索排序的工业级序列建模方案，以频次分层长短期序列+统一ID嵌入+因果Transformer编码访客旅程，离线NDCG+1.48%、线上Bookers+0.55%。

    MixFormer: Co-Scaling Up Dense and Sequence in Industrial Recommenders

    用单一参数空间统一序列建模与稠密特征交叉，配合用户-物品解耦实现请求级复用，AUC 提升 1.28% 且 FLOPs 降 36%。

    One Sequential Recommendation Model Pretrained from Synthetic Priors Predicts Multiple Datasets

    用 hDCSBM 合成先验预训练 PFN，以支持集条件化实现免更新推理的序列推荐，五基准平均超最优基线 7.53%。

    Scaling Recommender Transformers to One Billion Parameters

    ARGUS 将自回归预训练解耦为反馈预测与下一物品预测双任务，把推荐 Transformer 编码器扩到 10 亿参数，线上听歌时长 +2.26%、点赞率 +6.37%。

    Unleashing the Potential of Neighbors: Diffusion-based Latent Neighbor Generation for Session-based Recommendation

    用检索先验与多模态信号双路引导扩散模型生成“潜在邻居”，突破可观测邻居边界，Full-Ranking 下 P@20 最高提升 18.45%。

    ✨ 生成式推荐与离散语义 ID (13)

    APAO: Bridging the Training-Inference Gap in Generative Recommendation via Adaptive Prefix-Aware Optimization

    揭示 Beam Search 剪枝与 teacher-forcing 训练的前缀级不一致，用自适应最差前缀损失对齐训练与推理，全库排序下 Recall@20 最高提升 13.3%。

    Breaking the Likelihood Trap: Consistent Generative Recommendation with Graph-structured Model

    用有向无环图解码器扩展非自回归生成空间，并以 Gumbel-Softmax 打通评估器梯度，破解似然陷阱，快手线上 Views +0.78%。

    Collaborative Memory Augmentation for Generative Recommendation

    为生成式推荐引入跨用户协同记忆库，用可学习查询token压缩序列、目标感知检索与门控交叉注意力融合，Full-Ranking下NDCG@5最高提升23.7%。

    FlowTime: Towards Continuous Generative Watch Time Prediction via Flow-based Personalized Priors

    提出连续生成式回归新范式，用一步VAE+归一化流个性化先验建模多峰观看时长分布，KuaiRec MAE降0.676%、线上播放时长+1.044%。

    FORGE: Forming Semantic Identifiers for Generative Retrieval in Industrial Datasets

    系统化拆解 SID 构建全流程（多模态特征/量化编码/冲突后处理），提出免训练的 Embedding HitRate 与 Gini 系数代理指标，淘宝线上交易量 +0.35%。

    Hi-SAM: A Hierarchical Structure-Aware Multi-modal Framework for Large-Scale Recommendation

    解耦语义分词器+分层记忆锚点Transformer，修复语义ID推荐中分词冗余与扁平架构失配，工业A/B响应率+6.55%

    Hierarchical Residual Policy Optimization for Generative Recommendations

    将物品级反馈分解为 SID 前缀残差信用，用 RRPO 做保守 token 级策略优化，KuaiSim 会话回报 10.53 vs 8.14，线上 IAA Target Cost 最高 +3.49%。

    PCR-CA: Parallel Codebook Representations with Contrastive Alignment for Multiple-Category App Recommendation

    用并行码本VQ-AE替代RQ-VAE层级量化建模多类别App语义，配合用户/物品双层对比对齐与双流注意力，微软商店线上CTR+10.52%。

    Reasoning over Semantic IDs Enhances Generative Recommendation

    通过教师模型合成富化语料强化 SID-语言对齐，再用 GRPO 结果驱动强化学习激发 SID 推理，三数据集 Full-Ranking 全面超越 SOTA。

    S$^2$GR: Stepwise Semantic-Guided Reasoning in Latent Space for Generative Recommendation

    在每级 SID 码生成前插入受码本聚类语义对比监督的思考 token，实现逐步可验证潜在推理，工业短视频 A/B 显著提升时长。

    用方面级多重人物图+双分支推理补全稀疏用户画像，Amazon六域生成式评测全面超越DEP/DPL。

    Enriching Semantic Profiles into Knowledge Graph for Recommender Systems Using Large Language Models

    用 LLM 为 KG 全实体生成语义画像，以可逆加性注入+成对匹配对齐，Full-Ranking 下 Recall@40 最高提升 2.6%。

    Improving Item Discoverability in e-Commerce Search via Related Intent Generation

    用闭源LLM+蒸馏SLM生成替代/互补/主题三类隐式意图以扩展电商搜索召回，会话购买预测与LLM评审双轨评估，覆盖流量60%→80%、成本仅30%。

    MGFRec: Towards Reinforced Reasoning Recommendation with Multiple Groundings and Feedback

    将单步 grounding 扩展为多轮物品空间接地并引入用户 Agent 反馈，用 GRPO 训练 LLM 推理推荐，Full-Ranking 下 H@5 最高提升约 8.8%。

    Mixture-of-Experts Knowledge Graph Retrieval-Augmented Generation for Multi-Agent LLM-based Recommendation

    用 MoE 多粒度 KG 检索智能体按查询复杂度路由检索粒度，配合知识对齐与对比偏好优化，在 20 候选池协议下 Accuracy 相对提升 5.8%–20.4%。

    ProEx: A Unified Framework Leveraging Large Language Model with Profile Extrapolation for Recommendation

    用四步 CoT 为每个用户/物品生成多面画像并做环境不变性融合，在三个数据集上对 6 个基模型平均提升 5%+。

    Whose Name Comes Up? II: Benchmarking and Intervention-Based Auditing of LLM-Based Scholar Recommendation

    提出 LLMScholarBench，联合审计 22 个 LLM 在 5 类学者推荐任务、3 类推理期干预下的技术质量与社会代表性权衡。

    SafeCRS: Personalized Safety Alignment for LLM-Based Conversational Recommender Systems

    🧩 多模态推荐与内容理解 (3)

    Text-Guided Visual Representation Learning for Robust Multimodal E-Commerce Recommendation

    以结构化元数据初始化语义查询、双流解耦视觉证据并用可靠性双门控校准，在 134K 全库 I2I 检索上 H@100 相对提升 6.04%。

    UniNote: A Unified Embedding Model for Multimodal Representation and Ranking

    小红书工业级 I2I 统一嵌入模型：对比 SFT + GRPO 相对重排两阶段训练，10 类检索任务全 SOTA，MRL 支持弹性维度部署。

    VI-MMRec: Similarity-Aware Training Cost-free Virtual User-Item Interactions for Multimodal Recommendation

    用模态相似度构造虚拟交互矩阵并以统计权重融合，零训练开销即插即用地缓解多模态推荐数据稀疏，Full-Ranking 下 Recall@10 最高提升 22.25%。

    Denoising Implicit Feedback for Cold-start Recommendation

    用内容相似热物品协同表征为冷物品生成置信加权伪标签，并以相对熵×冷启动状态估计样本不确定性做自适应软标签纠正，快手十亿级 A/B 全指标提升。

    PinEqualizer: Full Funnel Content Exploration and Debiasing System at Pinterest

    面向工业级搜索/推荐全漏斗的新内容冷启动系统，以去偏替代纯探索，配合三层可扩展度量框架，线上新鲜内容曝光提升350%。

    🌐 跨域与多场景推荐 (4)

    Atomic Intent Reasoning: Bringing LLM Semantics to Industrial Cross-Domain Recommendations

    将 LLM 意图推理离线化为原子行为-意图对缓存，在线经意图树构建与目标感知检索实现约 400× 加速，快手 A/B 测试 GMV +3.446%。

    MergeRec: Model Merging for Data-Isolated Cross-Domain Sequential Recommendation

    提出数据隔离跨域序列推荐新设定，用任务向量模型合并+伪用户数据+推荐/蒸馏联合目标，Recall@10 平均提升 17.21%。

    Meta Lattice: Model Space Redesign for Cost-Effective Industry-Scale Ads Recommendations

    以模型空间重构统一碎片化广告组合，融合归因窗口混合、帕累托特征选择与推理期知识迁移，线上Topline +10%、容量省20%。

    Sharpness-aware Model Merging with Salience Recovery for LLM-based Cross-Domain Sequential Recommendation

    用锐度感知平坦极小值对齐 + 重尾重参数化恢复显著偏好信号，破解 LLM 跨域序列推荐模型合并中的参数冲突与多域饱和瓶颈。

    Think2Go: Generative Next POI Recommendation with LLM Reasoning

    统一SFT与RL推理的生成式Next-POI框架，用KDE时空认知不确定性与难度感知奖励差校准优势函数，Acc@1较GNPR提升5.8–7.5%。

    🎯 CTR/CVR 预估与特征交叉 (5)

    CTR-Sink: Attention Sink for Language Models in Click-Through Rate Prediction

    在文本化行为序列中插入携带时间距离的 [SINK] 锚点并配合两阶段训练与 sink 间注意力增强，缓解语义碎片化，AUC 稳定提升 0.2–0.6%。

    Expand More, Shrink Less: Shaping Effective-Rank Dynamics for Dense Scaling in Recommendation

    从有效秩视角诊断 RankMixer 的阻尼振荡塌缩，提出参数化全混合与 GLU-PFFN 实现“多扩张少收缩”，Criteo/Avazu 上 AUC 提升超 0.001。

    From Scaling to Structured Expressivity: Rethinking Transformers for CTR Prediction

    用域感知参数重构 Transformer 块，将复杂度从词表规模 n 转向域数 F，配合基组合超网络实现可预测幂律缩放，离线 AUC 最高 +4.38%，线上 CTR +2.33%。

    HMAF: A Hierarchical Multi-Slot GD-RTB Allocation Framework

    以 Plan-Calibrate-Execute 范式将 PV 约束对偶优化与在线列表级生成-评估排序耦合，美团线上 GD 交付率 +3.72%、广告总收入 +1.59%。

    MAC: A Conversion Rate Prediction Benchmark Featuring Labels Under Multiple Attribution Mechanisms

    首个多归因机制CVR公开基准MAC与PyMAL库，提出MoAE模型，GAUC最高提升0.39pt。

    ⚖️ 多任务学习与列表级重排 (3)

    DeGRe: Dense-supervised Generative Reranking for Recommendation

    离线束搜索挖掘前瞻序列+累积回归稠密监督蒸馏至轻量生成器，单次贪心解码逼近全局最优，线上GMV+3.75%

    OneRank: Unified Transformer-Native Ranking Architecture for Multi-Task Recommendation

    将多任务推理内化进 Transformer 栈，用任务私有 token 通道 + 梯度截断 + 匹配式打分替代编码器-预测器分离，Shopee 离线与线上 A/B 全面领先。

    Personalizing Marketplace Policies with Competing Objectives and Constrained Experiments: Evidence from a Job Marketplace

    双边市场免费额度阈值个性化：集成CATE+混合排序+线性外推，护栏风险降10%+，线上验证外推精度r=0.85

    🎮 强化学习与动态探索推荐 (4)

    Heterogeneous Multi-treatment Uplift Modeling for Trade-off Optimization in Short-Video Recommendation

    用异构多处理增益建模+在线动态权重，个性化权衡短视频消费与商业化指标，快手全量部署

    HOBA: Hierarchical On-Policy Bidding Agents for Adaptive Online Advertising

    三层时间尺度解耦出价：LLM 小时级推理超参、SARSA 分钟级因果去偏选专家、专家池逐次拍卖执行，AuctionNet 与线上 A/B 双验证。

    Learning Peer Influence Probabilities with Linear Contextual Bandits

    将同伴影响力概率学习建模为双目标线性上下文 Bandit，刻画 Regret–RMSE 帕累托前沿并提出 InfluenceCB 以单参数 β 导航权衡。

    Uncertainty-Aware Adaptive Recommendation across User Lifecycle

    用 EPE Critic 与经验贝叶斯先验方差量化逐样本认知不确定性，对低活跃用户风险规避降权、高活跃用户 UCB 探索加成，14 天线上 A/B 验证留存与多样性双收益。

    🛡️ 去偏公平、可信隐私与工业架构 (7)

    Bradley-Terry Rankings for Recommender Systems Across Dataset Taxonomies

    用 Bradley-Terry 概率排序替代指标均值聚合，在 14 算法×89 数据集上给出数据集感知的推荐算法排名与免运行预测。

    CanniUplift: A Holistic Framework for Mitigating Seller and Incentive Cannibalization in E-commerce Uplift Modeling

    用平台级GMV一致性约束与核销路径分解，缓解多卖家电商uplift建模中的卖家级与激励级蚕食，线上ΔGMV相对提升4.08%。

    Deep-learning Causal Retrieval Optimization for Efficient e-commerce Distribution in Pinterest

    将购物候选生成器触发建模为因果决策，用 DR 多任务提升学习+随机 Holdout+线性回放，线上触发率降 85% 而购物会话持平。

    LLM-as-a-Judge for Reliable and Explainable Offline Evaluation in Top-K Recommendation

    用 LLM 从用户文本行为构建语义偏好代理替代 holdout ID 匹配，以 reasoning-then-scoring 生成可解释 Top-K 评测，模型排序一致性较常规测试提升 40–150%。

    Lower Bias, Higher Welfare: How Creator Competition Reshapes Bias-Variance Tradeoff in Recommendation Platforms?

    博弈论建模创作者竞争如何重塑平台正则化选择，理论与实验一致表明策略环境下应弱正则（低偏差）以最大化用户福利。

    Rethinking Popularity Bias in Collaborative Filtering via Analytical Vector Decomposition
