    🏛️ KDD 2025 推荐系统论文解读

    73 篇 KDD 2025 论文解读，覆盖 15 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🤝 协同过滤与双塔召回 (7)

    Embed Progressive Implicit Preference in Unified Space for Deep Collaborative Filtering

    将多类隐式反馈按稀疏度映射为有序类别，用嵌套编码+嵌套OLR把渐进偏好压入统一空间，实现单次NNS一阶段排序。

    High Precision Audience Expansion via Extreme Classification in a Two-Sided Marketplace

    将 Airbnb 位置召回从矩形边界重构为 25M 级 S2 单元极端多分类，离线精度 +11.01%、线上未取消预订者 +0.17%。

    IU4Rec: Interest Unit-Based Product Organization and Recommendation for E-Commerce Platform

    闲鱼C2C限库存场景下以兴趣单元(IU)重构商品组织与两阶段推荐，IU-Boosted网络离线AUC+1.91%、线上CTR+2.90%

    On the Role of Weight Decay in Collaborative Filtering: A Popularity Perspective

    揭示权重衰减本质是将流行度编码进嵌入模长，提出 PRISM 初始化策略替代权重衰减，NDCG 最高提升 4.77% 且训练加速 38.48%。

    Optimizing Recall or Relevance? A Multi-Task Multi-Head Approach for Item-to-Item Retrieval in Recommendation

    用多任务蒸馏损失+多头I2I架构联合优化共互动召回与语义相关性，离线召回@500提升14.4%、L2主题相关性提升56.5%，并完成线上A/B验证。

    Real-time Indexing for Large-scale Recommendation by Streaming Vector Quantization Retriever

    用流式 VQ 码本替代 HNSW/DR 静态索引，实现实时挂载、索引均衡与可修复，抖音全量上线显著提升用户参与。

    Synergizing Implicit and Explicit User Interests: A Multi-Embedding Retrieval Framework at Pinterest

    Pinterest 工业级多嵌入召回框架，用可微聚类建模隐式兴趣、条件召回建模显式兴趣，线上 HF Repins +1.09%、A-Pincepts +0.81%。

    🕸️ 图神经网络与知识图谱推荐 (3)

    An Automatic Graph Construction Framework based on Large Language Models for Recommendation

    用 LLM 逐点生成语义向量 + 残差量化抽取隐因子作额外节点，O(N) 构图并设计元路径聚合，Full-Ranking 下 NDCG@10 最高提升 43.57%，华为广告 A/B 提升 RPM 2.69%。

    Collaborative Filtering Meets Spectrum Shift: Connecting User-Item Interaction with Graph-Structured Side Information

    揭示增广图频谱右移现象，提出仅含平移/缩放两因子的 SSC 校正，即插即用提升 LightGCN/JGCF 最高 23%，零额外开销。

    LightKG: Efficient Knowledge-Aware Recommendations with Simplified GNN Architecture

    用标量对编码关系+线性聚合+免子图对比层，在稀疏场景超越12个KGRS基线5.8%并省84.3%训练时间

    🔄 自监督对比学习与交互去噪 (3)

    Enhancing Graph Contrastive Learning with Reliable and Informative Augmentation for Recommendation

    用端到端多级向量量化学习离散码，将码作为虚拟邻居与语义正样本构建三重对比视图，Full-Ranking 下 NDCG@10 最高提升 17.5%。

    OmniSage: Large Scale, Multi-Entity Heterogeneous Graph Representation Learning

    统一异构图 GNN、内容特征与用户序列的多任务对比学习框架，支撑 Pinterest 十亿级实体通用表征，线上全站 Repin 提升约 2.5%。

    Shapley Value-driven Data Pruning for Recommender Systems

    用 FastSHAP 实时估计交互对训练损失的边际贡献，按 Shapley 值剪枝低效用交互并重训，四数据集 Recall/NDCG 平均提升 3.72%。

    ⏱️ 序列与会话推荐 (7)

    Bridging Textual-Collaborative Gap through Semantic Codes for Sequential Recommendation

    用多视图文本量化语义码作桥梁，以码为 Query 交叉注意力融合文本，配合双重掩码自监督，Full-Ranking 下 R@10 最高提升 20.1%。

    DV365: Extremely Long User History Modeling at Instagram

    以离线用户嵌入替代端到端长序列建模，用多切片+漏斗摘要将 4 万~7 万条历史压缩为 58×256 嵌入，15 个下游模型 NE 平均提升 0.4%+。

    GLINT-RU: Gated Lightweight Intelligent Recurrent Units for Sequential Recommender Systems

    单层并行专家混合（密集选择GRU+线性注意力）+门控MLP的高效序列推荐，Leave-One-Out全库排序下精度与推理速度双超SOTA。

    Multi-Grained Preference Enhanced Transformer for Multi-Behavior Sequential Recommendation

    M-GPT 用交互级图卷积建模跨类型行为依赖，并以多粒度多尺度注意力抽取行为感知偏好，Leave-One-Out 全库排序下 HR@5 相对提升 12.2%。

    Time Matters: Enhancing Sequential Recommendations with Time-Guided Graph Neural ODEs

    用时间引导扩散补全稀疏用户时间图、图神经ODE对齐用户兴趣与物品演化，五数据集Recall@20最高提升46%。

    Unlocking the Power of Diffusion Models in Sequential Recommendation: A Simple and Effective Approach

    揭示扩散序列推荐中的嵌入坍缩问题，提出逐 token 独立扩散+三阶段训练，六数据集 HR@20 平均提升 15.45%。

    Why Not Together? A Multiple-Round Recommender System for Queries and Items

    提出 MAGUS 多轮查询-物品联合推荐框架，以词组合关系图桥接查询与物品，用标签传播在线吸收反馈，可插拔接入 12 种基座模型。

    ✨ 生成式推荐与离散语义 ID (4)

    Controlling Diversity at Inference: Guiding Diffusion Recommender Models with Targeted Category Preferences

    提出解耦扩散模型 D3Rec，通过类别偏好引导的反向去噪过程，在推理阶段灵活控制推荐准确率-多样性权衡。

    Flow Matching for Collaborative Filtering

    用行为引导先验与离散流匹配重构生成式CF，全库排序下精度SOTA且仅需2步推理。

    Generating Long Semantic IDs in Parallel for Recommendation

    提出 RPG 用多 token 并行预测 + 图约束解码，将语义 ID 长度扩至 64，NDCG@10 平均超生成式基线 12.6% 且推理更省。

    GREAT: Guiding Query Generation with a Trie for Recommending Related Search about Video at Kuaishou

    用高质量查询构建 Trie 约束 LLM 训练与解码，实现短视频到查询的 I2Q 推荐，离线 Edit@1 最优、线上 CTR 与相关性双升。

    🧠 大语言模型推荐 (LLM4Rec) (10)

    Agent0: Leveraging LLM Agents to Discover Multi-value Features from Text for Enhanced Recommendations

    用 Architect-Sentinel-Oracle 三角色 LLM 智能体闭环自动挖掘文本多值类别特征，以 DCNv2+RIG 为 Oracle 在真实广告生产数据上取得 0.005+ RIG 提升并提速 2-3 倍。

    Collaboration of Large Language Models and Small Recommendation Models for Device-Cloud Recommendation

    提出端云协同 LSC4Rec：云端 LLM 召回+设备端 SRM 实时重排，配合协同训练、分数融合与不一致度触发请求，Beauty 平均提升 16.18%。

    EARN: Efficient Inference Acceleration for LLM-based Generative Recommendation by Register Tokens

    基于 LLMRec 注意力层间稀疏反转与双注意力汇现象，用首尾寄存器 token 压缩历史交互并在第 k 层后剪除 prompt，实现 3.79× 加速与 80.8% KV Cache 缩减且精度反超微调。

    Exploring Feature-based Knowledge Distillation for Recommender System: A Frequency Perspective

    从频域视角揭示特征蒸馏等权缺陷，提出轻量图滤波重加权 FreqD，全库排序下 Recall@20 最高提升 18.2%。

    GORACS: Group-level Optimal Transport-guided Coreset Selection for LLM-based Recommender Systems

    用最优传输+梯度范数构造测试损失上界代理目标，配合贪心初始化-交换精炼两阶段算法做组级核心集选择，20%训练开销超越全量微调。

    LettinGo: Explore User Profile Generation for Recommendation System

    用多LLM探索开放式用户画像、以下游推荐成败构造偏好对、DPO对齐画像生成器，Amazon Books Acc 66.3%→70.4%。

    LLM2Rec: Large Language Models Are Powerful Embedding Models for Sequential Recommendation

    两阶段将 LLM 改造为融合协同信号与语义的物品嵌入模型，Full-Ranking 下域内平均提升约 15%、跨域仍稳定增益。

    Lost in Sequence: Do Large Language Models Understand Sequential Recommendation?

    揭示现有 LLM4Rec 模型无法捕捉交互序列顺序信息，提出冻结 LLM 与 CF-SRec、仅训练轻量 MLP 的蒸馏框架 LLM-SRec，在 Amazon 四数据集上 NDCG@10 全面超越 SOTA。

    The Mental World of Large Language Models in Recommendation: A Benchmark on Association, Personalization, and Knowledgeability

    提出 LRWorld 基准（38K 样本/23M tokens），从关联、个性化、知识性三尺度十因素 31 任务系统评测数十个 LLM，揭示其在神经嵌入检索上的致命短板。

    UQABench: Evaluating User Embedding for Prompting LLMs in Personalized Question Answering

    提出首个标准化三阶段（预训练-微调-评测）用户嵌入软提示基准，用序列理解/行为预测/兴趣感知三类任务揭示嵌入式生成推荐与文本式相当且省 8-19× token。

    🗣️ 对话推荐与智能体仿真 (2)

    LaViC: Adapting Large Vision-Language Models to Visually-Aware Conversational Recommendation

    用视觉知识自蒸馏把商品图压成5个[CLS] token，再做推荐提示微调，在新建Reddit-Amazon三域上HR@1最高提升54.2%。

    Leveraging the Power of Conversations: Optimal Key Term Selection in Conversational Contextual Bandits

    用平滑关键词语境与最小特征值自适应触发对话，将对话式上下文 Bandit 遗憾降至近极小极大最优 O(√(dT logT))，累积遗憾较基线降低至少 14.6%。

    🧩 多模态推荐与内容理解 (3)

    FindRec: Stein-Guided Entropic Flow for Multi-Modal Sequential Recommendation

    用 Stein 核对齐图文与 ID 流分布、MoE 路由动态筛选跨模态信号，Mamba 建模长序列，三数据集 NDCG@5 相对提升 1.4–3.1%。

    MDVT: Enhancing Multimodal Recommendation with Model-Agnostic Multimodal-Driven Virtual Triplets

    用多模态融合表征动态构造虚拟三元组作为额外监督信号，配合三种预热阈值策略与增强 pairwise 损失，即插即用缓解数据稀疏，稀疏用户组 NDCG@10 最高提升 12.85%。

    NoteLLM-2: Multimodal Large Representation Models for Recommendation

    端到端微调 LLM+视觉编码器构建高效 MLRM，用 mICL 与门控后期融合缓解视觉忽视，I2I 全库召回 R@100 显著提升并落地线上 A/B。

    ❄️ 冷启动与长尾推荐 (1)

    Online Item Cold-Start Recommendation with Popularity-Aware Meta-Learning

    按流行度固定切分元学习任务并配冷启动增强器，流式在线场景下冷启动召回相对 SOTA 提升 11%–74%。

    🌐 跨域与多场景推荐 (5)

    Effective Two-Stage Knowledge Transfer for Multi-Entity Cross-Domain Recommendation

    提出 MKT 两阶段多实体知识迁移框架，用异构特征对齐与极化分布损失解决异质特征 schema 下的负迁移，线上 CTR +4.13%。

    Exploring Preference-Guided Diffusion Model for Cross-Domain Recommendation

    用源域交互历史构造偏好引导信号，逐步注入扩散逆向过程生成目标域冷启动用户表征，三场景 MAE 最高降 32.60%。

    Measure Domain's Gap: A Similar Domain Selection Principle for Multi-Domain Recommendation

    用原型距离+bandit动态为每个域挑选相似域子集，解耦共享专家以缓解多域推荐负迁移，三数据集AUC稳定提升。

    PERSCEN: Learning Personalized Interaction Pattern and Scenario Preference for Multi-Scenario Matching

    用用户专属特征图 + VQ 码本蒸馏场景感知偏好 + 渐进式 GLU 融合，在 KuaiRand/Alimama 四场景召回上全面超越 ADIN/SASS/M5。

    Revisiting Self-attention for Cross-domain Sequential Recommendation

    将跨域序列推荐重构为推荐损失与跨域注意力抑制的双目标帕累托优化，以即插即用方式改造自注意力，平均提升 Recall@10 达 9.8%/16.0%。

    📍 时空轨迹与 POI 本地生活推荐 (1)

    Generative Next POI Recommendation with Semantic ID

    用RQ-VAE将POI多源语义量化为层级语义ID并微调LLaMA3-8B生成下一POI，Acc@1最高提升16%，token开销降55%。

    🎯 CTR/CVR 预估与特征交叉 (8)

    An Audio-centric Multi-task Learning Framework for Streaming Ads Targeting on Spotify

    面向音频主导多模态广告场景的 CAMoE 框架，以模态感知任务分组、自适应损失掩码与 DCN 专家实现近帕累托最优 CTR 预估，线上音频 CTR +14.5%。

    Beyond Advertising: Mechanism Design for Platform-Wide Marketing Service 'QuanZhanTui'

    提出全站推场景下的库存约束卖家模型与流式支付拍卖 LPA，在合成与真实数据上同时提升流式福利、用户体验与平台收入。

    Bid2X: Revealing Dynamics of Bidding Environment in Online Advertising from A Foundation Model Lens

    将自动出价环境建模重构为跨场景基础模型的下一token预测，用变量/时间双注意力+零膨胀投影，8数据集MAE全面领先，线上GMV+4.65%。

    Contextual Generative Auction with Permutation-level Externalities for Online Advertising

    用自回归生成器直接生成广告位序列并建模排列级外部性，配合可微事后遗憾学习支付规则，淘宝线上 RPM +3.2%。

    Lightweight Auto-bidding based on Traffic Prediction in Live Advertising

    直播广告场景下，用LightGBM预测全时段累计成本/点击，结合LP对偶最优出价公式与投影梯度下降求解对偶变量，实现秒级轻量自动出价，线上GMV+4.28%。

    Scaling Transformers for Discriminative Recommendation via Generative Pretraining

    用生成式预训练初始化判别式排序模型并冻结稀疏Embedding，破解CTR/CVR过拟合，使稠密参数从13K扩到0.3B仍遵循幂律提升。

    SWaT: Statistical Modeling of Video Watch Time through User Behavior Analysis

    将用户观看行为假设翻译为分桶二项/几何分布白盒统计模型，以软标签 BCE 训练，离线与线上 A/B 均稳定超越 WLR/TPM/CREAD。

    TayFCS: Towards Light Feature Combination Selection for Deep Recommender Systems

    用泰勒展开+IME近似一次性梯度回传估计高阶组合重要性，再用LR滑窗剔除冗余，三数据集AUC显著提升且线上CVR+13.9%

    ⚖️ 多任务学习与列表级重排 (4)

    Beyond Item Dissimilarities: Diversifying by Intent in Recommender Systems

    用实时意图概率驱动整页贪心重排，以贝叶斯后验更新替代物品相似度，YouTube 线上 DAU +0.05%、用户享受度 +0.09%。

    Breaking the Top-$K$Barrier: Advancing Top-$K$ Ranking Metrics Optimization in Recommender Systems

    用量化分位数把 Top-K 截断转成阈值比较，推导 NDCG@K 的紧致平滑上界 SL@K，四数据集三骨干平均提升 6.03%。

    Combinatorial Optimization Perspective based Framework for Multi-behavior Recommendation

    将多行为融合视为组合优化问题施加三阶段约束，并用分布拟合多专家网络抑制负迁移，三数据集 HR@10 最高提升 49.91%。

    MOPI-HFRS: A Multi-objective Personalized Health-aware Food Recommendation System with LLM-enhanced Interpretation

    构建首个融合 NHANES 医疗数据的健康感知食物推荐基准，用符号图结构学习 + Pareto 多目标优化平衡偏好/个性化健康/营养多样性，并以知识注入 LLM 生成可解释理由。

    🎮 强化学习与动态探索推荐 (5)

    A Unified Online-Offline Framework for Co-Branding Campaign Recommendations

    首个联名营销推荐系统性研究：二分图建模+方差感知CUCB在线学习+部分枚举离线预算分配，理论保证近优regret与1-1/e近似，真实数据收益提升12%-73%。

    An Adaptable Budget Planner for Enhancing Budget-Constrained Auto-Bidding in Online Advertising

    将竞价周期切分为多阶段，用 in-context RL 逐 episode 调整预算分配，few-shot 适配新广告主，仿真与线上 A/B 均提升累计价值。

    Multi-task Offline Reinforcement Learning for Online Advertising in Recommender Systems
