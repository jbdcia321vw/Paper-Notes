    🏛️ RecSys 2026 推荐系统论文解读

    82 篇 RecSys 2026 论文解读，覆盖 13 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🤝 协同过滤与双塔召回 (8)

    Mosaic: A Fleet of User Embedding Specialists for Recommendation at Meta

    以四类异构专家模型族构建用户表征舰队，配合 MRM 与余弦冗余损失最大化增量信息，并提出免日志 CoEval 评估，离线 NE 稳定下降、线上 A/B 显著提升。

    Multi-Probe Zero Collision Hash (MPZCH): Mitigating Embedding Collisions and Enhancing Model Freshness in Large-Scale Recommenders

    用线性探测+身份/元数据辅助张量与主动淘汰，在工业级嵌入表上实现零碰撞并提升新内容新鲜度，训练/推理延迟几乎不变。

    Multilingual Semantic Retrieval for Apple Music Search

    305M 多语双塔 + 课程式多目标微调，配合分位数校准混合召回，离线 Hit@10 相对提升 69%，线上尾部查询 CR 提升 7.93% 且无结果率降 86%。

    Parameter-Efficient Single Collaborative Branch for Recommendation

    用单支路权重共享替代用户/物品双塔，参数量减半，精度持平且覆盖率与流行度偏差显著改善。

    Personalizing Incremental Video Search with Hybrid Text and ID Embeddings

    面向 Apple TV 逐键增量搜索，用文本语义与 ID 协同双嵌入注入 XGBoost 排序器，短前缀 NDCG@10 提升 8.63%，线上 CTR +1.14%。

    RecEvolve: A Knowledge-Driven Autonomous Agent System for Recommender Systems

    将双塔召回模型的架构搜索全生命周期交给多智能体闭环，41 次生产级训练换来 NDCG@50 相对 +19.9%、线上满意度 +3.77%，并意外暴露奖励黑客漏洞。

    SMART: LLM-Augmented Hybrid Retrieval for Dynamic Product Ads

    揭示规则查询擅长 BM25 重定向、LLM 查询擅长 ANN 拓客的检索分解，用输出审计门控仅路由 10% 用户，线上转化率 +27.6%

    UniPinRec: Unifying Generative Retrieval and Ranking at Pinterest Scale

    用 MAM 掩码动作建模 + 混合样本 + 跨阶段 KV 缓存复用，将生成式召回与排序全栈统一，线上延迟降 11.1%、QPS 升 63.6%。

    ⏱️ 序列与会话推荐 (7)

    Do Sequential Recommendation Benchmarks Really Require Higher-Order Sequence Modelling?

    用两个不学高阶序列表征的近期加权成对探针（SeqRules/PCTM）在 eSASRec 协议下反超 Transformer，质疑主流基准的容量测量效度。

    DP-Rec: Towards Dynamic Patching for Efficient Long-Sequence Recommendation

    用对比熵惊讶度动态切分长交互序列为变长行为块，在 FLOPs 匹配下 NDCG@10 最高提升 21.1%，实现更优效率-精度前沿。

    LONGER: Scaling Up Long Sequence Modeling in Industrial Recommenders

    用全局Token+Token Merge+混合因果注意力把工业超长行为序列端到端建模推到1万长度，离线AUC+1.57%、线上广告与电商双场景显著提升。

    RecRec: Latent Interests Recursive Reasoning for Sequential Recommendation

    解耦推理态与预测态、以 R 个潜在兴趣做递归推理的免 RL 序列推荐框架，Full-Ranking 下 NDCG@10 最高提升 14.8%。

    Residual Dominance as a Structural Account of Last-Item Reliance in Causal Self-Attention Recommenders

    用范数分解揭示残差连接主导同位置信息保留，并以推理期残差缩放诊断因果自注意力推荐器的末项依赖机制。

    SequenceO1: End-to-End Ultra-Long (100K) Sequence Modeling in Recommendation with Low-Rank Caching

    用可学习原型压缩 100K 历史为定长 sketch 并缓存复用，端到端精排训练/推理 FLOPs 降 49.9×/63.9×，线上 Finish +2.33%。

    Zero-Observation User Reactivation with Gap-Driven Dimensional Gating

    定义零观测用户唤醒问题，提出冻结骨干的逐维门控插件 DeltaGate，以 Δt 与历史表征联合路由个性化历史与全局先验，>365d 桶 Hit@10 提升 33%–84%。

    ✨ 生成式推荐与离散语义 ID (12)

    Addressing Cross-Stage Decoupling of Semantic and Collaborative Signals in Generative Recommendation

    提出 SCRec，通过协同增强分词、语义引导生成与双曲流形对齐三模块双向补全语义与协同信号，在 Amazon 三数据集 Full-Ranking 下 NDCG@10 相对提升 18.7%–26.6%。

    CoFiRec: Coarse-to-Fine Tokenization for Generative Recommendation

    将物品元数据按类目→标题→描述→CF信号分层独立量化，自回归由粗到细解码，Leave-One-Out全库排序下平均超越SOTA约6.4%。

    Distribution-Level Contrastive Supervision for Generative Recommendation

    用分词器多层码本概率分布作软语义目标，以负对称KL+BPR对比监督对齐推荐器表征，即插即用提升多种生成式骨干。

    EGR: Embedding-Native Generative Retrieval with a Shared LLM

    用单一共享 LLM 同时编码物品与用户历史，以双对比损失联合训练，免量化免 grounding，线上 CVR +2.91%

    Empowering Cross-Domain Sequential Recommendation with Hybrid Tokenization and Serial-Parallel Decoding

    跨域共享-专属多塔 RQ-VAE 混合分词 + 两段式串并解码，Leave-One-Out 全库排序下精度 +1.5%、时延 -85.1%。

    GenPage: Towards End-to-End Generative Homepage Construction at Netflix

    用单个 Transformer 将用户上下文 token 化后自回归生成整页多行首页，WBC/RL 后训练，线上 +0.24% 核心参与度且延迟降 20%。

    Hypothesis-Driven Shelf Generation for Personalised Recommendation

    用自然语言货架假设替代固定模板，解耦规划与目录履约，生成式检索+货架对齐显著提升个性化供给

    Not All Branches Are Equal: Adaptive Semantic ID Construction for Generative Recommendation

    将语义 ID 重构为树路径，用轮廓系数自适应分支+概率质量约束构建 AST，五域 Amazon 全库排序平均相对提升 13.08%

    Tokens are All You Need: Dual-purpose Semantic IDs for Achieving LLM-Level I/O Efficiency in Recommendation Systems

    用 RQ-VAE 语义ID 同时承担协同身份与内容重建双职责，以 SiDec 在线解码替代稠密向量 I/O，检索 HitRate@100 提升至 0.2910 且吞吐较原始稠密嵌入快 20.4%。

    Topology-Aware Tokenization for Generative Recommendation

    揭示 RQ-VAE 语义 ID 量化中的拓扑失真问题，提出由粗到细的三级拓扑蒸馏 TopoTok，在 Amazon 三数据集 Full-Ranking 下 Recall@5 最高提升 9.42%。

    🧠 大语言模型推荐 (LLM4Rec) (11)

    DeepAffinity: Long-Term Aspect Preference Prediction in eCommerce using Small Language Models

    用 135M 小模型+结构化字符串化+多任务预测头，从时序行为预测品牌/尺码/颜色等商品属性偏好，Fashion 微 F1 0.34 超 Gemini 零样本与 3B SFT。

    Improving Rare Medication Recommendation with Counterfactual Data Augmentation and Large Language Models

    用 LLM 反事实数据增强 + 病历摘要指令微调 + 逐药自回归生成，缓解罕见药长尾失效，Group-1 Jaccard 最高 +30.2%。

    LLM Reasoning for Subjective Tasks: Failure Modes, Mitigation, and Dynamic Reasoning Routing

    揭示主观验证任务上显式推理与标准 RLVR 会引发推理崩溃，提出条件长度惩罚奖励与人格路由蓝图，Netflix 四任务 macro-F1 最高回升至 0.851。

    LLM-Based User Personas for Recommendations at Scale

    工业级实时生成自然语言用户兴趣画像，蒸馏+异步推理支撑十亿用户在线服务，A/B 测试观看时长 +0.04%

    Pairwise Ranking Outperforms Single-Action RL for Offline Explanation Selection: A Practical Lesson

    将 LLM 解释生成离线化为冻结候选池，用 CPU 端 LambdaRank 逐候选打分选择，F1=0.500 超越 G-Refer/XRec 且延迟<100ms。

    Personalized Recommendation Tool Learning via Autonomous Language Agents

    让 LLM 智能体做个性化工具选择、传统推荐模型做全库打分，以架构设计绕开幻觉与上下文长度限制，Full-Ranking 下 R@10 最高提升 68.8%。

    Progressive Alignment of Recommender Foundation Model through Multi-Phase Post-Training

    将推荐基础模型后训练拆为 LP→FFT→RFT 三阶段，用稠密隐式反馈训练策略、稀疏业务指标仅训练奖励模型，离线 Rank NDCG 0.437→0.463，线上全漏斗指标显著优于非 FM 基线。

    RECAP: Feedback-Driven Streaming Semantic User Profiles for Short-Video Recommendation

    将流式结构化用户画像视为有界记忆状态，用 LLM 语义差分+确定性状态机维护，并以 LLM 判官清洗隐式反馈、双塔评估器打分作 GRPO 奖励闭环优化画像更新器。

    Self-Evolving Recommendation System: End-To-End Autonomous Model Optimization With LLM Agents

    用 Gemini 双智能体（快循环提名+慢循环上线）自动改写优化器/架构/奖励函数，在 YouTube 线上 A/B 取得显著北极星指标提升。

    SPEAR: Selection-aware Personalized End-to-end Adaptive Rewriting and Retrieval for Community Search

    以梯度隔离双嵌入+乘性门控+动态改写选择器统一查询改写与检索，离线点击召回@10提升99.5%，线上QVCTR+0.259%。

    🗣️ 对话推荐与智能体仿真 (9)

    $τ$-Rec: A Verifiable Benchmark for Agentic Recommender Systems

    用可验证目录谓词奖励、reveal-tagged 信息揭示机制与 pass^k 可靠性指标替代 LLM-as-judge，揭示智能体推荐在隐藏约束下的可靠性悬崖。

    A Position Paper on Recommender Systems in the Era of Autonomous Agents

    提出人-智能体-平台三方混合推荐生态，将智能体视为用户侧独立代理，重构任务定义、评估范式与四大研究方向。

    Bootstrapping Conversational Recommendation Agents At Spotify: Synthetic Data Generation and Self-Improvement Loops

    用多轮合成对话+方差归因自改进循环冷启动对话推荐智能体，线上A/B提升14%收听与5%周活。

    Conversational Recommendation over Live E-Commerce Catalogues with Self-Refreshing Retrieval

    面向实时电商商品库的自刷新检索式对话购物助手，以双哈希增量同步替代全量重建，同步开销降至全量 1.8%–12.3%

    Inverse Theory of Mind Modeling for Content Recommendation: From Web Browsing to Dynamic Intelligent Interfaces

    用 LLM 从浏览轨迹反向推断信念并合成多假设人格画像，在 OPeRA 上超越真实人格基线并驱动 VisionOS 空间界面。

    LLM-as-a-Judge for Evaluating System Responses in Conversational Music Recommendation

    首个以 400 条专家标注实证 LLM-as-a-Judge 在对话音乐推荐响应评估中与人类判断的对齐度，并给出条件化与规模选择指南。

    Melo: A Production LLM-Powered Music Recommendation Agent

    网易云音乐生产级 LLM 音乐推荐 Agent，以五节点确定性状态图 + 推理时实体接地 + 反思式重试解决实体幻觉与长尾塌缩，线上 A/B 留存提升超 2pp。

    Shape Your Feed: An LLM-based Agentic System for Conversational Recommendation

    三层 Agentic 架构（感知/服务/自进化）实现多模态实时用户可控重排，离线对齐打分 98.85% 准确率，线上 dislike 降 2.74%。

    The Utility of LLMs in Recommender Systems Explanation Evaluation

    系统评测 14 个 LLM 作为推荐解释评审员与 216 名人类评分的一致性，发现排序相关中等但绝对评分一致性低，并给出四条实用准则。

    🧩 多模态推荐与内容理解 (2)

    Binge Watch: Reproducible Multimodal Benchmark Datasets for Large-Scale Movie Recommendation on MovieLens-10M and 20M

    为 ML-10M/20M 构建可复现多模态基准 M3L（剧情/海报/预告片文本-图像-视频-音频），保留>90%交互并验证音频模态的关键增益。

    Mend the Measurement Gap: Latent User Preference Modeling for Short-Form Video Recommendation

    将异构行为反馈视为隐价值状态的噪声测量，用受限基线+因子化路由瓶颈解耦时长混杂，YouTube Shorts 线上主指标提升 2.67%

    👥 社交与群组推荐 (2)

    Are We Really Making Progress in Group Recommendation? Unmasking the Tie-Breaking Illusion

    揭示群组推荐中训练期 sigmoid 分数压缩与评估期确定性破平交互导致的系统性评估偏差，提出并列感知 HR/NDCG 精确期望协议，使多个 SOTA 方法报告增益大幅缩水。

    Consensus vs. Dissent: Dynamic LLM Modeling of Subjective Preferences in Group Recommenders

    用人类问卷+DeepSeek-V3.1 蒸馏 CoT 微调 Llama/OLMo 作实时判断模型，动态挑选社会选择聚合策略，用户研究(n=284)中公平与共识得分最高。

    ❄️ 冷启动与长尾推荐 (4)

    IDProxy: CTR Prediction with Multimodal LLMs for Cold-Start Recommendation at Xiaohongshu

    用 MLLM 生成代理 ID 嵌入，经粗到细两阶段对齐工业 CTR 排序器，新笔记在线 AUC 提升约 2 倍于全局流量。

    Learning Sparse Representations of Multimodal Content for Enhanced Cold Item Recommendation

    将多模态内容冷启动表征改为 top-K 稀疏嵌入，并用 α-entmax 预稀疏激活诱导锐化与去噪，冷启动 NDCG@20 提升 16.6%–75.5% 且存储更低。

    Predicting Custom-Feed Returns for New Bluesky Posts: A Prospective Study

    将新帖作为查询、信息流作为候选的冷启动路由任务，构建 collect-first/label-later 基准，LambdaRank 达 cR@10 0.7361。

    Soft Curriculum Learning for Optimizing Fresh and Generalized Recommendations

    用损失退火与图内权重替代刚性数据过滤，在连续训练中打破流行度反馈环，线上冷启动互动 +5.70%、满意度 +0.54% 且吞吐无损。

    📍 时空轨迹与 POI 本地生活推荐 (2)

    Generative Spatiotemporal Intent Sequence Recommendation via Implicit Reasoning in Amap

    将LLM显式CoT压缩为隐式潜token并配合时空反事实DPO，在Amap工业数据与线上A/B中实现低延迟意图序列生成。

    Give the Long-tail More SPACE: Promoting Provider Fairness in Next POI Recommendation

    以社区推断+非平衡最优传输配额+约束引导潜扩散生成虚拟用户，在物理可达与供给约束下提升长尾POI曝光，公平性最高提升94.11%且精度不降。

    🎯 CTR/CVR 预估与特征交叉 (3)

    Building a User Foundation Model for the Open Web

    在身份碎片化的开放网络 RTB 场景下，用 MLM+时序切分对比预训练 Transformer 用户序列编码器，并以 LLM-in-the-loop NAS 优化训练管线，线上 A/B 取得 +2.13% CTR、-1.13% eCPC。

    Hierarchical GTV Estimation: Bridging the Gap between Container-Level Ranking and Item-Level Conversion

    面向容器式电商的层级 GTV 预估框架 HGE，用集合感知编码器 + 代理标签分解 + 残差融合解决粒度错配，离线 XAUC +0.63pp、线上 RPS +1.42%。

    LO-FAR: A Cost-Aware Local Filter for Sparse Feature Ranking in Industrial Ad Recommendation

    用CPU级逐特征独立局部估计器替代GPU重训式置换/门控重要性，在475个稀疏ID-list特征上以约2 CPU小时完成排序并保持下游NE增益。

    ⚖️ 多任务学习与列表级重排 (7)

    Embedding Subspace Partitioning for Dynamic Multi-Objective Retrieval

    将双塔嵌入切分为任务感知正交子空间，用服务时可调权重的加权内积替代单一点积，单模型即可在线遍历多目标 Pareto 前沿。

    Heterogeneous Ranking in Industrial-Scale Recommender Systems: A Case Study

    面向 Google Discover 异构信息流的 HA-MoE 多门控专家架构，配合 LENS 可观测性与 DL-AUC 双层评估，离线与线上均获稳定增益。

    Learned Cross-Task Relationships in Multi-Task Models
