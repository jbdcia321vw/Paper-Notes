    🏛️ RecSys 2025 推荐系统论文解读

    86 篇 RecSys 2025 论文解读，覆盖 15 个推荐系统细分方向。每篇均包含一句话总结、核心思想、实验设置与审稿级批判，5 分钟读懂一篇论文。

    🤝 协同过滤与双塔召回 (17)

    A Non-Parametric Choice Model That Learns How Users Choose Between Recommended Options

    用 sigmoid 核密度估计学习误差分布，无需假设 MNL/ENL 即可同时推断用户偏好与选择机制，抗竞争型曝光偏差。

    Agentic Personalisation of Cross-Channel Marketing Experiences

    用 DiD 因果估计 + Thompson 采样构建模块化营销智能体，在 640 万用户线上 RCT 中显著提升漏斗事件与 GMV。

    Balancing Accuracy and Novelty with Sub-Item Popularity

    复用 RecJPQ 子 ID 分解在子码本粒度计算个性化流行度 sPPS，与 item 级 PPS 加权融合，在 NDCG 不降前提下显著提升个性化新颖度。

    Correcting the LogQ Correction: Revisiting Sampled Softmax for Large-Scale Retrieval

    指出标准 logQ 修正误把正样本当作采样项，提出带置信度权重的改进修正，在公开与工业数据上稳定超越标准 logQ。

    Estimating Quantum Execution Requirements for Feature Selection in Recommender Systems Using Extreme Value Theory

    用极值理论对 QAOA 求解 QUBO 特征选择的输出建模，估计达到经典 SA 水平所需的量子执行次数，并在模拟器与真实 QPU 上验证。

    Hierarchical Graph Information Bottleneck for Multi-Behavior Recommendation

    用信息瓶颈原理重构多行为层次推荐，以 InfoNCE 保真、HSIC 压缩、可学习边丢弃去噪，全库排序下 HR@10 最高提升 15.08%。

    Industry Insights from Comparing Deep Learning and GBDT Models for E-Commerce Learning-to-Rank

    在 OTTO 电商 LTR 场景系统对比 DNN 与生产级 LambdaMART，Two-Tower+Softmax CE 离线 NDCG_c +4.32%，8 周线上点击 +1.86%、营收 +0.56%。

    IP2: Entity-Guided Interest Probing for Personalized News Recommendation

    以实体-标题对比预训练探测新闻内实体焦点，并用跨注意力双塔用户编码器建模新闻间实体引导兴趣，MIND-large AUC 达 72.06%。

    Kamae: Bridging Spark and Keras for Seamless ML Preprocessing

    将 PySpark 预处理管线一对一翻译为等价 Keras 层，消除离线/在线特征工程重复实现，Expedia 线上延迟降 61%、成本降 58%。

    Location Matters: Leveraging Multi-Resolution Geo-Embeddings for Housing Search

    将 H3 多分辨率六边形网格与城市嵌入注入双塔对比学习，缓解房源地理稀疏，离线重排模拟租金转化提升 85%。

    🔄 自监督对比学习与交互去噪 (2)

    NLGCL: Naturally Existing Neighbor Layers Graph Contrastive Learning for Recommendation

    用 GNN 相邻层天然异构节点作正样本对替代图增广，免视图构建，全库排序下 NDCG@10 最高提升 12.41% 且训练最快。

    SGCL: Unifying Self-Supervised and Supervised Learning for Graph Recommendation

    将 BPR 与 InfoNCE 合并为单一监督图对比损失，免增广免负采样，精度与训练效率双超 SGL/SimGCL。

    ⏱️ 序列与会话推荐 (5)

    eSASRec: Enhancing Transformer-based Recommendations in a Modular Fashion

    系统消融 Transformer 序列推荐各模块增强，提出 SASRec+LiGR+SS 组合 eSASRec，在时间切分与覆盖率指标下与 HSTU 同处帕累托前沿。

    MoRE: A Mixture of Reflectors Framework for Large Language Model-Based Sequential Recommendation

    用显式/隐式/协同三视角离线反思 + 元反思器自改进与 Contextual Bandit 在线选视角，LLM 序列推荐全库候选下 NDCG@10 最高提升 10.1%。

    Not Just What, But When: Integrating Irregular Intervals to LLM for Sequential Recommendation

    将不规则时间间隔经 MLP 编码与 Interval-Infused Attention 注入 LLaMA-2，配合选项化提示，在 3 个 Amazon 数据集上 HR@1 平均提升 4.4%，并提出“间隔冷启动”新评测视角。

    Time to Split: Exploring Data Splitting Strategies for Offline Evaluation of Sequential Recommenders

    系统对比 LOO 与全局时间切分及目标/验证变体，揭示 LOO 时序泄漏与排序失真，推荐 GTS+Last/Random/Successive 协议。

    User Long-Term Multi-Interest Retrieval Model for Recommendation

    以类别感知分层双兴趣学习与指针生成式类别→物品级联检索，将召回阶段行为序列扩展至千级，淘宝离线HR@2000达16.55%，线上点击+5.54%、订单+11.01%。

    ✨ 生成式推荐与离散语义 ID (6)

    Enhancing Embedding Representation Stability in Recommendation Systems with Semantic ID

    提出 Semantic ID prefix-ngram 分层前缀参数化，用语义聚类碰撞替代随机哈希，缓解 ID 漂移与长尾稀疏，Meta 线上 NE 提升 0.15% 且 A/A 方差降 43%

    GRACE: Generative Recommendation via Journey-Aware Sparse Attention on Chain-of-Thought Tokenization

    用 PKG 属性链式 CoT token 增强语义 ID，并以旅程感知四路稀疏注意力替代全注意力，Home 域 HR@10 相对提升 106.9%，长序列注意力计算降 48%。

    How Fair is Your Diffusion Recommender Model?

    首个针对 DiffRec/L-DiffRec 的公平性实证研究，在 ML1M/FTKY 上以 Full-Ranking 评估效用与消费者/提供者公平，揭示扩散模型放大偏见而 L-DiffRec 可缓解。

    Prompt-to-Slate: Diffusion Models for Prompt-Conditioned Slate Generation

    用潜空间扩散 Transformer 从纯文本 Prompt 直接生成整组 Slate，离线 NDCG 提升 17%、线上重复曝光降 13.4%。

    Semantic IDs for Joint Generative Search and Recommendation

    系统对比任务专属与跨任务语义ID构建策略，发现多任务双塔嵌入+统一RQ-KMeans语义ID在联合搜索推荐中取得最佳权衡。

    Semantic IDs for Music Recommendation

    用 RQ-VAE 残差量化生成音乐语义 ID 替代逐曲嵌入，参数量降 75%–99% 而精度不降，线上多样性显著提升。

    🧠 大语言模型推荐 (LLM4Rec) (4)

    Balancing Fine-tuning and RAG: A Hybrid Strategy for Dynamic LLM Recommendation Updates

    以十亿用户短视频兴趣探索系统为案例，量化对比微调与RAG的更新代价/敏捷性，提出月度微调+周内RAG刷新的混合更新策略，线上A/B显著提升满意度。

    Biases in LLM-Generated Musical Taste Profiles for Recommendation

    通过 64 人用户研究揭示 LLM 生成音乐品味画像存在流派/国别系统性偏差，且用户认同度与下游推荐指标仅弱相关。

    Evaluating Podcast Recommendations with Profile-Aware LLM-as-a-Judge

    用90天收听历史蒸馏自然语言用户画像，驱动零样本LLM做剧集级与模型级离线评判，47人用户研究中与人工判断高度一致。

    Heterogeneous User Modeling for LLM-based Recommendation

    用压缩提示+[USER]锚点token将跨域异构行为压成单一用户表征，并以域重要性平滑加权缓解域跷跷板，六域全库排序R@10最高提升约30%。

    🗣️ 对话推荐与智能体仿真 (2)

    Failure Prediction in Conversational Recommendation Systems

    提出监督式对话性能预测任务，用AE与L1收缩多轮预测器区分系统失败与目录失败，揭示目录缺失场景下预测精度显著下降。

    USB-Rec: An Effective Framework for Improving Conversational Recommendation Capability of Large Language Model

    用带标签用户模拟器自动构造偏好对做 RL 训练，再在推理期用内部用户模拟器+树搜索自增强，iEval 全面超越 SOTA。

    🧩 多模态推荐与内容理解 (9)

    APS Explorer: Navigating Algorithm Performance Spaces for Informed Dataset Selection

    将 29 算法 × 96 数据集的性能向量投影为可交互 PCA 性能空间，用可视化工具支撑可辩护的数据集选择。

    Beyond the past: Leveraging Audio and Human Memory for Sequential Music Recommendation

    用音频编码器预测新歌的 ACT-R 类激活值，将记忆式重复建模扩展到未听歌曲，NDCG_Exp 相对 PISA 提升约 40%，RepBias 降至 0.09%。

    Image-Seeking Intent Prediction for Cross-Device Product Search

    用语音查询+商品摘要预测图像意图，以可微精度损失抑制误触发，离线 Precision 达 78.5。

    Improving Visual Recommendation on E-commerce Platforms Using Vision-Language Models

    在 Mercari C2C 平台微调 SigLIP 图像编码器做视觉相似召回，离线 nDCG@5 +9.1%，线上 CTR +50%、CVR +14%。

    Just Ask for Music (JAM): Multimodal and Personalized Natural Language Music Recommendation

    将查询建模为用户到物品的向量平移，用交叉注意力聚合音频/歌词/CF 多模态，在 JAMSessions 全库排序上 NDCG@10 相对 TalkRec 提升约 105%

    LLM-Powered Nuanced Video Attribute Annotation for Enhanced Recommendations

    用 Gemini 多模态 LLM 做短视频“氛围”属性标注，经金/银集评估与蒸馏扩量，接入个性化受限召回，线上参与度 +0.49%。

    Personalized Image Generation for Recommendations Beyond Catalogs

    用轻量条件扩散先验从隐式反馈采样用户个性化 CLIP 嵌入，冻结 SD+IP-Adapter 解码，免微调实现可扩展个性化图像生成。

    VL-CLIP: Enhancing Multimodal Recommendations via Visual Grounding and LLM-Augmented CLIP Embeddings

    用 Grounding DINO 裁剪商品主体 + LLM 自反思改写商品描述，再微调 CLIP 双塔，Walmart 线上 CTR +18.6%、GMV +4.0%。

    Yambda-5B — A Large-Scale Multi-modal Dataset for Ranking And Retrieval

    发布 Yandex Music 4.79B 交互工业级数据集，含音频嵌入与 is_organic 标志，提出 Global Temporal Split 评测协议并给出 6 类基线基准。

    👥 社交与群组推荐 (3)

    A Multistakeholder Approach to Value-Driven Co-Design of Recommender System Evaluation Metrics in Digital Archives

    通过 5×5 焦点小组将档案领域五类利益相关者价值映射为四阶段研究漏斗评估指标框架，提出研究路径质量、元数据加权相关性等指标方向。

    Consistent Explainers or Unreliable Narrators? Understanding LLM-generated Group Recommendations

    用社会选择聚合策略作多基线对4个LLM的群组推荐与解释做一致性审计，发现推荐近似ADD、解释常称平均但夹带未定义流行度/相似度/多样性。

    You Don't Bring Me Flowers: Mitigating Unwanted Recommendations Through Conformal Risk Control

    用保形风险控制对任意排序器做后处理，以“重复安全内容替换”替代纯删除，在 KuaiRand 上可证明地把不想要内容比例压到用户指定 α 以下且保住 nDCG。

    ❄️ 冷启动与长尾推荐 (9)

    Do We Really Need Specialization? Evaluating Generalist Text Embeddings for Zero-Shot Recommendation and Search

    实证通用文本嵌入(GTE)零样本即超越领域微调模型，并以PCA有效维度揭示空间利用率与压缩收益。

    Exploring the Potential of LLMs for Serendipity Evaluation in Recommender Systems

    用 LLM 模拟用户对推荐结果做惊喜度（serendipity）打分，在淘宝与 MovieLens 两个真实用户调研数据集上做元评估，最优配置 Pearson 相关达 21.5%，显著超越传统代理指标。

    Item-centric Exploration for Cold Start Problem

    提出以物品为中心的 Beta 后验过滤控制，在排序后剔除“错配受众”曝光，线上探索曝光降 20% 而满意度升 50%、可推荐语料扩 10%。

    Let It Go? Not Quite: Addressing Item Cold Start in Sequential Recommendations with Content-Based Initialization

    冻结内容嵌入+有界可训练 delta 校正，兼顾冷启动物品语义结构与热物品任务适配，三数据集冷启动 NDCG@10 最高提升 20.9%。

    LLM-RecG: A Semantic Bias-Aware Framework for Zero-Shot Sequential Recommendation

    揭示 LLM 语义嵌入的域语义偏置，用域间紧致+域内多样双熵损失与源域序列模式注意力实现零样本跨域序列推荐，R@10 平均提升超 10%。

    On Inherited Popularity Bias in Cold-Start Item Recommendation

    揭示生成式冷启动模型继承热模型流行度偏置，提出基于向量模长重标定的免训练后处理去偏方法，在三个多媒体数据集上显著提升物品公平性与曝光多样性。

    Reading Between the Lines: A Study of Thematic Bias in Book Recommender Systems

    用 BERTopic 为 Book-Crossing 打主题标签，构建数据-推荐-用户三阶段主题偏置评估框架，揭示长尾小众读者被主流主题同质化的现象。

    Recommendation Is a Dish Better Served Warm

    系统量化冷启动阈值：物品侧训练交互扫描+用户侧推理历史截断，揭示 6–15 条交互的冷热分界并批判 p-core 过滤的任意性。

    SocRipple: A Two-Stage Framework for Cold-Start Video Recommendations

    社交种子+嵌入KNN涟漪扩散的两阶段冷启视频召回框架，Recall@200 提升至 12.8–13.2%，线上冷启曝光 +36% 且互动率持平。

    🌐 跨域与多场景推荐 (5)

    Affect-aware Cross-Domain Recommendation for Art Therapy via Music Preference Elicitation

    以音乐偏好诱导替代纯视觉诱导，提出 Mozart/Haydn/Salieri 三种情感感知跨域艺术治疗推荐，200 人用户研究验证情绪改善。

    Impacts of Mainstream-Driven Algorithms on Recommendations for Children Across Domains: A Reproducibility Study

    跨电影/音乐/图书三域复现儿童与主流用户偏好偏差，并引入流行度偏差指标，揭示推荐算法对儿童群体的域特异性失效。

    Leave No One Behind: Fairness-Aware Cross-Domain Recommender Systems for Non-Overlapping Users

    为无源域数据的非重叠用户生成虚拟源域画像，双注意力+限制器实现模型无关的跨域公平性纠偏，UGF最高降94.13%且整体精度不降。

    RankGraph: Unified Heterogeneous Graph Learning for Cross-Domain Recommendation

    构建跨产品异构异质图，用 GPU 加速 RGCN + 对比学习产出图 token 注入推荐基础模型，线上 CTR +0.92%、CVR +2.82%。

    Zero-shot Cross-domain Knowledge Distillation: A Case study on YouTube Music

    用 YouTube 视频大教师零样本蒸馏到低流量 YouTube Music 双排序模型，离线 AUC 微增但线上新发内容互动 +11.39%。

    📍 时空轨迹与 POI 本地生活推荐 (1)

    Exploring the Effect of Context-Awareness and Popularity Calibration on Popularity Bias in POI Recommendations

    系统评测上下文感知模型与校准流行度(CP)重排在POI推荐中的去偏效果，发现二者组合可在保精度同时最贴近用户流行度画像。

    🎯 CTR/CVR 预估与特征交叉 (7)

    Blending Sequential Embeddings, Graphs, and Engineered Features: 4th Place Solution in RecSys Challenge 2025

    异构因果Transformer序列编码+TwHIN图+300维手工特征经DCN-v2融合，构建跨6任务通用用户画像，获挑战赛第4名。

    Counterfactual Inference under Thompson Sampling

    推导 Thompson Sampling 下动作倾向性的精确可计算闭式解，使 IPS 类离线评估在 TS 策略下首次可行，OBP 仿真验证无偏收敛。

    Decoupled Entity Representation Learning for Pinterest Ads Ranking

    提出解耦式上游-下游实体表征框架 DERM，三塔+对比自监督+滑动平均聚合，离线 AUC 提升 0.19%、线上 CTR +1.38%、CPA -1.61%

    Exploring Scaling Laws of CTR Model for Online Performance Improvement

    提出 SUAN 统一注意力块实现 CTR 模型三级量级缩放律，再经稀疏注意力+并行推理+在线蒸馏落地线上，CTR +2.81%。

    Identifying Offline Metrics that Predict Online Impact: A Pragmatic Strategy for Real-World Recommender Systems

    用帕累托前沿近似单模型多偏好分流，在 OTTO 线上实验验证 Recall@20→CTR、OD@20→CVR、乘积→销量 的离线-在线对齐关系。

    Modeling Long-term User Behaviors with Diffusion-driven Multi-interest Network for CTR Prediction

    用目标正交分解构造兴趣通道做多兴趣抽取，再用条件扩散生成增强兴趣，工业 A/B 上 CTR +1.52%。

    R4ec: A Reasoning, Reflection, and Refinement Framework for Recommendation Systems

    用 actor/reflection 双小模型迭代反思精炼 LLM 知识，注入 CTR 主干，AUC 相对提升 2.5%+，线上收入 +2.2%。

    ⚖️ 多任务学习与列表级重排 (5)

    D-RDW: Diversity-Driven Random Walks for News Recommender Systems
